## Teams and rotations

### Blackbird as main DPS

|  | [叫我棉被, 零号攻略组](https://www.bilibili.com/video/BV1DaaF6AEay/) | Video |
| --- | --- | --- |
| Rotation | Blackbird: Skill (fills Malice together with the 20 she starts the battle with); Skia: Ultimate (the instant Esper Cycle sets off Stain first); Lacrimosa: copied monster skill (copy Black Tome against groups); Sakiri: Ultimate → Skill; Lacrimosa: Ultimate; Blackbird: Ultimate → Basic Attack ×5 → Enhanced Skill → Basic Attack ×5 → Enhanced Skill → Basic Attack ×5 → Enhanced Skill (once transformed, the Enhanced Skill after each fifth hit, three sets; with the Esper Cycle gauge full, swap to Skia to refresh Stain); Blackbird: Ultimate → Skill (second-stage Ultimate to leave the transformation, then her normal Skill for the next instant Esper Cycle); Lacrimosa: Skill (sets off Nova; Skill if ready); Blackbird: Basic Attack ×5 (one normal Basic Attack set for the remaining 20 Malice); Sakiri: Ultimate → Skill. add Lacrimosa's Ultimate if it is charged, skip it if not, then Blackbird's Ultimate starts the next round; Daffodill as the Chaos teammate works the same way | [5:35](https://www.bilibili.com/video/BV1DaaF6AEay/?t=335) |
| Reason | The key is Blackbird's two Esper Cycles per rotation, the instant one from her normal Skill and one built on the field, setting off Nova and Stain; at Awakening 0 she still needs 20 Malice each loop, so after Nova go back to her for a normal Basic Attack set. | [5:11](https://www.bilibili.com/video/BV1DaaF6AEay/?t=311) |
| Tip | During Blackbird's Enhanced Skill, hold Basic Attack for a multi-hit attack, then tap Basic Attack to start straight from the third hit, saving a little time. | [6:44](https://www.bilibili.com/video/BV1DaaF6AEay/?t=404) |
