## Levels

| Fact | Value |
| --- | --- |
| Character level | Up to 80; ascension at levels 30, 40, 50, 60, 70 and 80 |
| Arc level | Up to 80; ascension at the same levels |
| Level cap | Prydwen states that a character cannot pass the player's Hunter Level |
| Awakenings | Six per character, one per duplicate, chosen in any order; Resonances at 3 and 6 Awakenings. Each character page lists them |

| Item | Use | Sources |
| --- | --- | --- |
| Expansion Core | A portable component used to substitute missing materials when upgrading Esper Abilities or Arcs. Core consumption scales with material rarity. | Hunter Exchange |
| Heterogeneous Unit | An unstable heterogeneous form used when enemy drop materials are insufficient. The amount of Heterogeneous Units used can be adjusted based on the material's rarity. |  |
