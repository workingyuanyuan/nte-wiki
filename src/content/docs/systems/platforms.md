## Servers and accounts

| Topic | Rule |
| --- | --- |
| Servers | Asia, America, Europe, SEA |
| Progress between servers | Not shared; each server is independent |
| Progress between platforms | Shared on the same server when signing in with the same account |
| UID | Shared across platforms and assigned at random |
| Login on iOS and Mac | Facebook, Google, Sign in with Apple, or email |
| Login on Windows PC, Steam, Epic, Galaxy Store | Facebook, Google, or email |
| Login on PlayStation | PSN or email |
| Third-party logins | Accounts created through different providers are separate and share no data |
| Support | In game: Settings, Support Center |

## How to update

| Platform | Steps |
| --- | --- |
| PC | Close the game, reopen the launcher, click Update |
| Android | Launch the game and follow the update prompt |
| iOS and Mac | Download or update from the App Store |
| PlayStation | System menu, select NTE, press OPTIONS, then Check for Update |
| Steam | Close the game, restart the Steam client, find NTE in the Library, click Update |

Version updates take place on Wednesdays from 06:00 to 11:00 (UTC+8); login is closed during maintenance.
