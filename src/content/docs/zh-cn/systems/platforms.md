## 服务器与账号

| 项目 | 规则 |
| --- | --- |
| 服务器 | Asia、America、Europe、SEA |
| 跨服务器进度 | 不互通；每个服务器各自独立 |
| 跨平台进度 | 在同一服务器使用相同账号登录时互通 |
| UID | 跨平台共用，建立时随机指派 |
| iOS 与 Mac 登录方式 | Facebook、Google、Sign in with Apple 或电子邮箱 |
| Windows PC、Steam、Epic、Galaxy Store 登录方式 | Facebook、Google 或电子邮箱 |
| PlayStation 登录方式 | PSN 或电子邮箱 |
| 第三方登录 | 通过不同平台授权建立的账号彼此独立，资料不互通 |
| 客服支持 | 游戏内：设置 - 客服中心 |

## 系统需求

| 平台 | 最低配备 | 推荐配备 |
| --- | --- | --- |
| PC 处理器 | Intel Core i7-10700 | Intel Core i7-12700 或以上 |
| PC 显示卡 | NVIDIA GeForce GTX 1660 或 AMD Radeon RX 5600 | NVIDIA GeForce RTX 3060 或 AMD Radeon RX 6700 或以上 |
| PC 作业系统 | Windows 10 64 位 | Windows 10 64 位 |
| PC 存储空间（官方启动器） | 预留 60 GB 可用空间，解压缩过程中另需 60 GB 临时空间 | 建议安装于 SSD |
| Steam 版 PC | 16 GB 内存、DirectX 11、70 GB 存储空间；亦列出 Snapdragon X 搭配 Adreno X1 | 32 GB 内存、DirectX 12、70 GB 存储空间；亦列出 Snapdragon X2 Elite 搭配 Adreno X2 |
| Android | 高通骁龙 855 或联发科天玑 8000；Android 10.0；20 GB 可用空间 | 高通骁龙 8 Gen 2、骁龙 8 Gen 3 或联发科天玑 9200 或以上 |
| iOS | iPhone 12 Pro Max；iOS 15.0；20 GB 可用空间 | iPhone 14 Pro 或更新机型；iOS 17.0 或以上版本 |

## 更新方式

| 平台 | 操作步骤 |
| --- | --- |
| PC | 关闭当前游戏，重新开启启动器并点击更新 |
| Android | 启动游戏并依画面提示进行更新 |
| iOS 与 Mac | 前往 App Store 下载或更新 |
| PlayStation | 开启系统界面，选择《异环》，按下 OPTIONS 键后选择检查更新 |
| Steam | 关闭游戏，重新启动 Steam 用户端，在「收藏库」中找到《异环》并点击更新 |

版本更新于周三 06:00 至 11:00 (UTC+8) 进行；维护期间暂停登录。
