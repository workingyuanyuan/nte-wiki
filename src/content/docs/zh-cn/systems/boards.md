## 运作方式

| 项目 | 规则 |
| --- | --- |
| 位置 | 棋盘位于斯卡布罗集市；弧盘研募计划位于弧盘商店 - 弧盘研募计划 |
| 开放条件 | 完成正篇任务「序章 - 全新的目的地 - 前往『伊波恩古董店』」 |
| 限定棋盘 | 包含 1 位限定 S 级角色与 3 位 A 级角色；玩家通过掷骰并停在格子上取得奖励 |
| 开放天数 | 三周，自周三维护后起至周三 05:59 (UTC+8) 止；「无归路」开放时间为两周 |
| 掷骰奖励 | 每个棋盘都有对应的礼遇界面，累计掷骰 50、120、200 次可分别获得滑翔翼造型、载具涂装与时装；同一批奖励也有机率提前从棋盘格子中掷出 |
| 掷骰计数 | 依棋盘名称分别累计，同名棋盘返场时会保留进度 |
| A 级角色 | [薄荷](/zh-cn/characters/mint/)、[埃德嘉](/zh-cn/characters/edgar/)与[阿德勒](/zh-cn/characters/adler/)，或[哈尼娅](/zh-cn/characters/haniel/)、[海月](/zh-cn/characters/aurelia/)与[翳](/zh-cn/characters/skia/) |
| 限定弧盘 | 每位限定角色对应一个限定 S 级弧盘，各自有专属的弧盘研募计划，开放期间与对应棋盘相同 |
| 弧盘研募消耗 | 三重钥匙；自 1.2 版起也可使用该研募计划的专属钥匙，例如决意钥匙 |
| 常驻棋盘 | 常驻开放，收录常驻 S 级与 A 级角色；依 Game8 与 Prydwen 记载，另有独立卡池与保底机制 |

Prydwen 指出，限定 S 级角色的保底计数会在不同限定棋盘之间继承，而弧盘研募计划与常驻棋盘则各自独立计算保底。该保底计数与礼遇界面的掷骰次数不同。
