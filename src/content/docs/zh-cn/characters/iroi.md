## 技能

伊洛伊通过普通攻击、技能、支援技能以及队友进入「退行」来累积「臆想」。她的技能可治疗、提供攻击力增益并让队友进入「退行」，而极轨终结则会消耗「臆想」开启治疗梦境——或开启进攻梦境，短暂复活一名处于「退行」状态的队友。

| 栏位 | 技能 | 效果说明 |
| --- | --- | --- |
| 普通攻击 | 分工合作、白日梦、清明梦、起床时间、无意识响应 | 「分工合作」进行最多五段小羊攻击、「起床时间」为下落攻击、「无意识响应」于「极限闪避」后发动反击以削减「倾陷值」；各项均会累积「臆想」。长按普通攻击可消耗「臆想」进行最多三次「白日梦」攻击，再次长按则召唤「莫尔甫斯」进行持续的「清明梦」射击。 |
| 技能 | 未来自我连续性假设、自我认同延伸 | 点按触发「自我认同延伸」治疗全队、依据伊洛伊的基础攻击力提供攻击力加成、召唤三只小羊聚拢敌人并累积「臆想」。长按「未来自我连续性假设」使三名队友进入「退行」直至战斗结束。被动方面，任何倒下的队友都会进入「退行」并累积「臆想」。 |
| 极轨终结 | 三十八亿年的海市蜃楼 | 开启梦境并持续消耗「臆想」直至耗尽。低于「臆想」门槛时，开启「牛角门的梦境」为全队持续治疗；达到或高于门槛时，开启「象牙门的梦境」造成灵属性伤害、使「白日梦」与「清明梦」免消耗，并短暂复活一名处于「退行」状态的队友。 |
| 支援技能 | 砰！ | 与「莫尔甫斯」向前击打，造成一段灵属性伤害、治疗全队成员并累积「臆想」。 |
| 被动 1 | 镜象 | 提供「创生」强化，当「创生株」持续存在时生成一个「创生株复制体」，向附近目标发射「复制创生花」。 |
| 被动 2 | 交感性神经系统 | 进行治疗时，赋予全队成员额外的「无视防御」。 |

## 觉醒

每取得一个重复角色可任选一项觉醒解锁；觉醒数达 3 与 6 时解锁共鸣。

| 觉醒 | 效果 |
| --- | --- |
| 重复囚徒困境 | 伊洛伊处于后台时，每秒恢复3点「臆想」。 同时「臆想」积攒效率提升30% ，并且入战后获得满额「臆想」。 |
| 策略：「一报还一报」 | 任意队友释放技能时，伊洛伊将随机召唤莫尔甫斯/伊刻洛斯/方塔苏斯中的一名，协助攻击1次造成共计200%*伊洛伊自身攻击力的伤害，并使全体友方获得相当于伊洛伊自身攻击力*120%的生命值回复，冷却时间5秒。 |
| 策略特性：善良 | 伊洛伊的治疗效果提升36% 。 |
| 策略特性：可激怒 | 「退行」状态下的小羊们攻击倍率提升 莫尔甫斯： 「再睡会儿」的倍率，提升值相当于基础倍率的30% 。 「多睡会儿」的倍率，提升值相当于基础倍率的30% 。 伊刻洛斯： 「打一针吧」的倍率提升，提升值相当于基础倍率的30% 。 「多打几针」的倍率提升，提升值相当于基础倍率的30% 。 方塔苏斯： 「来首歌吧」的倍率提升，提升值相当于基础倍率的30% 。 「不好听吗」的倍率提升，提升值相当于基础倍率的30% 。 |
| 策略特性：清晰 | 「交感性神经系统」效果追加：基于伊洛伊基础攻击力的15% ，提高队伍中角色的攻击力，持续20 秒。 |
| 策略特性：宽容 | 伊洛伊释放「极轨终结：三十八亿年的海市蜃楼」后复活的角色，获得100% 生命值、50 点环合值、50 点极轨终结能量。 |
| 共鸣 3：身为万物的灵长 | 「普通攻击：分工合作」「变轨技能：未来自我连续性假设」「极轨终结：三十八亿年的海市蜃楼」的技能等级提升1 级。 伊洛伊在队伍中时，全队的防御力提升30% 。 |
| 共鸣 6：自诩宇宙的精华 | 伊洛伊在队伍中时，全队暴击伤害提升25% ；队伍中每存在一名「退行」状态的队友，伊洛伊造成的伤害提升15% ，暴击率提升5% 。 |
