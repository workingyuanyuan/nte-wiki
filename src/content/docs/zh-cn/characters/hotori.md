| 项目 | 内容 |
| --- | --- |
| 等级 | S 级，限定 |
| 属性 | 光 |

官方介绍形容浔是神秘莫测的伊波恩古董店店主：早雾眼中最不靠谱的成年人，也是娜娜莉崇拜的对象。

## 取得方式

| 项目 | 内容 |
| --- | --- |
| 棋盘 | 「斯卡布罗集市」的限定棋盘「独酌胧月流」 |
| 首次开放 | 2026-05-13 维护后至 2026-06-03 05:59 (UTC+8) |
| 返场 | 2026-09-09 维护后至 2026-09-30 05:59 (UTC+8) |
| 开放条件 | 完成正篇任务「序章 - 全新的目的地 - 前往『伊波恩古董店』」 |
| 同棋盘 A 级角色 | [哈尼娅](/zh-cn/characters/haniel/)、[海月](/zh-cn/characters/aurelia/)、[翳](/zh-cn/characters/skia/) |
| 掷骰奖励 | 滑翔翼造型「幽兰」、Blizzard-V4 涂装「秋色残影」、时装「兰花不菲」：累计掷骰 50、120、200 次后于「时计礼遇」界面领取，也可能提前掷到对应格子 |

掷骰次数依棋盘名称分开计算：首次开放期间在「时计礼遇」累积的进度已保留至返场。

棋盘机制说明：[棋盘与弧盘研募](/zh-cn/systems/boards/)。

## 技能

浔不使用冷却时间或极轨终结能量，而是随时间在「非闭合时计」上累积能量。她的技能消耗 60 能量以记录最多三个队友的支援技能或变轨技能，极轨终结则触发「时停」来重现这些技能并施展太刀连段。

| 栏位 | 技能 | 效果说明 |
| --- | --- | --- |
| 普通攻击 | 胧月流、非闭合时计、漪澜、勾月、极限反击：半霎 | 「胧月流」进行最多五段光属性攻击，战斗中长按可触发「漪澜」向前突进，「勾月」为空中下落攻击。当浔切换上场时「非闭合时计」会被动旋转，最多可储存 120 能量。「极限反击：半霎」于「极限闪避」后发动反击以削减「倾陷值」。 |
| 技能 | 今景复映 | 无冷却时间；当「非闭合时计」能量高于 60 时消耗 60 能量，造成七段光属性伤害、回拨指针并记录最多三个队友的支援技能或变轨技能（每名队友限一个）。进入或离开战斗会清除记录，再次施放则会覆盖先前的记录。 |
| 极轨终结 | 浮世来潮 | 无冷却时间且不消耗极轨终结能量；于「非闭合时计」能量蓄满时施放，造成十段光属性伤害并持太刀进入「时停」，期间无法切换角色且免疫时间控制。会重现一次已记录的攻击、叠加最多十层太刀连段以造成「终结伤害」，并回拨指针。 |
| 支援技能 | 店主威势 | 投掷雨伞，对范围内造成一段光属性伤害。 |
| 被动 1 | 鬼兰家纹 | 提供「创生」强化，使「创生株」的攻击不会在「时停」期间暂停。 |
| 被动 2 | 天下万宝 | 提高「浮世来潮」的「终结伤害倍率」。 |

## 觉醒

每取得一个重复角色可任选一项觉醒解锁；觉醒数达 3 与 6 时解锁共鸣。

| 觉醒 | 效果 |
| --- | --- |
| 欣欣渐行 | 每记录下一个「援护技」或「变轨技能」，浔在时停期间造成的伤害提升12%。 |
| 忆昔告远 | 时停期间，浔造成的伤害提升20%。 |
| 垂目须臾 | 使用「变轨技能：今景复映」并完成记录后，快速回复使用「变轨技能：今景复映」所消耗的能量，每60秒最多触发一次。在回复能量的过程中进行消耗能量的行为会打断能量恢复。 |
| 旧藏遗散 | 未回拨指针期间，全队每击败1个目标，「非闭合时计」额外积蓄10点能量，最多生效3次。释放「极轨终结：浮世来潮」重置计数。 |
| 独窥全相 | 浔上阵时，如果场上仅有1个敌人，全队对该目标造成的伤害提升15%。浔力竭时，失去该效果。 |
| 时轮啮雪 | 时停期间，浔造成伤害时无视目标30%防御。 |
| 共鸣 3：东零西碎的永恒 | 「普通攻击：胧月流」、「变轨技能：今景复映」、「极轨终结：浮世来潮」的技能等级提升1级。 |
| 共鸣 6：了然于中的至珍 | 浔在编队内且存活时，全队攻击力提升30%。 |
