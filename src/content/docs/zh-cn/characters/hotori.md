## 角色资料

| 项目 | 内容 |
| --- | --- |
| 等级 | S 级，限定 |
| 属性 | 光 |
| 弧盘类型 | 固态 (Solid) |

官方介绍形容浔是神秘莫测的伊波恩古董店店主：早雾眼中最不靠谱的成年人，也是娜娜莉崇拜的对象。

## 取得方式

| 项目 | 内容 |
| --- | --- |
| 棋盘 | 「斯卡布罗集市」的限定棋盘「独酌胧月流」 |
| 首次开放 | 2026-05-13 维护后至 2026-06-03 05:59 (UTC+8) |
| 返场 | 2026-09-09 维护后至 2026-09-30 05:59 (UTC+8) |
| 开放条件 | 完成正篇任务「序章 - 全新的目的地 - 前往『伊波恩古董店』」 |
| 同棋盘 A 级角色 | [哈尼娅](/zh-cn/characters/haniel/)、[海月](/zh-cn/characters/aurelia/)、[翳](/zh-cn/characters/skia/) |
| 掷骰奖励 | 滑翔翼造型「幽兰」、Blizzard-V4 涂装「秋色残影」、时装「兰花不菲」：累计掷骰 50、120、200 次后于「时计礼遇」界面领取，也可能提前掷到对应格子 |

掷骰次数依棋盘名称分开计算：首次开放期间在「时计礼遇」累积的进度已保留至返场。

棋盘机制说明：[棋盘与弧盘研募](/zh-cn/systems/boards/)。

## 技能

浔不使用冷却时间或极轨终结能量，而是随时间在 Non-Closed Timepiece 上累积能量。她的技能消耗 60 能量以记录最多三个队友的支援技能或变轨技能，极轨终结则触发 Time Stop 来重现这些技能并施展太刀连段。

| 栏位 | 技能 | 效果说明 |
| --- | --- | --- |
| 普通攻击 | Misty Moon Style, Non-Closed Timepiece, Rippling Waves, Crescent, Critical Riposte: Half Moment | Misty Moon Style 进行最多五段光属性攻击，战斗中长按可触发 Rippling Waves 向前突进，Crescent 为空中下落攻击。当浔切换上场时 Non-Closed Timepiece 会被动旋转，最多可储存 120 能量。Critical Riposte: Half Moment 于 Critical Dodge 后发动反击以削减 Break。 |
| 技能 | Present Replay | 无冷却时间；当 Non-Closed Timepiece 能量高于 60 时消耗 60 能量，造成七段光属性伤害、回拨指针并记录最多三个队友的支援技能或变轨技能（每名队友限一个）。进入或离开战斗会清除记录，再次施放则会覆盖先前的记录。 |
| 极轨终结 | World's Tide | 无冷却时间且不消耗极轨终结能量；于 Non-Closed Timepiece 能量蓄满时施放，造成十段光属性伤害并持太刀进入 Time Stop，期间无法切换角色且免疫时间控制。会重现一次已记录的攻击、叠加最多十层太刀连段以造成 Finisher DMG，并回拨指针。 |
| 支援技能 | Shopkeeper's Authority | 投掷雨伞，对范围内造成一段光属性伤害。 |
| 被动 1 | Ghost Orchid Crest | 提供 Blossom Enhancement，使 Vita Bud 的攻击不会在 Time Stop 期间暂停。 |
| 被动 2 | All Treasures Under Heaven | 提高 World's Tide 的 Finisher DMG Ratio。 |
