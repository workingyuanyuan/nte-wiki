官方介绍说灵可是破格收入 E.T.D 六队的成员。她能通过心电感应感知人与异象的「电波」，战斗则交给她收养的异象伙伴小贞。

## 取得方式

| 项目 | 内容 |
| --- | --- |
| 棋盘 | 位于「斯卡布罗集市」的限定棋盘「全频带漫游中！」 |
| 首次开放 | 2026-09-09 维护后至 2026-09-30 05:59 (UTC+8) |
| 开放条件 | 完成正篇任务「序章 - 全新的目的地 - 前往『伊波恩古董店』」 |
| 同棋盘 A 级角色 | [哈尼娅](/zh-cn/characters/haniel/)、[海月](/zh-cn/characters/aurelia/)与[翳](/zh-cn/characters/skia/) |
| 掷骰奖励 | 滑翔翼造型「超级恶灵！」、单车「旧时光」涂装组「高速运转的灵可」、时装「星间漫游」：累计掷骰 50、120、200 次可在「同频礼遇」界面领取，也可能提前掷到对应格子获得 |

棋盘机制详见：[棋盘与弧盘研募](/zh-cn/systems/boards/)。

## 技能

灵可通过普通攻击累积 Modulation 并在离场后施加 Hit 'Em Here! 印记，以呼唤队友或小贞发动对应属性的 Synced Strike。她的极轨终结可进入 Overdrive 并展开 Resonance Field，连锁触发 Synced Strike 并使队友的支援技能视为追击。

| 栏位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻击 | Poltergeist CQC, Spectral Smack, Spectral Entrance, Spectral Rush, Ghosthand Counter | 进行最多五段灵属性攻击并累积 Modulation 点数以强化 Full-Frequency Pulse 的 Synced Strike，另包含长按施放的 Spectral Smack、空中下坠的 Spectral Entrance，以及极限闪避反击 Ghosthand Counter。处于后台时，Spectral Rush 会定期派出小贞突袭并施加 Hit 'Em Here! 印记。 |
| 技能 | Full-Frequency Pulse | 进行最多四段灵属性攻击并开启选择轮盘，呼唤一名队友或小贞发动对应属性的 Synced Strike。消耗所有 Modulation 以获得额外 Synced Strike 伤害加成，或依缺席或无法行动的队友人数进一步强化小贞。 |
| 极轨终结 | Oversync | 进入 Overdrive 状态并展开 Resonance Field，与最多三名队友进行 Sync，使变轨技能可触发最多三次附带额外灵属性范围攻击的 Synced Strike。结束时引发依目标负面状态数量提高伤害的灵属性爆发；之后领域内队友的支援技能皆视为追击 Synced Strike。 |
| 支援技能 | Spectral Cross | 与小贞联手攻击造成范围灵属性伤害。在击破 Hit 'Em Here! 印记或施放 Full-Frequency Pulse、Oversync 时也会呼唤队友发动 Synced Strike，Synced Strike 伤害随 Spectral Cross 等级提升。 |
| 被动 1 | Weakness Radar | 灵可于队伍中时，Hexed Enhancement 会提高 Hexed 额外追击的基础伤害，并使受 Hexed 影响的目标受到的追击伤害提高。 |
| 被动 2 | Precision Tuning | 降低目标与触发 Synced Strike 的角色属性相同的异能抗性。不同属性的抗性降低效果可并存，同属性则不叠加，再次触发时刷新持续时间。 |

## 觉醒

每取得一个重复角色可任选一项觉醒解锁；觉醒数达 3 与 6 时解锁共鸣。

| 觉醒 | 效果 |
| --- | --- |
| 万物电台已接通！ | 灵可处于后台时，「普通攻击：恶灵闪击战！」的出现间隔缩短25%。 |
| 幽灵其实很可爱！ | 「极轨终结：超负荷共鸣」的灵属性爆发伤害的倍率提升30%。 |
| 将孤岛彼此相连！ | 释放「极轨终结：超负荷共鸣」将刷新「变轨技能：瞬息全频振」冷却时间。 |
| 星星也说悄悄话！ | 在「共鸣领域」内，每次触发「同频合击」时额外造成一次范围性灵属性异能伤害，当前「极轨终结：超负荷共鸣」技能等级下的倍率为{0}%。该攻击可消耗「小鬼打这里！」标记并触发「同频合击」。 |
| 向全频段呼唤爱！ | 「变轨技能：瞬息全频振」触发的「同频合击」可以触发环合效果。若所选队友与灵可无法发生环合，则本次「同频合击」获得50%增伤。 |
| 世界将予你回声！ | 灵可在队伍时，队伍角色的「同频合击」额外增加25%暴击率，并且队友的「同频合击」可以获得充能效果。 |
| 共鸣 3：心跳重叠于此时！ | 「援护技：恶灵左直拳！」、「变轨技能：瞬息全频振」、「极轨终结：超负荷共鸣」的技能等级提升1级；灵可自身的攻击力提升20%。 |
| 共鸣 6：万籁同频的刹那！ | 「共鸣领域」持续时间延长5秒，期间全队获得30%灵和咒属性增伤。 |
