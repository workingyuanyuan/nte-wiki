## 技能

灵可通过普通攻击累积「谐频」并在离场后施加「小鬼打这里！」印记，以呼唤队友或小贞发动对应属性的「同频合击」。她的极轨终结可进入「异能过载」并展开「共鸣领域」，连锁触发「同频合击」并使队友的支援技能视为追击。

| 栏位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻击 | 恶灵CQC、恶灵大巴掌！、恶灵式登场！、恶灵闪击战！、挨打必须还「手」！ | 进行最多五段灵属性攻击并累积「谐频」点数以强化「瞬息全频振」的「同频合击」，另包含长按施放的「恶灵大巴掌！」、空中下坠的「恶灵式登场！」，以及极限闪避反击「挨打必须还「手」！」。处于后台时，「恶灵闪击战！」会定期派出小贞突袭并施加「小鬼打这里！」印记。 |
| 技能 | 瞬息全频振 | 进行最多四段灵属性攻击并开启选择轮盘，呼唤一名队友或小贞发动对应属性的「同频合击」。消耗所有「谐频」以获得额外「同频合击」伤害加成，或依缺席或无法行动的队友人数进一步强化小贞。 |
| 极轨终结 | 超负荷共鸣 | 进入「异能过载」状态并展开「共鸣领域」，与最多三名队友进行「同频」，使变轨技能可触发最多三次附带额外灵属性范围攻击的「同频合击」。结束时引发依目标负面状态数量提高伤害的灵属性爆发；之后领域内队友的支援技能皆视为追击「同频合击」。 |
| 支援技能 | 恶灵左直拳！ | 与小贞联手攻击造成范围灵属性伤害。在击破「小鬼打这里！」印记或施放「瞬息全频振」、「超负荷共鸣」时也会呼唤队友发动「同频合击」，「同频合击」伤害随「恶灵左直拳！」等级提升。 |
| 被动 1 | 弱点感应 | 灵可于队伍中时，「覆纹」强化会提高「覆纹」额外追击的基础伤害，并使受「覆纹」影响的目标受到的追击伤害提高。 |
| 被动 2 | 精确调频 | 降低目标与触发「同频合击」的角色属性相同的异能抗性。不同属性的抗性降低效果可并存，同属性则不叠加，再次触发时刷新持续时间。 |

## 觉醒

每取得一个重复角色可任选一项觉醒解锁；觉醒数达 3 与 6 时解锁共鸣。

| 觉醒 | 效果 |
| --- | --- |
| 万物电台已接通！ | 灵可处于后台时，「普通攻击：恶灵闪击战！」的出现间隔缩短25%。 |
| 幽灵其实很可爱！ | 「极轨终结：超负荷共鸣」的灵属性爆发伤害的倍率提升30%。 |
| 将孤岛彼此相连！ | 释放「极轨终结：超负荷共鸣」将刷新「变轨技能：瞬息全频振」冷却时间。 |
| 星星也说悄悄话！ | 在「共鸣领域」内，每次触发「同频合击」时额外造成一次范围性灵属性异能伤害，当前「极轨终结：超负荷共鸣」技能等级下的倍率为{0}%。该攻击可消耗「小鬼打这里！」标记并触发「同频合击」。 |
| 向全频段呼唤爱！ | 「变轨技能：瞬息全频振」触发的「同频合击」可以触发环合效果。若所选队友与灵可无法发生环合，则本次「同频合击」获得50%增伤。 |
| 世界将予你回声！ | 灵可在队伍时，队伍角色的「同频合击」额外增加25%暴击率，并且队友的「同频合击」可以获得充能效果。 |
| 共鸣 3：心跳重叠于此时！ | 「援护技：恶灵左直拳！」、「变轨技能：瞬息全频振」、「极轨终结：超负荷共鸣」的技能等级提升1级；灵可自身的攻击力提升20%。 |
| 共鸣 6：万籁同频的刹那！ | 「共鸣领域」持续时间延长5秒，期间全队获得30%灵和咒属性增伤。 |

「充能效果」指获得终结能量，不是异能环合「盈蓄」；韩文游戏文字写明是灵可与该队友获得终结能量。
