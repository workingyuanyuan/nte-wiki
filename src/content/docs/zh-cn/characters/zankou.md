## 技能

残虹通过「绯影闪」与「离魂错」在「现实形态」和「幻境形态」之间切换，施加「蚀心」并将持续伤害 (「持续伤害」) 扩散为「追加攻击伤害」。把握时机施放「离魂错」可触发「灭」启动「血宴入梦时」，施加「鸩火」并提供一次免费的强化「焚天烬灭舞」。

| 栏位 | 技能 | 效果说明 |
| --- | --- | --- |
| 普通攻击 | 燎原、魇舞、绰影、落月、折枝、极限反击：虚徊 | 在「现实形态」下，「燎原」与「绰影」造成咒属性伤害并获得「狩」。在「幻境形态」下，「魇舞」与「落月」造成「追加攻击伤害」、施加「蚀心」、扩散最多四个持续伤害 (「持续伤害」) 效果并获得「惑」。另包含下落攻击「折枝」与反击技「极限反击：虚徊」。 |
| 技能 | 绯影闪、离魂错 | 在「现实形态」下，「绯影闪」会进入「幻境形态」、施加「蚀心」，并在特定连段后触发「乱」以削减「倾陷值」。在「幻境形态」下，「离魂错」会切回「现实形态」并造成「追加攻击伤害」、施加「蚀心」；于强化到期前施放可触发「灭」启动「血宴入梦时」。 |
| 极轨终结 | 焚天烬灭舞、血宴入梦时 | 「血宴入梦时」未启动时施放「焚天烬灭舞」；启动时优先施放「血宴入梦时」，造成「追加攻击伤害」、对大范围施加「鸩火」，并于限时内启用一次不消耗极轨终结能量的强化「焚天烬灭舞」。 |
| 支援技能 | 饲火 | 挥刀攻击，造成一段咒属性伤害。 |
| 被动 1 | 暮落残阳 | 提供「浊燃」强化，使「浊燃」最多可叠加三层。当队友对带有「浊燃」的目标施加持续伤害 (「持续伤害」) 效果时，残虹会增加一层「浊燃」并以新效果取代原本的「浊燃」伤害、类型与持续时间。 |
| 被动 2 | 殷红幻景 | 每场战斗一次，进入战斗时将残虹的「环合值」设为 100，且她在队伍中时使自身的「环合强度」提高 100。 |

## 觉醒

每取得一个重复角色可任选一项觉醒解锁；觉醒数达 3 与 6 时解锁共鸣。

| 觉醒 | 效果 |
| --- | --- |
| 瞳中深渊 | 觉醒后，残虹的「普通攻击：燎原」、「普通攻击：绰影」、「极限反击：虚徊」、强化「变轨技能：绯影闪」 、强化「变轨技能：离魂错」均能扩散持续伤害效果，且常态获得「狩」与「惑」增益效果。二者持续生效，不会有延迟清除，也不会因残虹离场或改变攻击形态而清除，仅在残虹阵亡时移除。 「狩」使残虹自身造成的伤害提升至40%，「惑」使全队持续伤害的暴击伤害提升至50%。 |
| 渊底之吻 | 残虹作为环合双方之一参与触发「浊燃」或「覆纹」时，可积累「蓄焰」，使下一次「极轨终结：焚天烬灭舞」造成的最终伤害提升150%；「蓄焰」可以在「极轨终结：焚天烬灭舞」尚未进入可释放状态时提前积累，最多1层。 |
| 吻痕窥梦 | 「狩」额外使残虹的抗打断能力提升50%；「惑」额外使残虹每秒回复自身最大生命值4%的生命。 |
| 梦魇生花 | 当「极轨终结：焚天烬灭舞」进入可释放状态时，立刻激活「极轨终结：血宴入梦时」。 此外，「蓄焰」的增伤效果也将作用于「极轨终结：血宴入梦时」，释放「极轨终结：血宴入梦时」共享「蓄焰」增伤效果层数。 |
| 花开见血 | 强化「变轨技能：绯影闪」首次命中可倾陷目标时，必定使该目标进入倾陷状态。该效果对每个目标在单场战斗中最多生效1次，对角色均衡模式下的Boss不生效。 此外，残虹在队伍时，全队造成的倾陷伤害提升300%。 |
| 血染双瞳 | 「灭」最后1段攻击命中单个目标时，根据命中目标持有的所有持续伤害总层数，每层使本段攻击对该目标造成的伤害提升12%，最多提升240%；命中多名目标时，则分别根据各个目标自身持有的所有持续伤害总层数，单独计算对各个目标的增伤效果。 |
| 共鸣 3：猩红盛宴 | 「普通攻击：燎原」、「普通攻击：魇舞」、「变轨技能：绯影闪」、「变轨技能：离魂错」、「极轨终结：焚天烬灭舞」和「极轨终结：血宴入梦时」的技能等级提升1级。残虹的「极轨终结：血宴入梦时」和「极轨终结：焚天烬灭舞」技能倍率提升20%。 |
| 共鸣 6：鸩火灼心 | 残虹对目标造成伤害后，使自身攻击力提升40%，持续20秒。该效果不可叠加，重复触发时刷新持续时间。 处于「浊燃」状态下的目标被击败后，残虹获得持续60秒的强化效果。强化期间，残虹对目标施加持续伤害效果时，立即使该目标的「浊燃」达到层数上限。再次击败处于「浊燃」状态下的目标时，刷新该强化效果的持续时间。 |
