## 角色资料

| 项目 | 内容 |
| --- | --- |
| 等级 | S 级，主角 |
| 属性 | 光 |
| 弧盘类型 | 固态 (Solid) |
| 加入版本 | 1.0 版 |
| 配音员 | 中文：马洋；英文：Hunter McCoy；日文：内田雄马；韩文：박기욱 |

零就是玩家操作的主角「鉴定师」。官方介绍描述这名由空白与谜团中现身的异能者，对各类异象的「奇点」有着敏锐的洞察力，并接受管理局的安排，在未取得异象猎人资格证的情况下前往伊波恩古董店工作。零可选择男性或女性外观游玩。

## 取得方式

零是每位玩家一开始就会拥有的角色。

## 技能

零通过 Appraisal 连段造成光属性伤害，以 Appraise and Engrave 发射 Esper Cannon 并在攻击低于自身等级的目标时追加一段伤害，并以 Divide by Zero 进行爆发输出。每当当前操作角色获得终结能量时，Appraiser 会通过 Charge Enhancement 为队友回复生命值。

| 栏位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻击 | Appraisal、Appraisal - Severance、Appraisal - Break、Critical Riposte: Flash of Inspiration | Appraisal - Severance 最多可进行五段连续光属性攻击。Appraisal - Break 从空中下坠攻击，造成随坠落高度提升的范围光属性伤害。极限闪避后触发 Critical Riposte: Flash of Inspiration 进行反击，造成范围光属性伤害并降低 Break。 |
| 技能 | Appraise and Engrave | 进行三段连续武器斩击后跃向空中蓄力，发射 Esper Cannon 造成范围光属性伤害，并对首位等级低于零的目标追加一次光属性伤害。 |
| 极轨终结 | Divide by Zero | 在剑舞之间斩断无形丝线，对范围内造成多段光属性伤害。 |
| 支援技能 | Rift Blossom | 斩裂空间并引爆裂隙，对范围内造成两段光属性伤害。 |
| 被动 1 | Appraiser | 施加 Charge Enhancement，每当当前操作角色获得终结能量时，依据零的基础攻击力回复生命值。 |
| 被动 2 | Anomaly Perception | 提升极轨终结 Divide by Zero 所造成的伤害。 |

## 觉醒

每取得一个重复角色可任选一项觉醒解锁；觉醒数达 3 与 6 时解锁共鸣。

| 觉醒 | 效果 |
| --- | --- |
| 初明凝视 | 「变轨技能：铭隙鉴刻」对首次命中的等级不高于自身等级的敌人造成1次200%*攻击力的额外伤害，该伤害无视目标75%防御。 |
| 探悉天职 | 成功释放「变轨技能：铭隙鉴刻」后，自身额外获得8点终结能量。 |
| 奇异记叙 | 「极轨终结：奇零除尽」的暴击率提升50%。 |
| 未决迷数 | 零的每1点基础攻击力都使得「极轨终结：奇零除尽」造成的伤害提升0.1%，上限提升25%。 |
| 默示赋命 | 零触发「援护技」后，使自身攻击力提升10%，持续20秒。 |
| 诓定解放 | 「变轨技能：铭隙鉴刻」的额外伤害倍率提升至300%*攻击力。 |
| 共鸣 3：鉴解 | 「鉴痕」「铭隙鉴刻」「奇零除尽」的技能等级提升1级。 |
| 共鸣 6：零示 | 零触发任意光相关异能环合后，全队角色攻击力提升12%，持续20秒。 |
