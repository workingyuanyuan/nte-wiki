## 技能

法帝娅在生命值高于 1 时会将队友受到的部分伤害转移至自身，降至 1 生命值时则改为分摊承受的伤害。她的技能会连结一名敌人以分摊她受到的伤害，失去足够生命值时可为极轨终结充能并强化其威力。

| 栏位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻击 | 话语中断的否定、观众目击的祭献、拟造坠落的轻蔑、极限反击：回避条件作用 | 「话语中断的否定」最多可攻击五次，「拟造坠落的轻蔑」从空中下坠攻击，极限闪避后施放「极限反击：回避条件作用」可进行反击并降低「倾陷值」。「观众目击的祭献」在法帝娅生命值高于 1 时将队友受到的伤害转移至自身，在生命值为 1 时分摊受到的伤害。 |
| 技能 | 存在证明的体验 | 造成范围魂属性伤害，并对范围内最大生命值最高的敌人施加「破灭体验」。生效期间，该目标会分摊法帝娅受到的部分伤害，直到效果结束、达到「分摊伤害」上限，或双方脱离战斗。 |
| 极轨终结 | 痛苦让位于狂喜 | 进入「敌神者」状态，造成六段「心灵伤害」并回复生命值；再次施放「话语中断的否定」最多可进行五次「心灵伤害」追加攻击。生命值损失达到「破灭阈值」时会补满终结能量并提升其伤害与治疗量，直到「敌神者」状态结束或被其他动作中断。 |
| 支援技能 | 脱格者的嘲弄 | 挥动十字盾牌，对范围内造成一次魂属性伤害。 |
| 被动 1 | 罪感熔炉 | 提供「黯星」强化，当「黯星」结束时让全体队友吸取目标的最大生命值，上限取决于法帝娅的基础最大生命值，并在脱离战斗后恢复双方数值。 |
| 被动 2 | 拒斥与豪掠 | 法帝娅在队伍中时，提升全队的最大生命值。 |

## 觉醒

每取得一个重复角色可任选一项觉醒解锁；觉醒数达 3 与 6 时解锁共鸣。

| 觉醒 | 效果 |
| --- | --- |
| 欲盖弥彰的圣洁 | 法帝娅的伤害分摊比例提升至75%。 |
| 无可否认的本能 | 敌方单位通过「破灭体验」承受的伤害比例提升至600%，上限提升至法帝娅生命上限的25%。当「破灭体验」被移除时，立刻造成敌方单位已承受伤害与「破灭体验」造成伤害上限差值的伤害。 |
| 诅咒祝福之人 | 进入战斗状态后，法帝娅提升固有生命上限的30%，离开战斗状态后失去提升的生命上限。 |
| 僭越禁忌之人 | 「敌神者」状态下法帝娅的回复比例提升至30%生命上限，在已损失生命值大于等于「破灭阈值」时回复比例提升至60%生命上限。 |
| 回溯死亡之人 | 「敌神者」状态下法帝娅的暴击率提升50%。 |
| 爱与死的使徒 | 「变轨技能：存在证明的体验」可为范围内最多10个目标施加「破灭体验」，每个目标单独计算「破灭体验」持续时间及通过「破灭体验」所承受的伤害上限。 |
| 共鸣 3：不敬的「圣洁」之人 | 「普通攻击：话语中断的否定」「变轨技能：存在证明的体验」「极轨终结：痛苦让位于狂喜」的技能等级提升1级。 |
| 共鸣 6：归一的「圣洁」之人 | 当法帝娅在队伍中时，全队获得10%最大生命值提升。 |
