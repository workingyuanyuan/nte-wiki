## 角色资料

| 项目 | 内容 |
| --- | --- |
| 等级 | S 级，常驻 |
| 属性 | 咒 |
| 弧盘类型 | 聚合 (Condensate) |
| 加入版本 | 1.0 版 |
| 配音员 | 中文：桑毓泽；英文：Griffin Burns；日文：中村悠一；韩文：심규혁 |

官方介绍指出，白藏是异象管理局 E.T.D 四队队长：随性散漫、直言不讳，还是个工作摸鱼大师。

## 取得方式

| 方式 | 说明 |
| --- | --- |
| 常驻棋盘 | 根据 Game8 与 Prydwen 的资料，常驻 S 级角色位于斯卡布罗集市的常驻棋盘 |
| 自选箱，1.2 版 | 向所有在 2026-08-19 05:59 (UTC+8) 前创建角色的玩家以信件发放「S 级常驻角色自选箱」 |
| 自选箱，1.4 版 | 来自都市大亨「噗卡计划」的「S 级常驻角色自选箱」 |

此自选箱可从六名角色中任选一名：早雾、白藏、哈索尔、法帝娅、达芙蒂尔或九原。棋盘机制说明见[棋盘与弧盘研募](/zh-cn/systems/boards/)。

## 技能

白藏会消耗当前生命值，通过普通攻击、闪避连段与「不吝赐教」衍生技生成「言灵字」（「祝」、「噤」与「詈」），再于「判予秋」领域内触发其额外伤害、治疗与低生命值处决效果。

| 栏位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻击 | 言行合一、无状之言、无讳之语、于风中、极限反击：避实击虚、如影随形 | 「言行合一」最多可进行五段咒属性攻击，「如影随形」每命中三次消耗当前生命值生成一个「祝」字，最多三个。「无状之言」与「无讳之语」会发射三道引爆指令。「于风中」为下坠攻击；「极限反击：避实击虚」会生成「祝」。 |
| 技能 | 不吝赐教、天地之心、噤念、如此罪状 | 「天地之心」会以地脉文字在目标位置进行攻击。闪避后按下变轨技能可施放「噤念」，造成单体咒属性伤害并生成「噤」字；在「无状之言」或「无讳之语」后施放则会触发「如此罪状」，造成范围伤害并生成「詈」字。 |
| 极轨终结 | 判予秋 | 展开领域并进入「言灵字」状态，持续造成咒属性伤害并处决低于生命值门槛的目标。赋予暂时的致命伤害免疫效果，结束领域并扩散已记录的伤害。依标记触发额外效果：「噤」造成额外单体伤害，「詈」造成范围伤害，「祝」则提供治疗与伤害。 |
| 支援技能 | 摸鱼结束 | 短暂蓄力并书写咒言指令，造成一次范围咒属性伤害，命中时在目标身上生成一个「噤」字。 |
| 被动 1 | 适度恶趣味 | 「浊燃」强化：在处于「浊燃」状态的目标身上生成「言灵字」时，额外施加一次相同效果的「浊燃」。 |
| 被动 2 | 适度上工 | 提升白藏的攻击力，并与 E.T.D 四队队友触发协同效果：在翳潜行期间切换登场时进行攻击并生成「噤」字；法帝娅生命值过低时进行攻击并为她治疗；或在安魂曲处于蝙蝠形态期间切换登场时触发超级跳跃。 |

## 觉醒

每取得一个重复角色可任选一项觉醒解锁；觉醒数达 3 与 6 时解锁共鸣。

| 觉醒 | 效果 |
| --- | --- |
| 唷 队长！ | 「判予秋」期间，触发「噤」字可提升30%白藏下次释放技能的伤害，可叠加。触发「詈」字可缩短白藏技能冷却4秒时长，可叠加（若无技能处于冷却状态，则下次使用时生效）。 |
| 招魂幡 | 与那座山峦一样，层层叠叠。每生成任意1个言灵字，白藏的攻击力将提升6%，效果最多叠加4层，每层持续时间10秒。 |
| 恶诅不过一开口 | 生成言灵字的上限提升至4个。 |
| 亦或是祝祷 | 「判予秋」期间，当任意1个言灵字被触发时，白藏额外恢复5%的最大生命值。 |
| 敬此月色 | 尚未结束。「判予秋」的持续时间提升至16秒。 |
| 于五色为白 | 「判予秋」期间，白藏的暴击率提升30%。 |
| 共鸣 3：序属归藏 | 「言行合一」、「不吝赐教」、「判予秋」的技能等级提升1级。 |
| 共鸣 6：驻于此处 | 偶尔展现队长的庇护力。「判予秋」期间，领域内的所有队伍成员获得20%的攻击力加成，并均可触发「即刻斩杀」效果。 |
