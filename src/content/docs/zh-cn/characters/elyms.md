## 技能

曳尔沐通过普通攻击连段、变轨技能与支援技能将「信号强度」从「弱信号」提升至「强信号」，借此提高极轨终结与离场后「追忆」追击的倍率，同时为队伍提供攻击力与追击伤害加成。

| 栏位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻击 | 即时故障、错频故障、干扰故障、记忆锚点、坠落梦、好的！握手！ | 「即时故障」在「弱信号」下最多可进行五段攻击以解锁「不连续的存在」，长按则施放「干扰故障」。「错频故障」在「中等信号／强信号」下最多可进行三段攻击以解锁「对你说再见」。瞄准施放「记忆锚点」，极限闪避触发「好的！握手！」，「坠落梦」为空中下落攻击。 |
| 技能 | 沉入电子梦、离去的人们、不连续的存在、对你说再见 | 「离去的人们」造成范围光属性伤害，并在「弱信号」下解锁「不连续的存在」，将「信号强度」提升至「中等信号」，获得「错视幻觉」并扫描目标以决定极轨终结形态。接在「错频故障」之后施放「对你说再见」会消耗「错视幻觉」层数造成对应倍率的伤害、进阶至「强信号」并重新扫描。 |
| 极轨终结 | 一如昨日光景 | 依据扫描结果自动切换单体与范围形态（「弱信号」下为范围形态），依照「信号强度」提升伤害倍率，施放后重置回「弱信号」。为队伍提供攻击力与追击伤害加成及「后台联机」，在离场后触发「追忆」协同追击伤害，直到次数耗尽。 |
| 支援技能 | 我在 | 造成光属性伤害，若当前为「弱信号」则提升至「中等信号」，获得「错视幻觉」，并扫描周围目标以切换「一如昨日光景」的单体／范围形态。 |
| 被动 1 | 中继节点 | 「盈蓄」强化会在场上角色获得极轨终结能量时为全队叠加光属性伤害加成，最多八层。「延滞」强化会在队友施加「延滞」后短暂延迟再次对同一目标施加「延滞」，此效果不会连锁触发自身。 |
| 被动 2 | 保底机制 | 提高曳尔沐的暴击伤害。 |

| 觉醒 | 效果 |
| --- | --- |
| 404 遥望一座孤岛 | 释放「极轨终结：一如昨日光景」后，依据释放前累计消耗的「错视幻觉」层数，每消耗过1层，使全队角色的暴击伤害提高10%，持续20秒。重复触发时，刷新该增益的效果和持续时间，并清空「错视幻觉」累计消耗层数。 |
| 200 节点彼此相连 | 「极轨终结：一如昨日光景」伤害的倍率提升30%。 释放「变轨技能：对你说再见」时，每消耗1层「错视幻觉」，本次技能造成的伤害无视目标5%防御。 |
| 504 访问响应超时 | 「信号强度」从「中等信号」增强至「强信号」后，获得3层「错视幻觉」。 「错视幻觉」可叠加，上限4层。 |
| 302 祈愿重新定向 | 曳尔沐在编队内且存活时，全队暴击伤害提升20%。 |
| 304 今日一如往昔 | 「变轨技能：离去的人们」伤害的倍率提升100%。 进入战斗时，曳尔沐的「环合值」为100点，此效果有30秒冷却且单场战斗中最多生效1次。 |
| 301 您访问的地址已被永久转移 | 释放「极轨终结：一如昨日光景」后，依据释放前累计消耗的「错视幻觉」层数，每消耗过1层，使曳尔沐造成的追加攻击伤害提升25%，持续20秒。重复触发时，刷新该增益的效果和持续时间，并清空「错视幻觉」累计消耗层数。 |
| 共鸣 3：拜启，我的旧友 | 「普通攻击」、「变轨技能」、「极轨终结」的技能等级提高1级。 释放「援护技：我在」或「变轨技能：不连续的存在」后，若处于「弱信号」状态，则直接增强至「强信号」，并依次触发「弱信号」增强至「中等信号」、「中等信号」增强至「强信号」的相关效果。「信号强度」增强至「强信号」时，可立即释放「变轨技能：对你说再见」。 |
| 共鸣 6：再会，我的新知 | 曳尔沐在编队内且存活时，全队角色造成的伤害无视目标12%全属性抗性。 「变轨技能：对你说再见」的最后一段命中目标时，若本次技能消耗了「错视幻觉」，则额外造成1次光属性异能伤害，当前「变轨技能：沉入电子梦」技能等级下的倍率为{0}%*「错视幻觉」消耗层数。 |
