| 项目 | 内容 |

| 弧盘类型 | 气态 (Gas) |

| 配音员 | 中文：井琉；英文：Xanthe Huynh；日文：能登麻美子；韩文：문유정 |

官方介绍说她居住在幽暗林中的「魔女之家」。当地人都称她为「魔女」，她寡言少语，并拥有神秘而强大的占卜能力。

| 项目 | 内容 |
| --- | --- |

| 首次开放 | 2026-09-30 维护后至 2026-10-21 05:59 (UTC+8) |
| 开放条件 | 完成正篇任务「序章 - 全新的目的地 - 前往『伊波恩古董店』」 |

| 掷骰奖励 | 滑翔翼造型「预兆鸟」、「旧时光」单车涂装「夜色飞羽」、时装「红与黑」：累计掷骰 50、120、200 次可在「卜运礼遇」界面领取，也可能提前掷到对应格子获得 |

棋盘机制详见：[棋盘与弧盘研募](/zh-cn/systems/boards/)。

## 技能

黑羽通过累积「恶意」并对敌人施加「失乐羽」印记以触发离场协同攻击，接着施放「恳请众魂安息」进入「救世的魔女」状态消耗「恶意」施展强化攻击，最后以「万火归一」收尾。

| 栏位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻击 | 掠影、归巢、顽疾、极限反击：鸟类本能、祭火、予尔等之恩泽、赐众生之福音、灼痕、极限反击：生于灾厄、祝祷 | 「掠影」、「归巢」、「顽疾」与「鸟类本能」造成魂属性伤害，并通过「祝祷」累积「恶意」。在「救世的魔女」状态下，攻击会替换为「祭火」、「予尔等之恩泽」、「赐众生之福音」、「灼痕」与「生于灾厄」，改为消耗「恶意」造成额外「恶意伤害」而非产生「恶意」。 |
| 技能 | 葬羽冥、渡世死焰 | 「葬羽冥」造成魂属性伤害、获得「恶意」并施加「失乐羽」，使队友最多可触发五次「失乐鸟」协同范围攻击。在「救世的魔女」状态下，「祭火」第五段或「无悲」之后可启动「渡世死焰」，蓄力造成魂属性伤害并消耗「恶意」。 |
| 极轨终结 | 恳请众魂安息、万火归一 | 「恳请众魂安息」使黑羽变身为「救世的魔女」，获得免疫受击硬直与移动速度提升并提高全队攻击力；离场时持续时间会暂停计算。再次施放可触发「万火归一」退出该状态并造成高额魂属性伤害。 |
| 支援技能 | 断罪于我、唯余慈悲 | 「断罪于我」化身为「伶仃鸟」造成魂属性伤害并获得「恶意」。在「救世的魔女」状态下则会变为「唯余慈悲」，造成魂属性伤害并在命中时消耗「恶意」。 |
| 被动 1 | 鸫歌 | 「浸染」强化提高「浸染」的伤害加成并延长其持续时间。「黯星」强化使「黯星」结束时依「黯星」期间实际受到的伤害造成额外精神伤害，接着再次施加一次「黯星」，且不会重复触发此再施加效果。 |
| 被动 2 | 长路 | 黑羽施放「断罪于我」时获得 20 点「恶意」。 |

## 觉醒

每取得一个重复角色可任选一项觉醒解锁；觉醒数达 3 与 6 时解锁共鸣。

| 觉醒 | 效果 |
| --- | --- |
| 叛逃者 | 「救世的魔女」发动「极轨终结：万火归一」后可消耗所有「恶意」。 「变轨技能：渡世死焰」伤害的倍率提升150%。 |
| 漫游记 | 「变轨技能：葬羽冥」伤害的倍率提升100%。 处于「救世的魔女」状态时防御提升20%；成功释放「变轨技能：渡世死焰」后获得相当于自身基础攻击力*400%的生命回复。 |
| 失明症 | 黑羽消耗「恶意」造成伤害的倍率提升50%。 |
| 坏骨头 | 黑羽发动「极轨终结：恳请众魂安息」后，提升全队攻击力的持续时间延长至25秒，期间使全队造成的伤害提升12%。 |
| 烂柯人 | 黑羽造成伤害时，使命中目标的魂、相、暗属性伤害抗性降低8%，持续25秒。 |
| 死与生 | 黑羽发动「极轨终结：恳请众魂安息」后，使自身魂属性异能伤害提升25%，持续25秒。 黑羽未处于「救世的魔女」状态下时，「失乐鸟」发动协同攻击后，提供4点「恶意」。 |
| 共鸣 3：唤作谢罪的启示 | 「普通攻击：掠影」、「普通攻击：祭火」、「变轨技能：葬羽冥」、「变轨技能：渡世死焰」、「极轨终结：恳请众魂安息」和「极轨终结：万火归一」的技能等级提升1级。 「极轨终结：恳请众魂安息」伤害的倍率提升100%，「极轨终结：万火归一」伤害的倍率提升50%。 黑羽发动「极轨终结：恳请众魂安息」后，获得20点「恶意」。 |
| 共鸣 6：聆听群星的悼词 | 黑羽处于队伍中时，全队的暴击伤害提升30%。 |
