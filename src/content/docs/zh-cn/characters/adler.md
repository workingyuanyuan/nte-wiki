## 技能

阿德勒通过普通攻击累积「业」层数，并以技能「诛恶护持」消耗层数，造成范围持续咒属性伤害并赋予「明悟之慧佑」护盾；他的极轨终结可造成多段咒属性伤害，被动「克己」则会对处于「浊燃」的敌人施加减益效果。

| 栏位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻击 | 度恶、灭苦、无明、极限反击：揭谛、业 | 以「度恶」最多进行五段连续咒属性攻击，以「灭苦」进行单体瞄准射击，或以「无明」发动下落攻击。在「极限闪避」后施放「度恶」会触发「极限反击：揭谛」，削减「倾陷值」。「度恶」、「无明」与「灭苦」命中时会赋予「业」，最多 20 层。 |
| 技能 | 诛恶护持 | 召唤「空若」幻影造成范围咒属性伤害与持续咒属性伤害，并为场上角色赋予带有「明悟之慧佑」的护盾。施放时消耗所有「业」层数，依消耗层数提高技能伤害。 |
| 极轨终结 | 万象澄寂 | 召唤五尊「空若」——「色」、「受」、「想」、「识」与「行」——攻击所有敌人，各自造成五段咒属性伤害。当场上仅剩一名敌人时，「空若」会再次发动攻击，共计十段咒属性伤害。 |
| 支援技能 | 明镜本无尘 | 瞄准并向敌人发射一发「压缩弹」，命中时造成一段范围咒属性伤害。 |
| 被动 1 | 克己 | 「浊燃」强化：每当目标被施加「浊燃」时，随机施加三种减益效果之一，分别为降低攻击力、降低「属性抗性」或提高「倾陷效率」。相同减益效果无法叠加。 |
| 被动 2 | 正心 | 提升阿德勒的防御力。 |

## 觉醒

每取得一个重复角色可任选一项觉醒解锁；觉醒数达 3 与 6 时解锁共鸣。

| 觉醒 | 效果 |
| --- | --- |
| 无色 | 释放「极轨终结：万象澄寂」后，阿德勒为自身附加20层「业」。 |
| 无受 | 每层「业」为阿德勒提供的伤害加成提升至3%。 |
| 无想 | 「明悟之慧佑」的护盾吸收量提升20%。 |
| 无行 | 「明悟之慧佑」碎裂时，基于阿德勒50%防御力吸收部分溢出伤害。 |
| 无识 | 释放「极轨终结：万象澄寂」后，阿德勒返还20点终结能量。 |
| 诸法空相 | 「明悟之慧佑」的持续时间延长至12秒。 |
| 共鸣 3：辩觉之净业 | 「普通攻击：度恶」「变轨技能：诛恶护持」「极轨终结：万象澄寂」的技能等级提升1级。 |
| 共鸣 6：慧佑之侍护 | 处于「明悟之慧佑」庇护时，全队造成的咒属性异能伤害提升10%。 |
