| 项目 | 内容 |

| 等级 | S 级，限定 |

官方介绍形容明音有着如太阳般耀眼的金发、天生属于聚光灯下，却常待在安静的角落戴着耳机，沉浸在自己的音乐中。公告中也称她为明音。

## 取得方式

| 项目 | 内容 |
| --- | --- |
| 棋盘 | 位于「斯卡布罗集市」的限定棋盘「灿烂的星」 |
| 首次开放 | 2026-10-21 维护后至 2026-11-11 05:59 (UTC+8) |
| 开放条件 | 完成正篇任务「序章 - 全新的目的地 - 前往『伊波恩古董店』」 |
| 同棋盘 A 级角色 | [哈尼娅](/zh-cn/characters/haniel/)、[海月](/zh-cn/characters/aurelia/)与[翳](/zh-cn/characters/skia/) |
| 掷骰奖励 | 滑翔翼造型「迷茫日」、「旧时光」单车涂装「音速流星」、时装「舞台之星」：累计掷骰 50、120、200 次可在「空箱礼遇」界面领取，也可能提前掷到对应格子获得 |

棋盘机制详见：[棋盘与弧盘研募](/zh-cn/systems/boards/)。

## 技能

明音凛通过「弦刃」累积「弦能」，并以「律动音浪」施加单体「泛音列」或部署范围「音域」来传导普通攻击，随后消耗 30 点「弦能」施放「同调共振」，同时善用「音障爆鸣」的两段式「华彩连段」状态。

| 栏位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻击 | 弦刃、舞台跳水、极限反击：羽刃回响 | 「弦刃」进行最多四段相属性攻击，每次明音凛造成伤害时都能产生最多 30 点「弦能」。「舞台跳水」从空中下坠造成范围相属性伤害。「极限反击：羽刃回响」在极限闪避后触发，造成相属性伤害并保留「弦刃」的连段进度。 |
| 技能 | 律动音浪、同调共振 | 点按「律动音浪」对单一目标施加「泛音列」，或长按部署「音域」；两者皆可伴随额外伤害传导普通攻击与「羽刃回响」，且场上同时只能存在一个。累积 30 点「弦能」时可施放「同调共振」，消耗能量并在无敌状态下造成高额伤害。 |
| 极轨终结 | 音障爆鸣 | 造成多段范围相属性伤害并进入提高抗打断能力的「华彩连段」状态，此状态独立于「泛音列」与「音域」。在「华彩连段」结束前可手动再次施放一次，造成范围伤害并提前结束状态。非战斗状态下可持续回复极轨终结能量。 |
| 支援技能 | 变奏和弦 | 强力拨动琴弦，造成一次相属性伤害。 |
| 被动 1 | 绝对音准 | 「延滞」强化：队伍首次触发「延滞」后，持续定期对带有「泛音列」或位于「音域」内的目标施加「延滞」，直到脱离战斗。重复施加「延滞」会触发额外相属性伤害，该伤害视为变轨技能伤害，并随目标剩余的「延滞」持续时间提高。 |
| 被动 2 | 烁星激昂 | 施放「音障爆鸣」后提高明音凛的攻击力。此效果不可叠加，再次触发时重置持续时间。 |

## 觉醒

每取得一个重复角色可任选一项觉醒解锁；觉醒数达 3 与 6 时解锁共鸣。

| 觉醒 | 效果 |
| --- | --- |
| 教室后的吉他谱 | 每次释放强化变轨技能「同调共振」时，立即回复一次相当于明音凛1000%基础攻击力的生命值，并且明音凛的防御力提升50%，抗打断能力提升60%，持续15秒。 |
| 琴行中的变调夹 | 被「泛音列」附着，或者处于「音域」内的敌人相属性抗性降低12%。 |
| 树荫下的胶囊罐 | 点按「变轨技能：律动音浪」释放「泛音列」时，该技能增加1000%的固定倍率；「音域」的半径扩大30%，且长按「变轨技能：律动音浪」释放「音域」时，吸附范围内的敌人。 |
| 耳机里的底噪声 | 释放强化变轨技能「同调共振」后，明音凛暴击伤害提升30%，持续15秒。 |
| 乐队间的节拍器 | 「泛音列」传导普通攻击的倍率提升效果提高至64%；「音域」传导普通攻击的伤害提升效果提高至90%。 |
| 舞台前的超新星 | 「烁星激昂」额外使明音凛获得16%的无视防御。 |
| 共鸣 3：全音阶 | 明音凛的普通攻击、变轨技能、极轨终结的技能等级提高1级；进入战斗时立即充满「弦能」。强化变轨技能「同调共振」增加800%的固定倍率。「极轨终结：音障爆鸣」第二段增加1000%的固定倍率。 |
| 共鸣 6：复调式 | 每次释放强化变轨技能「同调共振」后返还10点「弦能」。释放强化变轨技能「同调共振」后，明音凛暴击伤害提升64%，持续25秒。 |
