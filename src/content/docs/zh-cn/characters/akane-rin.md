## 角色资料

| 项目 | 内容 |
| --- | --- |
| 等级 | S 级，限定 |
| 属性 | 相 |
| 弧盘类型 | 液态 (Liquid) |
| 加入版本 | 1.4 版下半期，2026-10-21 |

官方介绍形容明音有着如太阳般耀眼的金发、天生属于聚光灯下，却常待在安静的角落戴着耳机，沉浸在自己的音乐中。公告中也称她为明音。

## 取得方式

| 项目 | 内容 |
| --- | --- |
| 棋盘 | 位于「斯卡布罗集市」的限定棋盘「灿烂的星」 |
| 首次开放 | 2026-10-21 维护后至 2026-11-11 05:59 (UTC+8) |
| 开放条件 | 完成正篇任务「序章 - 全新的目的地 - 前往『伊波恩古董店』」 |
| 同棋盘 A 级角色 | [哈尼娅](/zh-cn/characters/haniel/)、[海月](/zh-cn/characters/aurelia/)与[翳](/zh-cn/characters/skia/) |
| 掷骰奖励 | 滑翔翼造型「迷茫日」、「旧时光」单车涂装「音速流星」、时装「舞台之星」：累计掷骰 50、120、200 次可在「空箱礼遇」界面领取，也可能提前掷到对应格子获得 |

棋盘机制详见：[棋盘与弧盘研募](/zh-cn/systems/boards/)。

## 技能

明音凛通过 Stringblade 累积 String Energy，并以 Rhythm Wave 施加单体 Overtone 或部署范围 Reverb Field 来传导普通攻击，随后消耗 30 点 String Energy 施放 Synced Resonance，同时善用 Sonic Boom 的两段式 Solo Cadenza 状态。

| 栏位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻击 | Stringblade, Stage Dive, Critical Riposte: Featherblade Reverb | Stringblade 进行最多四段相属性攻击，每次明音凛造成伤害时都能产生最多 30 点 String Energy。Stage Dive 从空中下坠造成范围相属性伤害。Critical Riposte: Featherblade Reverb 在极限闪避后触发，造成相属性伤害并保留 Stringblade 的连段进度。 |
| 技能 | Rhythm Wave, Synced Resonance | 点按 Rhythm Wave 对单一目标施加 Overtone，或长按部署 Reverb Field；两者皆可伴随额外伤害传导普通攻击与 Featherblade Reverb，且场上同时只能存在一个。累积 30 点 String Energy 时可施放 Synced Resonance，消耗能量并在无敌状态下造成高额伤害。 |
| 极轨终结 | Sonic Boom | 造成多段范围相属性伤害并进入提高抗打断能力的 Solo Cadenza 状态，此状态独立于 Overtone 与 Reverb Field。在 Solo Cadenza 结束前可手动再次施放一次，造成范围伤害并提前结束状态。非战斗状态下可持续回复极轨终结能量。 |
| 支援技能 | Altered Chord | 强力拨动琴弦，造成一次相属性伤害。 |
| 被动 1 | Perfect Pitch | Remora Enhancement：队伍首次触发 Remora 后，持续定期对带有 Overtone 或位于 Reverb Field 内的目标施加 Remora，直到脱离战斗。重复施加 Remora 会触发额外相属性伤害，该伤害视为变轨技能伤害，并随目标剩余的 Remora 持续时间提高。 |
| 被动 2 | Starlit Anthem | 施放 Sonic Boom 后提高明音凛的攻击力。此效果不可叠加，再次触发时重置持续时间。 |
