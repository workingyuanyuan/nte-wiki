## 技能

卡厄斯通过攻击累积「罪状」，并在极轨终结的「恶名往复」状态期间迅速生成「罪状」，随后以「裁断」消耗满层的「罪状」造成高额「清算伤害」，同时施加「追缉许可」并强化「延滞」。

| 栏位 | 技能 | 效果说明 |
| --- | --- | --- |
| 普通攻击 | 追猎、裁断、破局、直觉/本能 | 「追猎」进行最多五段相属性伤害攻击。长按普通攻击可触发「裁断」，消耗满层「罪状」造成第二段高额「清算伤害」，未满层时则造成一段攻击。「破局」于空中下落造成依高度加成的范围相属性伤害，而在「极限闪避」后施放「追猎」会触发「直觉/本能」，削减「倾陷值」。 |
| 技能 | 疑点锁定 | 向前射击并召唤猎犬来回扑咬目标两次，命中时对最多两名敌人施加「追缉许可」，并提高对带有「追缉许可」目标造成的伤害。 |
| 极轨终结 | 罪业清偿 | 召唤猎犬压制附近敌人，对范围内所有敌人施加「追缉许可」并进入「恶名往复」。「恶名往复」启动期间，「罪状」会随时间快速增加，使「裁断」能更频繁地施放并造成高额「清算伤害」。 |
| 支援技能 | 强袭 | 向上挥舞镰刀，造成一段相属性伤害。 |
| 被动 1 | 未迟到的正义 | 「延滞」强化会在「延滞」结束时对目标造成依攻击力加成的相属性伤害，依超过「延滞」基础持续时间的经过时间提高总伤害，并在重新施加时重置「延滞」的持续时间。 |
| 被动 2 | 重点关注！ | 提高攻击带有「追缉许可」敌人时获得的伤害加成。 |

## 觉醒

每取得一个重复角色可任选一项觉醒解锁；觉醒数达 3 与 6 时解锁共鸣。

| 觉醒 | 效果 |
| --- | --- |
| 灼见 | 卡厄斯在攻击带有「追缉许可」的敌人时，能够额外获取40%的「罪状」。 |
| 罪名/恶行 | 卡厄斯在攻击带有「追缉许可」的敌人时，无视目标20%防御力。 |
| 烟火 | 卡厄斯使用「极轨终结：罪业清偿」后，暴击伤害提升30%，持续20秒。重复触发刷新持续时间。 |
| 海潮漫延 | 卡厄斯击败带有「追缉许可」的目标时，该「追缉许可」会传递至附近未被标记的目标，重新计算持续时间。 |
| 独见虚空 | 当场上仅剩1名带有「追缉许可」的目标时，卡厄斯对其造成的伤害提升20%。 |
| 伪原点 | 卡厄斯使用「极轨终结：罪业清偿」后，立即将「罪状」补充至上限。 |
| 共鸣 3：正义/正确 | 「普通攻击：追猎」「变轨技能：疑点锁定」「极轨终结：罪业清偿」的技能等级提升1级。 |
| 共鸣 6：光明/白昼 | 带有「追缉许可」的敌人相属性异能伤害抗性降低10%。 |
