## 技能

早雾是咒属性支援角色，能以「一口吞食」与「千钧隆重的饕餮宴」牵引并控制敌人，同时依据自身的基础攻击力提升全队攻击力。她的被动技能会在目标处于「浮空」或「压制」后降低敌人防御力，并提高处于「浊燃」状态的目标所受到的持续伤害。

| 栏位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻击 | 鬼郎丸头锤、猛撞、摄食模式、下咽、极限反击：恶作剧 | 「猛撞」最多可进行五段咒属性攻击，「下咽」为空中下坠攻击，在极限闪避后施放「极限反击：恶作剧」可进行反击并降低「倾陷值」。长按会启动「摄食模式」，在处于「饥饿」状态时牵引附近目标并吞食弱小敌人，直到变为「饱食」。 |
| 技能 | 一口吞食、打嗝、噬重 | 点按施放「打嗝」，牵引附近敌人后使鬼郎丸膨胀并击倒敌人。长按施放「噬重」，牵引附近敌人并吞噬区域内的重力使目标浮空，但此效果对强力敌人无效。 |
| 极轨终结 | 千钧隆重的饕餮宴 | 鬼郎丸从上方吐出「重力沼液」造成六段范围咒属性伤害，以强大重力压制敌人并使处于「压制」的敌人无法移动（对 BOSS 无效）。同时依据早雾的基础攻击力提升除早雾以外的全队攻击力。 |
| 支援技能 | 砸扁你！ | 将变大的鬼郎丸砸向目标，对范围内造成一次咒属性伤害。 |
| 被动 1 | 可以吃吗？ | 提供「浊燃」强化，依目标身上持续伤害效果的种类数量，提高处于「浊燃」状态的目标所受到的持续伤害，设有上限。 |
| 被动 2 | 鬼把戏 | 早雾对敌人施加「浮空」或「压制」后，降低敌人的防御力。 |

## 觉醒

每取得一个重复角色可任选一项觉醒解锁；觉醒数达 3 与 6 时解锁共鸣。

| 觉醒 | 效果 |
| --- | --- |
| 弥散性的朦白 | 「极轨终结：千钧隆重的饕餮宴」造成的无法移动效果持续时间延长至6秒。 |
| 暌离性的轻巧 | 「极轨终结：千钧隆重的饕餮宴」对于浮空的敌人额外造成伤害，额外伤害量随目标质量提升而提升，最大600%*攻击力。 |
| 黏附性的啮合 | 基于全队角色击败的敌人数量，在之后的15秒内提升「变轨技能：一口吞食」和「极轨终结：千钧隆重的饕餮宴」的伤害。每击败1名敌人，提升6%的伤害，累计最大提升60%，此效果脱战清空。 |
| 祈愿性的依归 | 释放「极轨终结：千钧隆重的饕餮宴」后，基于早雾基础攻击力的30%，提升全队角色（不包括早雾）的攻击力，持续20秒。 |
| 失觉性的崩落 | 「变轨技能：一口吞食」成功使目标浮空时，「极轨终结：千钧隆重的饕餮宴」立即蓄满终结能量，并清空冷却时间。 |
| 溶解性的暴食 | 鬼郎丸在「摄食模式」下，最多可吞噬并同时消化3个目标，每个目标独立计算消化时间。 |
| 共鸣 3：不穷食欲 | 「普通攻击：鬼郎丸头锤」、「变轨技能：一口吞食」、「极轨终结：千钧隆重的饕餮宴」的技能等级提升1级。 |
| 共鸣 6：薄雾通彻 | 目标每带有1个负面效果，早雾对其造成的伤害提升3%，累计最大提升12%。 |
