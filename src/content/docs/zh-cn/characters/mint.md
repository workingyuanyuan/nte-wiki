## 技能

薄荷是一名驻场灵属性攻击角色，能衔接五段连击、消耗耐力持续旋转的「龙卷风」、突进攻击以及多段范围斩击。在场期间她会获得额外防御力与抗打断能力，且「创生」强化能扩大「创生花」的伤害范围。

| 栏位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻击 | 满分收容术、天降正义法、焦糖脆片、龙卷风 | 最多可进行五段连续灵属性攻击，并可在空中施放下落攻击「天降正义法」。长按普通攻击会触发「龙卷风」，持续旋转对周围造成灵属性伤害并消耗耐力。触发「极限闪避」后，「焦糖脆片」会攻击范围内敌人造成灵属性伤害并削减「倾陷值」。 |
| 技能 | 奥义·超级连风爪 | 向前突进后返回起始位置，对路径上的敌人造成两段范围灵属性伤害。 |
| 极轨终结 | 奥义·霹雳疾风斩 | 将风之力汇聚于双刃，造成多段范围灵属性伤害，并以造成高额范围灵属性伤害的终结一击收尾。 |
| 支援技能 | 奥义·无敌飓风刃 | 蓄力并跃向空中发动贯穿攻击，造成一段范围灵属性伤害。 |
| 被动 1 | 变身！超级薄荷！ | 「创生」强化会在命中时扩大「创生花」的伤害范围。 |
| 被动 2 | 收工！宾果时间！ | 薄荷留在场上时，提升自身的防御力与抗打断能力。 |

## 觉醒

每取得一个重复角色可任选一项觉醒解锁；觉醒数达 3 与 6 时解锁共鸣。

| 觉醒 | 效果 |
| --- | --- |
| 特遣行动 | 「极限反击：焦糖脆片」命中敌人时可重置「变轨技能：奥义·超级连风爪」的冷却时间，该效果每3秒可触发一次。 |
| 二次补考 | 「变轨技能：奥义·超级连风爪」的伤害提升40%。 |
| 全勤奖金 | 角色对敌人触发「创生」或「覆纹」后，使得薄荷自身攻击力提升15%，该效果持续15秒。 |
| 午休时间 | 薄荷对仅存在的单个敌人造成伤害后，使得自身的暴击率提升12%。 |
| 第一直觉 | 薄荷在成功释放「变轨技能：奥义·超级连风爪」后，使得自身的暴击伤害提升25%，该效果可持续6秒。 |
| 精英队员 | 薄荷对生命值低于40%的目标造成的伤害额外增加15%。 |
| 共鸣 3：薄荷波波茶 | 「普通攻击：满分收容术」「变轨技能：奥义·超级连风爪」「极轨终结：奥义· 霹雳疾风斩」的技能等级提升1级。 |
| 共鸣 6：蓬绒绒慕斯 | 成功释放「变轨技能：奥义·超级连风爪」后，薄荷额外获得2点环合值。 |
