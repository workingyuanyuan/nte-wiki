## 技能

海月通过 Cadenza Aria 进入 Cadenza 状态，并在 Staccato 中骑乘水母定期触发水母爆裂，一边累积 Crescendo 攻击力层数、一边以 Canzon Chorus 聚拢敌人，并在 Nova 结束后造成额外魂属性伤害。

| 栏位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻击 | Cappella, Legato, Staccato, Portamento, Critical Riposte: Syncopation | Legato 最多可进行四段魂属性攻击。移动时长按闪避可触发 Staccato 骑乘水母，定期发射水母爆裂直至耐力不足，其 Critical Riposte 可发射四发爆裂。Portamento 可于空中发动下落攻击；Critical Riposte: Syncopation 则在 Critical Dodge 后反击并削减 Break。 |
| 技能 | Cadenza Aria | 造成一段范围魂属性伤害并进入 Cadenza 状态。 |
| 极轨终结 | Canzon Chorus | 聚集附近水母，造成六段范围魂属性伤害并小幅牵引目标。 |
| 支援技能 | Dissonance | 指挥水母发动攻击，命中时造成一段范围魂属性伤害。 |
| 被动 1 | Harmonics | Nova Enhancement：目标的 Nova 状态结束后，对其造成三段魂属性伤害。 |
| 被动 2 | Crescendo | 水母爆裂命中目标时提升海月的攻击力，最多叠加十层。 |

## 觉醒

每取得一个重复角色可任选一项觉醒解锁；觉醒数达 3 与 6 时解锁共鸣。

| 觉醒 | 效果 |
| --- | --- |
| 未来序曲 | 处于「华彩」状态时，海月的暴击率提高15%。 |
| 一支特别的歌 | 成功进行极限闪避或释放「援护技：不协和音」后，海月将进入持续5秒的「华彩」状态。如已处于该状态，则其持续时间在原有基础上延长5秒。「华彩」状态最多可持续12秒。 |
| 三重奏的休止符 | 处于「华彩」状态时，海月释放「极轨终结：众声轮唱」所造成的伤害提高20%。 |
| 五线谱的空白处 | 在释放「普通攻击：顿音」时，海月的防御力增加20%。 |
| 一支平凡的歌 | 「极轨终结：众声轮唱」暴击率提高15%。 |
| 往日赋格 | 「渐强」效果的最大叠加层数提升至20层。释放「变轨攻击：华彩唱段」后，立即获得10层「渐强」效果。 |
| 共鸣 3：万物于此和声 | 「普通攻击：清唱」「变轨技能：华彩唱段」「极轨终结：众声轮唱」的技能等级提升1级。 |
| 共鸣 6：与你一同奏响 | 进入「华彩」状态或「华彩」状态持续时间延长时，全队的魂属性异能伤害提升8%，持续15秒，重复获得刷新持续时间。 |
