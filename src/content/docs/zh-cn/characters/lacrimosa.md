## 技能

安魂曲在「茄汁金属乐」与「茄汁打击乐」形态之间切换，以叠加「噩梦」并改变「工作日最终审判」的攻击模式。通过「恶魔的灵感」，她也能习得敌方招式，短暂以「恶魔的礼物」取代「起床气加载中」。

| 栏位 | 技能 | 效果说明 |
| --- | --- | --- |
| 普通攻击 | 酸甜口味的制裁、茄汁金属乐、茄汁打击乐、风味变奏、恶魔的灵感、番茄座流星雨、fff休止符、噩梦 | 通过「风味变奏」在五段暗属性连段的「茄汁金属乐」与「茄汁打击乐」之间切换，并决定「工作日最终审判」的形态。包含下落攻击「番茄座流星雨」、「极限闪避」反击技「fff休止符」，以及瞄准模式下的「恶魔的灵感」，用以习得敌方招式取代「起床气加载中」。命中可叠加「噩梦」，最多十层。 |
| 技能 | 起床气加载中、恶魔的礼物 | 「起床气加载中」投掷造物造成范围暗属性伤害、施加「噩梦」，并可衔接「茄汁金属乐」或「茄汁打击乐」的第五段攻击。通过「恶魔的灵感」替换后，变轨技能「恶魔的礼物」会复制并施放习得的敌方技能，同时提供目标部分攻击力。 |
| 极轨终结 | 工作日最终审判 | 依当前使用的普通攻击流派变化，在「茄汁金属乐」下操控卡车造成十段暗属性伤害，或在「茄汁打击乐」下拆解汽车造成五段暗属性伤害，并对范围内所有目标施加「噩梦」。 |
| 支援技能 | 紧急唤醒 | 操纵「异能造物」造成一段范围暗属性伤害。 |
| 被动 1 | 番茄酱盛宴 | 「失谐」强化会在「失谐」对处于「倾陷」状态的目标触发时，造成基于攻击力的额外伤害。 |
| 被动 2 | 就要自然醒 | 在技能冷却期间使用「茄汁金属乐」或「茄汁打击乐」五次后，获得一次额外施放「起床气加载中」的机会，每次冷却期间仅触发一次。 |

## 觉醒

每取得一个重复角色可任选一项觉醒解锁；觉醒数达 3 与 6 时解锁共鸣。

| 觉醒 | 效果 |
| --- | --- |
| 不加班之宽赦 | 「噩梦」的伤害倍率提升，当前技能等级下提升至{0}%。 |
| 闹钟响彻四方 | 安魂曲通过「援护技」入场时，自身造成的伤害提升15%，提升效果持续15秒。 |
| 冰淇淋在烈阳中融化 | 第5段「普通攻击：茄汁金属乐」或「普通攻击：茄汁打击乐」命中目标时，一次性结算目标当前已累积的全部「噩梦」效果。 |
| 威严赫赫番茄酱大王 | 「噩梦」状态的持续时间延长至6秒。 |
| 强化玻璃径受审判 | 安魂曲造成「噩梦」伤害时，额外削减目标生命值上限，削减量为本次「噩梦」伤害值的200%。每3秒，安魂曲基于期间造成的「噩梦」伤害回复自身生命值，回复量为期间「噩梦」总伤害值的1.5%。目标受到治疗时，不再移除「噩梦」层数。 |
| 早起出勤之咏 | 安魂曲释放「变轨技能：恶魔的礼物」后的5秒内，从任意可触发「黯星」「浊燃」「失谐」三种异能环合的角色切换至安魂曲时，无需累积「环合值」，即可自动释放「援护技」，并触发相应环合。该效果每5秒最多触发1次。 |
| 共鸣 3：困倦的火焰在心中燃烧 | 「普通攻击：酸甜口味的制裁」「变轨技能：起床气加载中」「变轨技能：恶魔的礼物」「极轨终结：工作日最终审判」的技能等级提升1级。以蝙蝠形态飞行时，耐力消耗降低至85%。 |
| 共鸣 6：美梦的时刻即将来临 | 安魂曲造成的伤害，无视目标20%防御力。以蝙蝠形态飞行时，耐力消耗降低至70%。 |

## 机制细节

- 「风味变奏」以瞄准键施放：切换到「茄汁打击乐」时安魂曲会后跳拉开距离，切换到「茄汁金属乐」时则会突进拉近距离。[^1]
- 按下瞄准键后形态不会立刻切换，要等下方图示变化才算切换完成；在「轨外之境」中，未遇敌时无法切换形态。[^2]
- 「茄汁金属乐」的攻击硬直比「茄汁打击乐」短。[^3]
- 「茄汁金属乐」打满五段约需 3.33 秒；「茄汁打击乐」打完前四段约需 1.5 秒。[^4]
- 近战普攻的爆炸伤害在实战中并不稳定出现。[^4]
- 「茄汁打击乐」第四段只要擡手成功，即使马上闪避，后续攻击也会自动打完。[^5]
- 两种形态的前四段普通攻击都共有 10 段伤害；第五段在「茄汁金属乐」为 4 段，在「茄汁打击乐」只有 1 段。[^6]
- 两种形态的普通攻击环合值皆为 32；叫我棉被与零号攻略组给出「茄汁打击乐」一整套普通攻击的环合值为 36，且「茄汁打击乐」获得的环合值多于「茄汁金属乐」。终结能量的获取也是「茄汁打击乐」较多。[^7]
- 每造成 1 段伤害就为敌人附加一层持续 3 秒的「噩梦」，每层每秒造成 1 次伤害。[^8]
- 0 觉醒时，正常打法不会超过十层的上限。[^9]
- 按伤害计算，「噩梦」约占安魂曲总伤害的三分之一。[^10]
- 敌人每受到一次治疗，就移除安魂曲挂上的一层「噩梦」。[^11]解锁觉醒「强化玻璃径受审判」后，治疗不再移除层数。
- 「噩梦」在[早雾](/zh-cn/characters/sakiri/)的「浊燃」强化中算一种持续伤害，「浊燃」本身也算一种，因此处于「浊燃」且带有「噩梦」的目标受到的持续伤害提升 50%，属独立乘区。[^12]
- [阿德勒](/zh-cn/characters/adler/)自身的持续伤害再算一种，可把这项加成提升到 75%。[^13]
- 以「恶魔的灵感」习得招式时，长按普通攻击进入瞄准，在敌人身上出现蝙蝠标记时松开。[^14]
- 2026-05-28 时可习得的敌方招式共 46 种。[^15]
- 成功习得过一次的招式会永久记住，之后可在角色界面选择「恶魔的礼物」固定使用的招式，不必每次在战斗中重新习得。[^16]
- 在可习得的招式中，[黑之书](/zh-cn/anomalies/black-tome/)的倍率最高，但后摇较长。[^17]
- 以黑之书招式施放的「恶魔的礼物」倍率为 1,885%。[^18]
- 通过「恶魔的礼物」施放的习得招式同样受技能等级影响。[^19]
- 实测中，不论招式来自哪个敌人，由安魂曲施放时都造成暗属性伤害。[^20]
- 施放「起床气加载中」后可直接接第五段普攻的效果保留很久，中间接极轨终结、下落攻击、闪避或走两步后仍能接上；目前实测只有退出战斗、切人离场或超过一两秒没出普攻时才会失效。[^21]
- 「就要自然醒」累计的五次普攻，在中途切人后需重新累积。[^22]
- 在大世界中长按闪避键，安魂曲可原地起飞。[^23]
- 「强化玻璃径受审判」削减生命值上限后，敌人的当前生命值也会按比例下降。[^24]
- 「最后一朵玫瑰」的层数每次叠加都会刷新持续时间，这点与「噩梦」不同。[^25]
