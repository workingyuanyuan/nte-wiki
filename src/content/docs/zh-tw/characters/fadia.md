## 技能

法帝婭在生命值高於 1 時會將隊友受到的部分傷害轉移至自身，降至 1 生命值時則改為分攤承受的傷害。她的技能會連結一名敵人以分攤她受到的傷害，失去足夠生命值時可為極軌終結充能並強化其威力。

| 欄位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻擊 | 話語中斷的否定、觀眾目擊的祭獻、擬造墜落的輕蔑、極限反擊：迴避條件作用 | 「話語中斷的否定」最多可攻擊五次，「擬造墜落的輕蔑」從空中下墜攻擊，極限閃避後施放「極限反擊：迴避條件作用」可進行反擊並降低「傾陷值」。「觀眾目擊的祭獻」在法帝婭生命值高於 1 時將隊友受到的傷害轉移至自身，在生命值為 1 時分攤受到的傷害。 |
| 技能 | 存在證明的體驗 | 造成範圍魂屬性傷害，並對範圍內最大生命值最高的敵人施加「破滅體驗」。生效期間，該目標會分攤法帝婭受到的部分傷害，直到效果結束、達到「分攤傷害」上限，或雙方脫離戰鬥。 |
| 極軌終結 | 痛苦讓位於狂喜 | 進入「敵神者」狀態，造成六段「心靈傷害」並回復生命值；再次施放「話語中斷的否定」最多可進行五次「心靈傷害」追加攻擊。生命值損失達到「破滅閾值」時會補滿終結能量並提升其傷害與治療量，直到「敵神者」狀態結束或被其他動作中斷。 |
| 支援技能 | 脫格者的嘲弄 | 揮動十字盾牌，對範圍內造成一次魂屬性傷害。 |
| 被動 1 | 罪感熔爐 | 提供「黯星」強化，當「黯星」結束時讓全體隊友吸取目標的最大生命值，上限取決於法帝婭的基礎最大生命值，並在脫離戰鬥後恢復雙方數值。 |
| 被動 2 | 拒斥與豪掠 | 法帝婭在隊伍中時，提升全隊的最大生命值。 |

## 覺醒

每取得一個重複角色可任選一項覺醒解鎖；覺醒數達 3 與 6 時解鎖共鳴。

| 覺醒 | 效果 |
| --- | --- |
| 欲蓋彌彰的聖潔 | 法帝婭的傷害分攤比例提升至75%。 |
| 無可否認的本能 | 敵方單位通過「破滅體驗」承受的傷害比例提升至600%，上限提升至法帝婭生命上限的25%。當「破滅體驗」被移除時，立刻造成敵方單位已承受傷害與「破滅體驗」造成傷害上限差值的傷害。 |
| 詛咒祝福之人 | 進入戰鬥狀態後，法帝婭提升固有生命上限的30%，離開戰鬥狀態後失去提升的生命上限。 |
| 僭越禁忌之人 | 「敵神者」狀態下法帝婭的回復比例提升至30%生命上限，在已損失生命值大於等於「破滅閾值」時回復比例提升至60%生命上限。 |
| 回溯死亡之人 | 「敵神者」狀態下法帝婭的暴擊率提升50%。 |
| 愛與死的使徒 | 「變軌技能：存在證明的體驗」可為範圍內最多10個目標施加「破滅體驗」，每個目標單獨計算「破滅體驗」持續時間及通過「破滅體驗」所承受的傷害上限。 |
| 共鳴 3：不敬的「聖潔」之人 | 「普通攻擊：話語中斷的否定」「變軌技能：存在證明的體驗」「極軌終結：痛苦讓位於狂喜」的技能等級提升1級。 |
| 共鳴 6：歸一的「聖潔」之人 | 當法帝婭在隊伍中時，全隊獲得10%最大生命值提升。 |

共鳴 6 的英文遊戲文字寫作攻擊力 10%，中文、日文與韓文遊戲文字寫作最大生命值 10%。
