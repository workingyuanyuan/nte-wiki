## 取得方式

| 項目 | 內容 |
| --- | --- |
| 棋盤 | 「斯卡布羅集市」的限定棋盤「破曉前」 |
| 首次開放 | 2026-07-08 維護後至 2026-07-29 05:59 (UTC+8) |
| 返場 | 2026-11-11 維護後至 2026-12-02 05:59 (UTC+8) |
| 開放條件 | 完成正篇任務「序章 - 全新的目的地 - 前往『伊波恩古董店』」 |
| 同棋盤 A 級角色 | [薄荷](/zh-tw/characters/mint/)、[埃德嘉](/zh-tw/characters/edgar/)、[阿德勒](/zh-tw/characters/adler/) |
| 擲骰獎勵 | 滑翔翼造型「蔽日之影」、Blizzard-V4 塗裝「赤炎龍影」、時裝「地海高校生」：累計擲骰 50、120、200 次後於「毅心禮遇」介面領取，也可能提前擲到對應格子 |

擲骰次數依棋盤名稱分開計算：首次開放期間在「毅心禮遇」累積的進度已保留至本次返場。

棋盤機制說明：[棋盤與弧盤研募](/zh-tw/systems/boards/)。

## 技能

真紅透過普通攻擊、「高速突破」與「破襲戰術」累積「桀驁鬥志」，再以「沸血赤紅」消耗進入「升騰之赤」狀態。在此狀態下，她會產生「清醒邊緣」來施放「天降赤鋒」，並銜接「赤紅的處決」與「處決的龍炎」。

| 欄位 | 技能 | 效果說明 |
| --- | --- | --- |
| 普通攻擊 | 特種格鬥術、空箭、特種格鬥術—變式、極限反擊：瞬時決勝、驚駭急襲、落錘、驚駭急襲—輕蔑、極限反擊：不容喘息 | 進行最多五段光屬性攻擊、下落攻擊、長按攻擊與「極限反擊」來累積「桀驁鬥志」。在「升騰之赤」期間，「驚駭急襲」、「落錘」、「驚駭急襲—輕蔑」與「極限反擊：不容喘息」會取代上述招式並改為獲得「清醒邊緣」，且在「威懾凝視」效果下造成額外傷害。 |
| 技能 | 高速突破、天降赤鋒 | 「高速突破」朝目標衝刺造成多段光屬性傷害並獲得「桀驁鬥志」。在「升騰之赤」期間會變為「天降赤鋒」，消耗全部「清醒邊緣」躍至目標上方發動下劈爪擊，每次狀態期間最多可施放五次。 |
| 極軌終結 | 沸血赤紅、赤紅的處決、處決的龍炎 | 消耗全部「桀驁鬥志」進入「升騰之赤」，提升傷害、抗打斷能力與移動能力並替換一般技能。隨著狀態接近結束，依據「天降赤鋒」使用次數施放最多三次「赤紅的處決」，隨後再次按下可施放「處決的龍炎」。 |
| 支援技能 | 破襲戰術 | 發動強力的膝擊，造成一段光屬性傷害並獲得「桀驁鬥志」。 |
| 被動 1 | 獨行 | 提供「盈蓄」強化，當場上角色獲得極軌終結能量時，賦予後台隊友對應的「盈蓄」。當真紅於「盈蓄」狀態下在場上時，每次觸發會造成範圍傷害並疊加攻擊力增益，最多十層。 |
| 被動 2 | 逆鱗 | 提高對非 Boss 敵人造成的極軌終結傷害。 |

## 覺醒

每取得一個重複角色可任選一項覺醒解鎖；覺醒數達 3 與 6 時解鎖共鳴。

| 覺醒 | 效果 |
| --- | --- |
| 暴雨滂沱的小巷 | 真紅造成的傷害無視目標12%防禦。 |
| 凌晨的訓練場 | 「極軌終結」命中後，真紅使目標光屬性抗性降低10%，持續20秒。 |
| 夕陽下的海灘 | 切換角色不會移除「威懾凝視」，真紅在後台時也會增長凝視層數。 |
| 雪飄落的坡道 | 「威懾凝視」層數上限提升至16層，「威懾凝視」達到16層時觸發的「即瞬猛襲」可獲得「承軌反擊」或「極限反擊」觸發的「即瞬猛襲」所附帶的額外效果，即強制擊退目標並使其短暫癱瘓（對Boss不生效），並對目標再造成一次相當於20%「即瞬猛襲」的傷害。 |
| 歡聲笑語的客廳 | 「升騰之赤」持續期間，真紅防禦力提升50%，抗打斷係數提升50%，並在釋放「變軌技能：天降赤鋒」後獲得相當於自身基礎攻擊力*300%的生命值回覆。 |
| 赤龍的藏寶地 | 真紅「變軌技能：天降赤鋒」、「極軌終結：赤紅的處決」和「極軌終結：處決的龍炎」傷害的倍率提升30%，且「變軌技能：天降赤鋒」和「極軌終結：赤紅的處決」能吸附範圍目標。 |
| 共鳴 3：蛻變的決心 | 「普通攻擊」、「變軌技能」和「極軌終結」的技能等級提升1級。「升騰之赤」持續期間，真紅造成的傷害額外提升30%。 |
| 共鳴 6：赤紅的英雄 | 真紅暴擊率提升10%，造成的傷害無視目標15%防禦。 |
