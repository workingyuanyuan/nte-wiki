## 技能

翳透過「拘管格鬥術」與「潛影追擊」在每個目標身上附著最多三個「獸牙影刺」影刺。他的技能會啟動「尾追」使「獸牙影刺」持續存在並進入「齧逐潛影」以在接觸時觸發額外攻擊，而「群犬吠形」則提供傷害強化並附加控制效果。

| 欄位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻擊 | 拘管格鬥術、就地執管、獸牙影刺、極限反擊：頓筆簽字 | 「拘管格鬥術」最多可進行五段相屬性攻擊，並分裂出追蹤目標的「獸牙影刺」影刺，每個目標最多附著三個，造成一段相屬性傷害後消失。另包含空中下落攻擊「就地執管」與「極限閃避」後的反擊「極限反擊：頓筆簽字」。 |
| 技能 | 潛影追擊、尾追、齧逐潛影 | 進入「尾追」狀態，造成六段範圍相屬性傷害，對每個目標分裂三個「獸牙影刺」，並進入「齧逐潛影」。「尾追」會使「獸牙影刺」在命中時不會消失。「齧逐潛影」提供潛行移動，接觸敵人時觸發額外「獸牙影刺」攻擊，並在結束時造成範圍傷害。 |
| 極軌終結 | 群犬吠形 | 將影子向外擴散造成一段範圍相屬性傷害，隨後收攏造成三段範圍傷害。施放後提高「獸牙影刺」傷害（包含「齧逐潛影」的碰撞傷害），並在每次攻擊時施加控制效果。 |
| 支援技能 | 緝令 | 指揮影子如警犬般撕咬目標，造成一段範圍相屬性傷害。 |
| 被動 1 | 現場控制 | 施加「延滯」強化，當「獸牙影刺」鎖定處於「延滯」狀態的目標時，額外施加一層「延滯」。 |
| 被動 2 | 捉拿歸案 | 施放「群犬吠形」後，提高「獸牙影刺」的傷害，包含「齧逐潛影」模式下的碰撞傷害。 |

## 覺醒

每取得一個重複角色可任選一項覺醒解鎖；覺醒數達 3 與 6 時解鎖共鳴。

| 覺醒 | 效果 |
| --- | --- |
| 排斥變節的規程 | 「獸牙影刺」自動攻擊的傷害倍率提升60%。 |
| 秩序井然的待辦 | 翳在釋放「變軌技能：潛影追擊」後，使自身的暴擊率提升10%，抗打斷能力提升50%，持續15秒。 |
| 異類處理的草案 | 翳對已被「獸牙影刺」鎖定的目標造成的傷害提升4%。 如果場上僅有一個被「獸牙影刺」鎖定的目標，翳對其造成的傷害額外提升4%。 |
| 劃定常規的決議 | 「尾追」狀態的持續時間延長至12秒。目標每被附著1秒，受到的附著傷害提高2%，最高提升至40%。 |
| 社會適應的重任 | 目標每被1個「獸牙影刺」鎖定，質量提升50點，移動速度降低20%。 |
| 無謂形貌的立身 | 「齧逐潛影」模式下，觸碰已被「獸牙影刺」鎖定的敵方目標，使「獸牙影刺」造成的額外傷害倍率提升20%。 |
| 共鳴 3：職場生存守則 | 「普通攻擊：拘管格鬥術」「變軌技能：潛影追擊」「極軌終結：群犬吠形」的技能等級提升1級。 |
| 共鳴 6：工作模範準則 | 每個「獸牙影刺」降低其鎖定目標2%的相異能屬性抗性，最多降低6%。 |
