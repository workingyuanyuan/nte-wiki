官方介紹將卡厄斯介紹為 E.T.D 六隊的核心戰鬥力，「使命必達的執行者」。

Chaos 同時也是英文版中「暗」屬性的名稱；本頁面介紹的是角色卡厄斯。

## 取得方式

| 項目 | 內容 |
| --- | --- |
| 棋盤 | 「斯卡布羅集市」的限定棋盤「無歸路」 |
| 首次開放 | 2026-06-24 維護後至 2026-07-08 05:59 (UTC+8) |
| 開放條件 | 完成正篇任務「序章 - 全新的目的地 - 前往『伊波恩古董店』」 |

| 擲骰獎勵 | 滑翔翼造型「天際獵手」、Novis ST-X 950 塗裝「獵犬奔襲」、時裝「放晴日」：累計擲骰 50、120、200 次後於「沉霧禮遇」介面領取，也可能提前擲到對應格子 |

Prydwen 與 Game8 列出「無歸路」與弧盤「眾人追尋之物」將在 1.5 版下半期返場，自 2026-12-02 起；Game8 寫明結束時間為 2026-12-23 05:59 (UTC+8)。

棋盤機制說明：[棋盤與弧盤研募](/zh-tw/systems/boards/)。

## 技能

卡厄斯透過攻擊累積「罪狀」，並在極軌終結的「惡名往復」狀態期間迅速生成「罪狀」，隨後以「裁斷」消耗滿層的「罪狀」造成高額「清算傷害」，同時施加「追緝許可」並強化「延滯」。

| 欄位 | 技能 | 效果說明 |
| --- | --- | --- |
| 普通攻擊 | 追獵、裁斷、破局、直覺/本能 | 「追獵」進行最多五段相屬性傷害攻擊。長按普通攻擊可觸發「裁斷」，消耗滿層「罪狀」造成第二段高額「清算傷害」，未滿層時則造成一段攻擊。「破局」於空中下落造成依高度加成的範圍相屬性傷害，而在「極限閃避」後施放「追獵」會觸發「直覺/本能」，削減「傾陷值」。 |
| 技能 | 疑點鎖定 | 向前射擊並召喚獵犬來回撲咬目標兩次，命中時對最多兩名敵人施加「追緝許可」，並提高對帶有「追緝許可」目標造成的傷害。 |
| 極軌終結 | 罪業清償 | 召喚獵犬壓制附近敵人，對範圍內所有敵人施加「追緝許可」並進入「惡名往復」。「惡名往復」啟動期間，「罪狀」會隨時間快速增加，使「裁斷」能更頻繁地施放並造成高額「清算傷害」。 |
| 支援技能 | 強襲 | 向上揮舞鐮刀，造成一段相屬性傷害。 |
| 被動 1 | 未遲到的正義 | 「延滯」強化會在「延滯」結束時對目標造成依攻擊力加成的相屬性傷害，依超過「延滯」基礎持續時間的經過時間提高總傷害，並在重新施加時重置「延滯」的持續時間。 |
| 被動 2 | 重點關注！ | 提高攻擊帶有「追緝許可」敵人時獲得的傷害加成。 |

## 覺醒

每取得一個重複角色可任選一項覺醒解鎖；覺醒數達 3 與 6 時解鎖共鳴。

| 覺醒 | 效果 |
| --- | --- |
| 灼見 | 卡厄斯在攻擊帶有「追緝許可」的敵人時，能夠額外獲取40%的「罪狀」。 |
| 罪名/惡行 | 卡厄斯在攻擊帶有「追緝許可」的敵人時，無視目標20%防禦力。 |
| 煙火 | 卡厄斯使用「極軌終結：罪業清償」後，暴擊傷害提升30%，持續20秒。重複觸發刷新持續時間。 |
| 海潮漫延 | 卡厄斯擊敗帶有「追緝許可」的目標時，該「追緝許可」會傳遞至附近未被標記的目標，重新計算持續時間。 |
| 獨見虛空 | 當場上僅剩1名帶有「追緝許可」的目標時，卡厄斯對其造成的傷害提升20%。 |
| 偽原點 | 卡厄斯使用「極軌終結：罪業清償」後，立即將「罪狀」補充至上限。 |
| 共鳴 3：正義/正確 | 「普通攻擊：追獵」「變軌技能：疑點鎖定」「極軌終結：罪業清償」的技能等級提升1級。 |
| 共鳴 6：光明/白晝 | 帶有「追緝許可」的敵人相屬性異能傷害抗性降低10%。 |
