官方介紹將卡厄斯介紹為 E.T.D 六隊的核心戰鬥力，「使命必達的執行者」。

Chaos 同時也是英文版中「暗」屬性的名稱；本頁面介紹的是角色卡厄斯。

## 取得方式

| 項目 | 內容 |
| --- | --- |
| 棋盤 | 「斯卡布羅集市」的限定棋盤「無歸路」 |
| 首次開放 | 2026-06-24 維護後至 2026-07-08 05:59 (UTC+8) |
| 開放條件 | 完成正篇任務「序章 - 全新的目的地 - 前往『伊波恩古董店』」 |
| 同棋盤 A 級角色 | [哈尼婭](/zh-tw/characters/haniel/)、[海月](/zh-tw/characters/aurelia/)、[翳](/zh-tw/characters/skia/) |
| 擲骰獎勵 | 滑翔翼造型「天際獵手」、Novis ST-X 950 塗裝「獵犬奔襲」、時裝「放晴日」：累計擲骰 50、120、200 次後於「沉霧禮遇」介面領取，也可能提前擲到對應格子 |

Prydwen 與 Game8 列出「無歸路」與弧盤「眾人追尋之物」將在 1.5 版下半期返場，自 2026-12-02 起；Game8 寫明結束時間為 2026-12-23 05:59 (UTC+8)。

棋盤機制說明：[棋盤與弧盤研募](/zh-tw/systems/boards/)。

## 技能

卡厄斯透過攻擊累積 Crime，並在極軌終結的 Dread Echo 狀態期間迅速生成 Crime，隨後以 Final Verdict 消耗滿層的 Crime 造成高額 Settlement DMG，同時施加 Warrant 並強化 Remora。

| 欄位 | 技能 | 效果說明 |
| --- | --- | --- |
| 普通攻擊 | Pursuit, Final Verdict, Overturn, Intuition / Instinct | Pursuit 進行最多五段相屬性傷害攻擊。長按普通攻擊可觸發 Final Verdict，消耗滿層 Crime 造成第二段高額 Settlement DMG，未滿層時則造成一段攻擊。Overturn 於空中下落造成依高度加成的範圍相屬性傷害，而在 Critical Dodge 後施放 Pursuit 會觸發 Intuition / Instinct，削減 Break。 |
| 技能 | Doubtmark | 向前射擊並召喚獵犬來回撲咬目標兩次，命中時對最多兩名敵人施加 Warrant，並提高對帶有 Warrant 目標造成的傷害。 |
| 極軌終結 | Retribution | 召喚獵犬壓制附近敵人，對範圍內所有敵人施加 Warrant 並進入 Dread Echo。Dread Echo 啟動期間，Crime 會隨時間快速增加，使 Final Verdict 能更頻繁地施放並造成高額 Settlement DMG。 |
| 支援技能 | Onslaught | 向上揮舞鐮刀，造成一段相屬性傷害。 |
| 被動 1 | Justice in Time | Remora Enhancement 會在 Remora 結束時對目標造成依攻擊力加成的相屬性傷害，依超過 Remora 基礎持續時間的經過時間提高總傷害，並在重新施加時重置 Remora 的持續時間。 |
| 被動 2 | Prime Target | 提高攻擊帶有 Warrant 敵人時獲得的傷害加成。 |
