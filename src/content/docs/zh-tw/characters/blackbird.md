## 角色資料

| 項目 | 內容 |
| --- | --- |
| 等級 | S 級，限定 |
| 屬性 | 魂 |
| 弧盤類型 | 氣態 (Gas) |
| 加入版本 | 1.4 版，2026-09-30 |
| 配音員 | 中文：井琉；英文：Xanthe Huynh；日文：能登麻美子；韓文：문유정 |

官方介紹說她居住在幽暗林中的「魔女之家」。當地人都稱她為「魔女」，她寡言少語，並擁有神秘而強大的占卜能力。

## 取得方式

| 項目 | 內容 |
| --- | --- |
| 棋盤 | 位於「斯卡布羅集市」的限定棋盤「預言終幕時」 |
| 首次開放 | 2026-09-30 維護後至 2026-10-21 05:59 (UTC+8) |
| 開放條件 | 完成正篇任務「序章 - 全新的目的地 - 前往『伊波恩古董店』」 |
| 同棋盤 A 級角色 | [薄荷](/zh-tw/characters/mint/)、[埃德嘉](/zh-tw/characters/edgar/)與[阿德勒](/zh-tw/characters/adler/) |
| 擲骰獎勵 | 滑翔翼造型「預兆鳥」、「舊時光」單車塗裝「夜色飛羽」、時裝「紅與黑」：累計擲骰 50、120、200 次可在「卜運禮遇」介面領取，也可能提前擲到對應格子獲得 |

棋盤機制詳見：[棋盤與弧盤研募](/zh-tw/systems/boards/)。

## 技能

黑羽透過累積「惡意」並對敵人施加「失樂羽」印記以觸發離場協同攻擊，接著施放「懇請眾魂安息」進入「救世的魔女」狀態消耗「惡意」施展強化攻擊，最後以「萬火歸一」收尾。

| 欄位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻擊 | 掠影、歸巢、頑疾、極限反擊：鳥類本能、祭火、予爾等之恩澤、賜眾生之福音、灼痕、極限反擊：生於災厄、祝禱 | 「掠影」、「歸巢」、「頑疾」與「鳥類本能」造成魂屬性傷害，並透過「祝禱」累積「惡意」。在「救世的魔女」狀態下，攻擊會替換為「祭火」、「予爾等之恩澤」、「賜眾生之福音」、「灼痕」與「生於災厄」，改為消耗「惡意」造成額外「惡意傷害」而非產生「惡意」。 |
| 技能 | 葬羽冥、渡世死焰 | 「葬羽冥」造成魂屬性傷害、獲得「惡意」並施加「失樂羽」，使隊友最多可觸發五次「失樂鳥」協同範圍攻擊。在「救世的魔女」狀態下，「祭火」第五段或「無悲」之後可啟動「渡世死焰」，蓄力造成魂屬性傷害並消耗「惡意」。 |
| 極軌終結 | 懇請眾魂安息、萬火歸一 | 「懇請眾魂安息」使黑羽變身為「救世的魔女」，獲得免疫受擊硬直與移動速度提升並提高全隊攻擊力；離場時持續時間會暫停計算。再次施放可觸發「萬火歸一」退出該狀態並造成高額魂屬性傷害。 |
| 支援技能 | 斷罪於我、唯餘慈悲 | 「斷罪於我」化身為「伶仃鳥」造成魂屬性傷害並獲得「惡意」。在「救世的魔女」狀態下則會變為「唯餘慈悲」，造成魂屬性傷害並在命中時消耗「惡意」。 |
| 被動 1 | 鶇歌 | 「浸染」強化提高「浸染」的傷害加成並延長其持續時間。「黯星」強化使「黯星」結束時依「黯星」期間實際受到的傷害造成額外精神傷害，接著再次施加一次「黯星」，且不會重複觸發此再施加效果。 |
| 被動 2 | 長路 | 黑羽施放「斷罪於我」時獲得 20 點「惡意」。 |

## 覺醒

每取得一個重複角色可任選一項覺醒解鎖；覺醒數達 3 與 6 時解鎖共鳴。

| 覺醒 | 效果 |
| --- | --- |
| 叛逃者 | 「救世的魔女」發動「極軌終結：萬火歸一」後可消耗所有「惡意」。 「變軌技能：渡世死焰」傷害的倍率提升150%。 |
| 漫遊記 | 「變軌技能：葬羽冥」傷害的倍率提升100%。 處於「救世的魔女」狀態時防禦提升20%；成功釋放「變軌技能：渡世死焰」後獲得相當於自身基礎攻擊力*400%的生命回覆。 |
| 失明症 | 黑羽消耗「惡意」造成傷害的倍率提升50%。 |
| 壞骨頭 | 黑羽發動「極軌終結：懇請眾魂安息」後，提升全隊攻擊力的持續時間延長至25秒，期間使全隊造成的傷害提升12%。 |
| 爛柯人 | 黑羽造成傷害時，使命中目標的魂、相、暗屬性傷害抗性降低8%，持續25秒。 |
| 死與生 | 黑羽發動「極軌終結：懇請眾魂安息」後，使自身魂屬性異能傷害提升25%，持續25秒。 黑羽未處於「救世的魔女」狀態下時，「失樂鳥」發動協同攻擊後，提供4點「惡意」。 |
| 共鳴 3：喚作謝罪的啟示 | 「普通攻擊：掠影」、「普通攻擊：祭火」、「變軌技能：葬羽冥」、「變軌技能：渡世死焰」、「極軌終結：懇請眾魂安息」和「極軌終結：萬火歸一」的技能等級提升1級。 「極軌終結：懇請眾魂安息」傷害的倍率提升100%，「極軌終結：萬火歸一」傷害的倍率提升50%。 黑羽發動「極軌終結：懇請眾魂安息」後，獲得20點「惡意」。 |
| 共鳴 6：聆聽群星的悼詞 | 黑羽處於隊伍中時，全隊的暴擊傷害提升30%。 |
