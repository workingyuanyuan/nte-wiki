## 取得方式

| 方式 | 說明 |
| --- | --- |
| 常駐棋盤 | 根據 Game8 與 Prydwen 的資料，常駐 S 級角色位於斯卡布羅集市的常駐棋盤 |
| 自選箱，1.2 版 | 向所有在 2026-08-19 05:59 (UTC+8) 前創建角色的玩家以信件發放「S 級常駐角色自選箱」 |

此自選箱可從六名角色中任選一名：早霧、白藏、哈索爾、法帝婭、達芙蒂爾或九原。棋盤機制說明見[棋盤與弧盤研募](/zh-tw/systems/boards/)。

## 技能

哈索爾透過技能、「極限反擊：零誤差行動」與「效率推進」被動累積「閃送之力」層數。施放極軌終結後進入「緊急派送」狀態，依據層數獲得攻擊力加成，並將「空中指令」強化為消耗層數進行高速連段的「輪轉打擊」。

| 欄位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻擊 | 高頻送達、壓軸派送、制高清算、極限反擊：零誤差行動 | 「高頻送達」最多可進行五段相屬性攻擊，「壓軸派送」從空中下墜攻擊，長按普通攻擊施放「制高清算」將敵人挑飛後下墜攻擊。極限閃避後觸發「極限反擊：零誤差行動」進行反擊，造成範圍相屬性傷害、降低「傾陷值」並獲得「閃送之力」。 |
| 技能 | 空中指令、輪轉打擊 | 「空中指令」斬擊前方敵人以獲得兩層「閃送之力」；長按可蓄力擴大相屬性範圍傷害並施加「滿星追蹤」，使敵人擊中隊友時賦予三層。處於「緊急派送」狀態時會變為「輪轉打擊」，消耗層數施展高速機車連段攻擊。 |
| 極軌終結 | 鐵騎速遞 | 召喚荊棘機車繞行並俯衝轟炸敵人，造成範圍相屬性傷害，進入「緊急派送」狀態。期間停止獲得「閃送之力」，將「空中指令」升級為「輪轉打擊」，提升移動速度並依據已儲存層數獲得攻擊力加成。切換角色會立即結束「緊急派送」。 |
| 支援技能 | 墜點標定 | 從空中發動攻擊並踢擊目標引發衝擊，造成兩段範圍相屬性傷害。 |
| 被動 1 | 延時預警 | 提供「延滯」強化，延長目標身上的「延滯」持續時間，並在攻擊受「延滯」影響的目標時提高暴擊率。 |
| 被動 2 | 效率推進 | 擊敗目標後獲得一層「閃送之力」。 |

## 覺醒

每取得一個重複角色可任選一項覺醒解鎖；覺醒數達 3 與 6 時解鎖共鳴。

| 覺醒 | 效果 |
| --- | --- |
| 精英快遞員 | 入戰後首次長按「變軌技能」，將直接獲得6層「閃送之力」。 |
| 荊棘支配 | 「優評鎖定」和「滿星追蹤」自然結束時，哈索爾同樣可獲得「閃送之力」。 |
| 一翼失衡 | 哈索爾對非Boss目標造成的傷害提升15%。 |
| 引擎共鳴 | 處於「緊急派送」狀態時，哈索爾每次成功釋放「變軌技能：輪轉打擊」，都會使下一次「變軌技能：輪轉打擊」的暴擊率提升25%，該效果將在本次「緊急派送」狀態結束後清除。 |
| 例行三明治 | 每獲得1層「閃送之力」，哈索爾對目標造成的傷害提升1%，該效果可疊加，最多提升至15%，脫離戰鬥狀態後效果會被移除。 |
| 日常生活攻略中 | 處於「緊急派送」狀態時，哈索爾的暴擊傷害提升30%。 |
| 共鳴 3：運力加倍 | 「普通攻擊：高頻送達」、「變軌技能：空中指令」和「極軌終結：鐵騎速遞」的技能等級提升1級。 |
| 共鳴 6：無阻通行 | 處於「緊急派送」狀態下，哈索爾造成的傷害無視目標10%的防禦力。 |
