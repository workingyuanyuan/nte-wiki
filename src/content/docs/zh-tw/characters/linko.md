## 角色資料

| 項目 | 內容 |
| --- | --- |
| 等級 | S 級，限定 |
| 屬性 | 靈 |
| 弧盤類型 | 等離子 (Plasma) |
| 加入版本 | 1.3 版下半期，2026-09-09 |

官方介紹說靈可是破格收入 E.T.D 六隊的成員。她能透過心電感應感知人與異象的「電波」，戰鬥則交給她收養的異象夥伴小貞。

## 取得方式

| 項目 | 內容 |
| --- | --- |
| 棋盤 | 位於「斯卡布羅集市」的限定棋盤「全頻帶漫遊中！」 |
| 首次開放 | 2026-09-09 維護後至 2026-09-30 05:59 (UTC+8) |
| 開放條件 | 完成正篇任務「序章 - 全新的目的地 - 前往『伊波恩古董店』」 |
| 同棋盤 A 級角色 | [哈尼婭](/zh-tw/characters/haniel/)、[海月](/zh-tw/characters/aurelia/)與[翳](/zh-tw/characters/skia/) |
| 擲骰獎勵 | 滑翔翼造型「超級惡靈！」、單車「舊時光」塗裝組「高速運轉的靈可」、時裝「星間漫遊」：累計擲骰 50、120、200 次可在「同頻禮遇」介面領取，也可能提前擲到對應格子獲得 |

## 技能

靈可透過普通攻擊累積 Modulation 並在離場後施加 Hit 'Em Here! 印記，以呼喚隊友或小貞發動對應屬性的 Synced Strike。她的極軌終結可進入 Overdrive 並展開 Resonance Field，連鎖觸發 Synced Strike 並使隊友的支援技能視為追擊。

| 欄位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻擊 | Poltergeist CQC, Spectral Smack, Spectral Entrance, Spectral Rush, Ghosthand Counter | 進行最多五段靈屬性攻擊並累積 Modulation 點數以強化 Full-Frequency Pulse 的 Synced Strike，另包含長按施放的 Spectral Smack、空中下墜的 Spectral Entrance，以及極限閃避反擊 Ghosthand Counter。處於後台時，Spectral Rush 會定期派出小貞突襲並施加 Hit 'Em Here! 印記。 |
| 技能 | Full-Frequency Pulse | 進行最多四段靈屬性攻擊並開啟選擇輪盤，呼喚一名隊友或小貞發動對應屬性的 Synced Strike。消耗所有 Modulation 以獲得額外 Synced Strike 傷害加成，或依缺席或無法行動的隊友人數進一步強化小貞。 |
| 極軌終結 | Oversync | 進入 Overdrive 狀態並展開 Resonance Field，與最多三名隊友進行 Sync，使變軌技能可觸發最多三次附帶額外靈屬性範圍攻擊的 Synced Strike。結束時引發依目標負面狀態數量提高傷害的靈屬性爆發；之後領域內隊友的支援技能皆視為追擊 Synced Strike。 |
| 支援技能 | Spectral Cross | 與小貞聯手攻擊造成範圍靈屬性傷害。在擊破 Hit 'Em Here! 印記或施放 Full-Frequency Pulse、Oversync 時也會呼喚隊友發動 Synced Strike，Synced Strike 傷害隨 Spectral Cross 等級提升。 |
| 被動 1 | Weakness Radar | 靈可於隊伍中時，Hexed Enhancement 會提高 Hexed 額外追擊的基礎傷害，並使受 Hexed 影響的目標受到的追擊傷害提高。 |
| 被動 2 | Precision Tuning | 降低目標與觸發 Synced Strike 的角色屬性相同的異能抗性。不同屬性的抗性降低效果可並存，同屬性則不疊加，再次觸發時刷新持續時間。 |
