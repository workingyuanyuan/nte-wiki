## 角色資料

| 項目 | 內容 |
| --- | --- |
| 等級 | S 級，常駐 |
| 屬性 | 咒 |
| 弧盤類型 | 氣態 (Gas) |
| 加入版本 | 1.0 版 |

官方介紹指出，早霧是伊波恩古董店冰箱便利貼規則的制定者，使用的武器是異象巨錘「鬼郎丸」。

## 取得方式

| 方式 | 說明 |
| --- | --- |
| 常駐棋盤 | 根據 Game8 與 Prydwen 的資料，常駐 S 級角色位於斯卡布羅集市的常駐棋盤 |
| 自選箱，1.2 版 | 向所有在 2026-08-19 05:59 (UTC+8) 前創建角色的玩家以信件發放「S 級常駐角色自選箱」 |
| 自選箱，1.4 版 | 來自都市大亨「噗卡計畫」的「S 級常駐角色自選箱」 |

此自選箱可從六名角色中任選一名：早霧、白藏、哈索爾、法帝婭、達芙蒂爾或九原。棋盤機制說明見[棋盤與弧盤研募](/zh-tw/systems/boards/)。

## 技能

早霧是咒屬性支援角色，能以 Devour Whole 與 Feast of Gluttony 牽引並控制敵人，同時依據自身的基礎攻擊力提升全隊攻擊力。她的被動技能會在目標處於 Airborne 或 Supress 後降低敵人防禦力，並提高處於 Scorch 狀態的目標所受到的持續傷害。

| 欄位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻擊 | Kiroumaru Headbutt、Ram、Eating Mode、Swallow、Critical Riposte: Mischief | Ram 最多可進行五段咒屬性攻擊，Swallow 為空中下墜攻擊，在極限閃避後施放 Critical Riposte: Mischief 可進行反擊並降低 Break。長按會啟動 Eating Mode，在處於 Hungry 狀態時牽引附近目標並吞食弱小敵人，直到變為 Full。 |
| 技能 | Devour Whole、Burp、Gravity Eater | 點按施放 Burp，牽引附近敵人後使鬼郎丸膨脹並擊倒敵人。長按施放 Gravity Eater，牽引附近敵人並吞噬區域內的重力使目標浮空，但此效果對強力敵人無效。 |
| 極軌終結 | Feast of Gluttony | 鬼郎丸從上方吐出 Gravity Slurry 造成六段範圍咒屬性傷害，以強大重力壓制敵人並使處於 Suppressed 的敵人無法移動（對 BOSS 無效）。同時依據早霧的基礎攻擊力提升除早霧以外的全隊攻擊力。 |
| 支援技能 | Squash! | 將變大的鬼郎丸砸向目標，對範圍內造成一次咒屬性傷害。 |
| 被動 1 | Can I Eat This? | 提供 Scorch Enhancement，依目標身上持續傷害效果的種類數量，提高處於 Scorch 狀態的目標所受到的持續傷害，設有上限。 |
| 被動 2 | Impish Trick | 早霧對敵人施加 Airborne 或 Supress 後，降低敵人的防禦力。 |
