## 技能

伊洛伊透過普通攻擊、技能、支援技能以及隊友進入「退行」來累積「臆想」。她的技能可治療、提供攻擊力增益並讓隊友進入「退行」，而極軌終結則會消耗「臆想」開啟治療夢境——或開啟進攻夢境，短暫復活一名處於「退行」狀態的隊友。

| 欄位 | 技能 | 效果說明 |
| --- | --- | --- |
| 普通攻擊 | 分工合作、白日夢、清明夢、起床時間、無意識響應 | 「分工合作」進行最多五段小羊攻擊、「起床時間」為下落攻擊、「無意識響應」於「極限閃避」後發動反擊以削減「傾陷值」；各項均會累積「臆想」。長按普通攻擊可消耗「臆想」進行最多三次「白日夢」攻擊，再次長按則召喚「莫爾甫斯」進行持續的「清明夢」射擊。 |
| 技能 | 未來自我連續性假設、自我認同延伸 | 點按觸發「自我認同延伸」治療全隊、依據伊洛伊的基礎攻擊力提供攻擊力加成、召喚三隻小羊聚攏敵人並累積「臆想」。長按「未來自我連續性假設」使三名隊友進入「退行」直至戰鬥結束。被動方面，任何倒下的隊友都會進入「退行」並累積「臆想」。 |
| 極軌終結 | 三十八億年的海市蜃樓 | 開啟夢境並持續消耗「臆想」直至耗盡。低於「臆想」門檻時，開啟「牛角門的夢境」為全隊持續治療；達到或高於門檻時，開啟「象牙門的夢境」造成靈屬性傷害、使「白日夢」與「清明夢」免消耗，並短暫復活一名處於「退行」狀態的隊友。 |
| 支援技能 | 砰！ | 與「莫爾甫斯」向前擊打，造成一段靈屬性傷害、治療全隊成員並累積「臆想」。 |
| 被動 1 | 鏡象 | 提供「創生」強化，當「創生株」持續存在時生成一個「創生株複製體」，向附近目標發射「複製創生花」。 |
| 被動 2 | 交感性神經系統 | 進行治療時，賦予全隊成員額外的「無視防禦」。 |

## 覺醒

每取得一個重複角色可任選一項覺醒解鎖；覺醒數達 3 與 6 時解鎖共鳴。

| 覺醒 | 效果 |
| --- | --- |
| 重複囚徒困境 | 伊洛伊處於後台時，每秒恢復3點「臆想」。 同時「臆想」積攢效率提升30% ，並且入戰後獲得滿額「臆想」。 |
| 策略：「一報還一報」 | 任意隊友釋放技能時，伊洛伊將隨機召喚莫爾甫斯/伊刻洛斯/方塔蘇斯中的一名，協助攻擊1次造成共計200%*伊洛伊自身攻擊力的傷害，並使全體友方獲得相當於伊洛伊自身攻擊力*120%的生命值回覆，冷卻時間5秒。 |
| 策略特性：善良 | 伊洛伊的治療效果提升36% 。 |
| 策略特性：可激怒 | 「退行」狀態下的小羊們攻擊倍率提升 莫爾甫斯： 「再睡會兒」的倍率，提升值相當於基礎倍率的30% 。 「多睡會兒」的倍率，提升值相當於基礎倍率的30% 。 伊刻洛斯： 「打一針吧」的倍率提升，提升值相當於基礎倍率的30% 。 「多打幾針」的倍率提升，提升值相當於基礎倍率的30% 。 方塔蘇斯： 「來首歌吧」的倍率提升，提升值相當於基礎倍率的30% 。 「不好聽嗎」的倍率提升，提升值相當於基礎倍率的30% 。 |
| 策略特性：清晰 | 「交感性神經系統」效果追加：基於伊洛伊基礎攻擊力的15% ，提高隊伍中角色的攻擊力，持續20 秒。 |
| 策略特性：寬容 | 伊洛伊釋放「極軌終結：三十八億年的海市蜃樓」後復活的角色，獲得100% 生命值、50 點環合值、50 點極軌終結能量。 |
| 共鳴 3：身為萬物的靈長 | 「普通攻擊：分工合作」「變軌技能：未來自我連續性假設」「極軌終結：三十八億年的海市蜃樓」的技能等級提升1 級。 伊洛伊在隊伍中時，全隊的防禦力提升30% 。 |
| 共鳴 6：自詡宇宙的精華 | 伊洛伊在隊伍中時，全隊暴擊傷害提升25% ；隊伍中每存在一名「退行」狀態的隊友，伊洛伊造成的傷害提升15% ，暴擊率提升5% 。 |
