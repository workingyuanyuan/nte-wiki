## 角色資料

| 項目 | 內容 |
| --- | --- |
| 等級 | S 級 |
| 屬性 | 光 |
| 弧盤類型 | 氣態 (Gas) |

| 配音員 | 中文：則靈；英文：Alice Himora；日文：小原好美；韓文：권다예 |

官方角色介紹指出，小吱是粉爪銀行（新赫蘭德區總部）的大堂經理，員工編號 018888；她外表看起來像實習生，但能一字不漏背出所有細則條款。

Game8 將她的技能拼為「Pink Paws Priority Principe」，Prydwen 則拼為「Pink Paws Priority Principle」。1.1 版為小吱新增了一項都市特技，可在地圖上標示出所有「粉爪大劫案」藏品。

## 取得方式

小吱是免費角色。Game8 指出可透過提升都市大亨等級取得她；Prydwen 則將她與她的額外同名角色列為無須課金即可取得。

## 技能

小吱透過普通攻擊產生「金谷」，並以堆疊的變軌技能施放消耗；極軌終結的「金谷市場」與「盈餘」狀態則能將「金谷貸款」與波動的「金谷K線」轉換為光屬性傷害。

| 欄位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻擊 | 失鄉劍術、荒谷、豐玉、極限反擊：明斯基時刻 | 「失鄉劍術」最多可進行五段攻擊，造成光屬性傷害並獲得「金谷」。「荒谷」可點按或長按施放「荒谷」，造成光屬性傷害並獲得「金谷」與方斯（擊敗敵人時有額外獲得量）。「豐玉」可於空中下落攻擊獲得「金谷」；觸發「極限閃避」後可施放「極限反擊：明斯基時刻」，削減「傾陷值」並獲得「金谷」。 |
| 技能 | 粉爪在上原則 | 最多可儲存三層變軌技能。連續點按會依序施放「空倉」、「半倉」與「滿倉」；長按則消耗兩層或三層，在「半倉」期間持續消耗「金谷」，並消耗所有「金谷」與處於「負債」狀態的「金谷貸款」，造成不會暴擊的額外光屬性傷害，處於「盈餘」時獲得強化。 |
| 極軌終結 | 零和博弈 | 擲出「黑糖波波」造成範圍光屬性傷害，將「金谷貸款」轉換為「金谷」，進入「盈餘」與「金谷市場」狀態並投入所有「金谷」。首次「谷價結算」傷害必定暴擊；點按或長按「粉爪在上原則」會依「金谷K線」觸發「谷價結算」，隨後償還「金谷貸款」。 |
| 支援技能 | 臨時入場 | 「黑糖波波」載著小吱撞向目標，造成一段光屬性傷害。 |
| 被動 1 | 飛鳥症候群 | 「盈蓄」強化會為場上角色提供額外「盈蓄」。 |
| 被動 2 | 囤積癖 | 小吱在場上時，提升自身的「充能效率」。 |

## 覺醒

每取得一個重複角色可任選一項覺醒解鎖；覺醒數達 3 與 6 時解鎖共鳴。

| 覺醒 | 效果 |
| --- | --- |
| 太陽太陽請回答 | 「金谷」和「金谷貸款」的存儲上限提升10%。 |
| 煙花，悄然無聲 | 當小吱處於「盈餘」狀態時，每秒可獲得當前「金谷」10%的利息。 |
| 倘若沒有雨天 | 「金谷K線」中「金谷」價格上漲的概率提高50%。 |
| 致飯糰·繃帶·方斯 | 「金谷」的獲取速率提升20%。 |
| 日記的空白頁 | 小吱入戰後立刻獲得當前「金谷」存儲上限100%的「金谷」。 |
| 三十三天 | 「金谷」造成的額外光屬性異能傷害提高15%。 |
| 共鳴 3：是朋友，是家人 | 「負債」狀態下，「金谷」的獲取效率額外提升50%。 |
| 共鳴 6：歸鄉 | 小吱對目標造成傷害時，降低目標10%光屬性異能傷害抗性。 |
