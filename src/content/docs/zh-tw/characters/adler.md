## 技能

阿德勒透過普通攻擊累積「業」層數，並以技能「誅惡護持」消耗層數，造成範圍持續咒屬性傷害並賦予「明悟之慧佑」護盾；他的極軌終結可造成多段咒屬性傷害，被動「克己」則會對處於「濁燃」的敵人施加減益效果。

| 欄位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻擊 | 度惡、滅苦、無明、極限反擊：揭諦、業 | 以「度惡」最多進行五段連續咒屬性攻擊，以「滅苦」進行單體瞄準射擊，或以「無明」發動下落攻擊。在「極限閃避」後施放「度惡」會觸發「極限反擊：揭諦」，削減「傾陷值」。「度惡」、「無明」與「滅苦」命中時會賦予「業」，最多 20 層。 |
| 技能 | 誅惡護持 | 召喚「空若」幻影造成範圍咒屬性傷害與持續咒屬性傷害，並為場上角色賦予帶有「明悟之慧佑」的護盾。施放時消耗所有「業」層數，依消耗層數提高技能傷害。 |
| 極軌終結 | 萬象澄寂 | 召喚五尊「空若」——「色」、「受」、「想」、「識」與「行」——攻擊所有敵人，各自造成五段咒屬性傷害。當場上僅剩一名敵人時，「空若」會再次發動攻擊，共計十段咒屬性傷害。 |
| 支援技能 | 明鏡本無塵 | 瞄準並向敵人發射一發「壓縮彈」，命中時造成一段範圍咒屬性傷害。 |
| 被動 1 | 克己 | 「濁燃」強化：每當目標被施加「濁燃」時，隨機施加三種減益效果之一，分別為降低攻擊力、降低「屬性抗性」或提高「傾陷效率」。相同減益效果無法疊加。 |
| 被動 2 | 正心 | 提升阿德勒的防禦力。 |

## 覺醒

每取得一個重複角色可任選一項覺醒解鎖；覺醒數達 3 與 6 時解鎖共鳴。

| 覺醒 | 效果 |
| --- | --- |
| 無色 | 釋放「極軌終結：萬象澄寂」後，阿德勒為自身附加20層「業」。 |
| 無受 | 每層「業」為阿德勒提供的傷害加成提升至3%。 |
| 無想 | 「明悟之慧佑」的護盾吸收量提升20%。 |
| 無行 | 「明悟之慧佑」碎裂時，基於阿德勒50%防禦力吸收部分溢出傷害。 |
| 無識 | 釋放「極軌終結：萬象澄寂」後，阿德勒返還20點終結能量。 |
| 諸法空相 | 「明悟之慧佑」的持續時間延長至12秒。 |
| 共鳴 3：辯覺之淨業 | 「普通攻擊：度惡」「變軌技能：誅惡護持」「極軌終結：萬象澄寂」的技能等級提升1級。 |
| 共鳴 6：慧佑之侍護 | 處於「明悟之慧佑」庇護時，全隊造成的咒屬性異能傷害提升10%。 |
