官方介紹形容潯是神秘莫測的伊波恩古董店店主：早霧眼中最不靠譜的成年人，也是娜娜莉崇拜的對象。

| 項目 | 內容 |
| --- | --- |
| 棋盤 | 「斯卡布羅集市」的限定棋盤「獨酌朧月流」 |
| 首次開放 | 2026-05-13 維護後至 2026-06-03 05:59 (UTC+8) |
| 返場 | 2026-09-09 維護後至 2026-09-30 05:59 (UTC+8) |
| 開放條件 | 完成正篇任務「序章 - 全新的目的地 - 前往『伊波恩古董店』」 |
| 同棋盤 A 級角色 | [哈尼婭](/zh-tw/characters/haniel/)、[海月](/zh-tw/characters/aurelia/)、[翳](/zh-tw/characters/skia/) |
| 擲骰獎勵 | 滑翔翼造型「幽蘭」、Blizzard-V4 塗裝「秋色殘影」、時裝「蘭花不菲」：累計擲骰 50、120、200 次後於「時計禮遇」介面領取，也可能提前擲到對應格子 |

擲骰次數依棋盤名稱分開計算：首次開放期間在「時計禮遇」累積的進度已保留至返場。

棋盤機制說明：[棋盤與弧盤研募](/zh-tw/systems/boards/)。

## 技能

潯不使用冷卻時間或極軌終結能量，而是隨時間在 Non-Closed Timepiece 上累積能量。她的技能消耗 60 能量以記錄最多三個隊友的支援技能或變軌技能，極軌終結則觸發 Time Stop 來重現這些技能並施展太刀連段。

| 欄位 | 技能 | 效果說明 |
| --- | --- | --- |
| 普通攻擊 | Misty Moon Style, Non-Closed Timepiece, Rippling Waves, Crescent, Critical Riposte: Half Moment | Misty Moon Style 進行最多五段光屬性攻擊，戰鬥中長按可觸發 Rippling Waves 向前突進，Crescent 為空中下落攻擊。當潯切換上場時 Non-Closed Timepiece 會被動旋轉，最多可儲存 120 能量。Critical Riposte: Half Moment 於 Critical Dodge 後發動反擊以削減 Break。 |
| 技能 | Present Replay | 無冷卻時間；當 Non-Closed Timepiece 能量高於 60 時消耗 60 能量，造成七段光屬性傷害、回撥指針並記錄最多三個隊友的支援技能或變軌技能（每名隊友限一個）。進入或離開戰鬥會清除記錄，再次施放則會覆蓋先前的記錄。 |
| 極軌終結 | World's Tide | 無冷卻時間且不消耗極軌終結能量；於 Non-Closed Timepiece 能量蓄滿時施放，造成十段光屬性傷害並持太刀進入 Time Stop，期間無法切換角色且免疫時間控制。會重現一次已記錄的攻擊、疊加最多十層太刀連段以造成 Finisher DMG，並回撥指針。 |
| 支援技能 | Shopkeeper's Authority | 投擲雨傘，對範圍內造成一段光屬性傷害。 |
| 被動 1 | Ghost Orchid Crest | 提供 Blossom Enhancement，使 Vita Bud 的攻擊不會在 Time Stop 期間暫停。 |
| 被動 2 | All Treasures Under Heaven | 提高 World's Tide 的 Finisher DMG Ratio。 |
