官方介紹形容潯是神秘莫測的伊波恩古董店店主：早霧眼中最不靠譜的成年人，也是娜娜莉崇拜的對象。

| 項目 | 內容 |
| --- | --- |
| 棋盤 | 「斯卡布羅集市」的限定棋盤「獨酌朧月流」 |
| 首次開放 | 2026-05-13 維護後至 2026-06-03 05:59 (UTC+8) |
| 返場 | 2026-09-09 維護後至 2026-09-30 05:59 (UTC+8) |
| 開放條件 | 完成正篇任務「序章 - 全新的目的地 - 前往『伊波恩古董店』」 |
| 同棋盤 A 級角色 | [哈尼婭](/zh-tw/characters/haniel/)、[海月](/zh-tw/characters/aurelia/)、[翳](/zh-tw/characters/skia/) |
| 擲骰獎勵 | 滑翔翼造型「幽蘭」、Blizzard-V4 塗裝「秋色殘影」、時裝「蘭花不菲」：累計擲骰 50、120、200 次後於「時計禮遇」介面領取，也可能提前擲到對應格子 |

擲骰次數依棋盤名稱分開計算：首次開放期間在「時計禮遇」累積的進度已保留至返場。

棋盤機制說明：[棋盤與弧盤研募](/zh-tw/systems/boards/)。

## 技能

潯不使用冷卻時間或極軌終結能量，而是隨時間在「非閉合時計」上累積能量。她的技能消耗 60 能量以記錄最多三個隊友的支援技能或變軌技能，極軌終結則觸發「時停」來重現這些技能並施展太刀連段。

| 欄位 | 技能 | 效果說明 |
| --- | --- | --- |
| 普通攻擊 | 朧月流、非閉合時計、漪瀾、勾月、極限反擊：半霎 | 「朧月流」進行最多五段光屬性攻擊，戰鬥中長按可觸發「漪瀾」向前突進，「勾月」為空中下落攻擊。當潯切換上場時「非閉合時計」會被動旋轉，最多可儲存 120 能量。「極限反擊：半霎」於「極限閃避」後發動反擊以削減「傾陷值」。 |
| 技能 | 今景復映 | 無冷卻時間；當「非閉合時計」能量高於 60 時消耗 60 能量，造成七段光屬性傷害、回撥指針並記錄最多三個隊友的支援技能或變軌技能（每名隊友限一個）。進入或離開戰鬥會清除記錄，再次施放則會覆蓋先前的記錄。 |
| 極軌終結 | 浮世來潮 | 無冷卻時間且不消耗極軌終結能量；於「非閉合時計」能量蓄滿時施放，造成十段光屬性傷害並持太刀進入「時停」，期間無法切換角色且免疫時間控制。會重現一次已記錄的攻擊、疊加最多十層太刀連段以造成「終結傷害」，並回撥指針。 |
| 支援技能 | 店主威勢 | 投擲雨傘，對範圍內造成一段光屬性傷害。 |
| 被動 1 | 鬼蘭家紋 | 提供「創生」強化，使「創生株」的攻擊不會在「時停」期間暫停。 |
| 被動 2 | 天下萬寶 | 提高「浮世來潮」的「終結傷害倍率」。 |

## 覺醒

每取得一個重複角色可任選一項覺醒解鎖；覺醒數達 3 與 6 時解鎖共鳴。

| 覺醒 | 效果 |
| --- | --- |
| 欣欣漸行 | 每記錄下一個「援護技」或「變軌技能」，潯在時停期間造成的傷害提升12%。 |
| 憶昔告遠 | 時停期間，潯造成的傷害提升20%。 |
| 垂目須臾 | 使用「變軌技能：今景復映」並完成記錄後，快速回復使用「變軌技能：今景復映」所消耗的能量，每60秒最多觸發一次。在回覆能量的過程中進行消耗能量的行為會打斷能量恢復。 |
| 舊藏遺散 | 未回撥指針期間，全隊每擊敗1個目標，「非閉合時計」額外積蓄10點能量，最多生效3次。釋放「極軌終結：浮世來潮」重置計數。 |
| 獨窺全相 | 潯上陣時，如果場上僅有1個敵人，全隊對該目標造成的傷害提升15%。潯力竭時，失去該效果。 |
| 時輪齧雪 | 時停期間，潯造成傷害時無視目標30%防禦。 |
| 共鳴 3：東零西碎的永恆 | 「普通攻擊：朧月流」、「變軌技能：今景復映」、「極軌終結：浮世來潮」的技能等級提升1級。 |
| 共鳴 6：瞭然於中的至珍 | 潯在編隊內且存活時，全隊攻擊力提升30%。 |
