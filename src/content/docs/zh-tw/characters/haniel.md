## 技能

哈尼婭部署隨身音響「咕咕子」，為隊伍提供攻擊力加成並藉由場上角色的攻擊累積「四部和聲」層數，觸發「合奏」範圍魂屬性傷害。她的極軌終結賦予「超異科王牌」，暫停「咕咕子」的持續計時並追加可累積「主角光環」的「合奏·交響」效果。

| 欄位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻擊 | 超異科登場、超異科魔法炮、極限反擊：王牌身法 | 「超異科登場」最多可發射五發魔法飛彈，也能於空中下落造成魂屬性傷害。在第一擊期間長按普通攻擊可蓄力施放「超異科魔法炮」。「極限反擊：王牌身法」會在「極限閃避」後反擊，削減「傾陷值」並發射完全蓄力的「超異科魔法炮」。 |
| 技能 | 靜默月林的守護者 | 投擲可攜式音響「咕咕子」，造成範圍魂屬性傷害並依哈尼婭的基礎攻擊力為隊伍提供攻擊力加成。場上角色攻擊會為「咕咕子」累積「四部和聲」層數；達四層時觸發「合奏」造成範圍魂屬性傷害。場上同時只能存在一個「咕咕子」，且切換角色後仍會保留。 |
| 極軌終結 | 名為「哈尼婭」的旋律 | 展開增益力場並賦予「超異科王牌」，依哈尼婭的基礎攻擊力為隊伍提供攻擊力加成並暫停「咕咕子」的持續時間計時。觸發「合奏」時會同時觸發強化的「合奏·交響」，雖不會賦予「主角光環」，但會強化場上角色的下次攻擊。 |
| 支援技能 | 彩蛋時間 | 向敵人發射一發魔法飛彈，造成一段魂屬性傷害。 |
| 被動 1 | 是友情啊 | 提供「黯星」強化，讓隊友在「黯星」結束時依哈尼婭的基礎攻擊力從目標吸取攻擊力，設有上限；離開戰鬥時雙方屬性恢復原狀。 |
| 被動 2 | 是羈絆啊 | 每當場上角色觸發「合奏」時為哈尼婭賦予「主角光環」層數，提高「超異科魔法炮」的彈跳次數上限。處於「超異科王牌」期間每次觸發「合奏」可獲得雙倍層數，最多四層。 |

| --- | --- |

| 危機！瀕臨破碎的信任 | 處於「超異科王牌」狀態時，哈尼婭自身造成的魂屬性異能傷害增加30%。 |

| 共鳴 3：前傳 | 「普通攻擊：蓋羅塞克特術法」、「變軌技能：靜默月林的守護者」、「極軌終結：名為『哈尼婭』的旋律」的技能等級提升1級。 |
