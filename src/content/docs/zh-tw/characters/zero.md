## 角色資料

| 項目 | 內容 |
| --- | --- |
| 等級 | S 級，主角 |
| 屬性 | 光 |
| 弧盤類型 | 固態 (Solid) |
| 加入版本 | 1.0 版 |
| 配音員 | 中文：馬洋；英文：Hunter McCoy；日文：内田雄馬；韓文：박기욱 |

零就是玩家操作的主角「鑒定師」。官方介紹描述這名由空白與謎團中現身的異能者，對各類異象的「奇點」有著敏銳的洞察力，並接受管理局的安排，在未取得異象獵人資格證的情況下前往伊波恩古董店工作。零可選擇男性或女性外觀遊玩。

## 取得方式

零是每位玩家一開始就會擁有的角色。

## 技能

零透過「鑑痕」連段造成光屬性傷害，以「銘隙鑑刻」發射「異能炮」並在攻擊低於自身等級的目標時追加一段傷害，並以「奇零除盡」進行爆發輸出。每當當前操作角色獲得終結能量時，「鑑定師」會透過「盈蓄」強化為隊友回復生命值。

| 欄位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻擊 | 鑑痕、鑑痕·斷、鑑痕·破、極限反擊：一瞬靈感 | 「鑑痕·斷」最多可進行五段連續光屬性攻擊。「鑑痕·破」從空中下墜攻擊，造成隨墜落高度提升的範圍光屬性傷害。極限閃避後觸發「極限反擊：一瞬靈感」進行反擊，造成範圍光屬性傷害並降低「傾陷值」。 |
| 技能 | 銘隙鑑刻 | 進行三段連續武器斬擊後躍向空中蓄力，發射「異能炮」造成範圍光屬性傷害，並對首位等級低於零的目標追加一次光屬性傷害。 |
| 極軌終結 | 奇零除盡 | 在劍舞之間斬斷無形絲線，對範圍內造成多段光屬性傷害。 |
| 支援技能 | 綻裂 | 斬裂空間並引爆裂隙，對範圍內造成兩段光屬性傷害。 |
| 被動 1 | 鑑定師 | 施加「盈蓄」強化，每當當前操作角色獲得終結能量時，依據零的基礎攻擊力回復生命值。 |
| 被動 2 | 異象感知力 | 提升極軌終結「奇零除盡」所造成的傷害。 |

## 覺醒

每取得一個重複角色可任選一項覺醒解鎖；覺醒數達 3 與 6 時解鎖共鳴。

| 覺醒 | 效果 |
| --- | --- |
| 初明凝視 | 「變軌技能：銘隙鑑刻」對首次命中的等級不高於自身等級的敵人造成1次200%*攻擊力的額外傷害，該傷害無視目標75%防禦。 |
| 探悉天職 | 成功釋放「變軌技能：銘隙鑑刻」後，自身額外獲得8點終結能量。 |
| 奇異記敘 | 「極軌終結：奇零除盡」的暴擊率提升50%。 |
| 未決迷數 | 零的每1點基礎攻擊力都使得「極軌終結：奇零除盡」造成的傷害提升0.1%，上限提升25%。 |
| 默示賦命 | 零觸發「援護技」後，使自身攻擊力提升10%，持續20秒。 |
| 誆定解放 | 「變軌技能：銘隙鑑刻」的額外傷害倍率提升至300%*攻擊力。 |
| 共鳴 3：鑑解 | 「鑑痕」「銘隙鑑刻」「奇零除盡」的技能等級提升1級。 |
| 共鳴 6：零示 | 零觸發任意光相關異能環合後，全隊角色攻擊力提升12%，持續20秒。 |
