## 技能

海月透過 Cadenza Aria 進入 Cadenza 狀態，並在 Staccato 中騎乘水母定期觸發水母爆裂，一邊累積 Crescendo 攻擊力層數、一邊以 Canzon Chorus 聚攏敵人，並在 Nova 結束後造成額外魂屬性傷害。

| 欄位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻擊 | Cappella, Legato, Staccato, Portamento, Critical Riposte: Syncopation | Legato 最多可進行四段魂屬性攻擊。移動時長按閃避可觸發 Staccato 騎乘水母，定期發射水母爆裂直至耐力不足，其 Critical Riposte 可發射四發爆裂。Portamento 可於空中發動下落攻擊；Critical Riposte: Syncopation 則在 Critical Dodge 後反擊並削減 Break。 |
| 技能 | Cadenza Aria | 造成一段範圍魂屬性傷害並進入 Cadenza 狀態。 |
| 極軌終結 | Canzon Chorus | 聚集附近水母，造成六段範圍魂屬性傷害並小幅牽引目標。 |
| 支援技能 | Dissonance | 指揮水母發動攻擊，命中時造成一段範圍魂屬性傷害。 |
| 被動 1 | Harmonics | Nova Enhancement：目標的 Nova 狀態結束後，對其造成三段魂屬性傷害。 |
| 被動 2 | Crescendo | 水母爆裂命中目標時提升海月的攻擊力，最多疊加十層。 |

## 覺醒

每取得一個重複角色可任選一項覺醒解鎖；覺醒數達 3 與 6 時解鎖共鳴。

| 覺醒 | 效果 |
| --- | --- |
| 未來序曲 | 處於「華彩」狀態時，海月的暴擊率提高15%。 |
| 一支特別的歌 | 成功進行極限閃避或釋放「援護技：不協和音」後，海月將進入持續5秒的「華彩」狀態。如已處於該狀態，則其持續時間在原有基礎上延長5秒。「華彩」狀態最多可持續12秒。 |
| 三重奏的休止符 | 處於「華彩」狀態時，海月釋放「極軌終結：眾聲輪唱」所造成的傷害提高20%。 |
| 五線譜的空白處 | 在釋放「普通攻擊：頓音」時，海月的防禦力增加20%。 |
| 一支平凡的歌 | 「極軌終結：眾聲輪唱」暴擊率提高15%。 |
| 往日賦格 | 「漸強」效果的最大疊加層數提升至20層。釋放「變軌攻擊：華彩唱段」後，立即獲得10層「漸強」效果。 |
| 共鳴 3：萬物於此和聲 | 「普通攻擊：清唱」「變軌技能：華彩唱段」「極軌終結：眾聲輪唱」的技能等級提升1級。 |
| 共鳴 6：與你一同奏響 | 進入「華彩」狀態或「華彩」狀態持續時間延長時，全隊的魂屬性異能傷害提升8%，持續15秒，重複獲得刷新持續時間。 |
