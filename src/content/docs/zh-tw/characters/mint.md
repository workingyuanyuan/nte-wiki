## 技能

薄荷是一名駐場靈屬性攻擊角色，能銜接五段連擊、消耗耐力持續旋轉的 Minty Whirlwind、突進攻擊以及多段範圍斬擊。在場期間她會獲得額外防禦力與抗打斷能力，且 Blossom Enhancement 能擴大 Vita Pistils 的傷害範圍。

| 欄位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻擊 | Perfect Containment, Justice from Above, Caramel Crisp, Minty Whirlwind | 最多可進行五段連續靈屬性攻擊，並可在空中施放下落攻擊 Justice from Above。長按普通攻擊會觸發 Minty Whirlwind，持續旋轉對周圍造成靈屬性傷害並消耗耐力。觸發 Critical Dodge 後，Caramel Crisp 會攻擊範圍內敵人造成靈屬性傷害並削減 Break。 |
| 技能 | Ultimate: Super Claws | 向前突進後返回起始位置，對路徑上的敵人造成兩段範圍靈屬性傷害。 |
| 極軌終結 | Ultimate: Thunderous Whirlwind Slash | 將風之力匯聚於雙刃，造成多段範圍靈屬性傷害，並以造成高額範圍靈屬性傷害的終結一擊收尾。 |
| 支援技能 | Ultimate: Invincible Tornado Slash | 蓄力並躍向空中發動貫穿攻擊，造成一段範圍靈屬性傷害。 |
| 被動 1 | Transform! Super Mint! | Blossom Enhancement 會在命中時擴大 Vita Pistils 的傷害範圍。 |
| 被動 2 | Bingo! We're Done Here! | 薄荷留在場上時，提升自身的防禦力與抗打斷能力。 |

## 覺醒

每取得一個重複角色可任選一項覺醒解鎖；覺醒數達 3 與 6 時解鎖共鳴。

| 覺醒 | 效果 |
| --- | --- |
| 特遣行動 | 「極限反擊：焦糖脆片」命中敵人時可重置「變軌技能：奧義·超級連風爪」的冷卻時間，該效果每3秒可觸發一次。 |
| 二次補考 | 「變軌技能：奧義·超級連風爪」的傷害提升40%。 |
| 全勤獎金 | 角色對敵人觸發「創生」或「覆紋」後，使得薄荷自身攻擊力提升15%，該效果持續15秒。 |
| 午休時間 | 薄荷對僅存在的單個敵人造成傷害後，使得自身的暴擊率提升12%。 |
| 第一直覺 | 薄荷在成功釋放「變軌技能：奧義·超級連風爪」後，使得自身的暴擊傷害提升25%，該效果可持續6秒。 |
| 精英隊員 | 薄荷對生命值低於40%的目標造成的傷害額外增加15%。 |
| 共鳴 3：薄荷波波茶 | 「普通攻擊：滿分收容術」「變軌技能：奧義·超級連風爪」「極軌終結：奧義· 霹靂疾風斬」的技能等級提升1級。 |
| 共鳴 6：蓬絨絨慕斯 | 成功釋放「變軌技能：奧義·超級連風爪」後，薄荷額外獲得2點環合值。 |
