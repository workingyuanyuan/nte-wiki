## 技能

明音凜透過「弦刃」累積「弦能」，並以「律動音浪」施加單體「泛音列」或部署範圍「音域」來傳導普通攻擊，隨後消耗 30 點「弦能」施放「同調共振」，同時善用「音障爆鳴」的兩段式「華彩連段」狀態。

| 欄位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻擊 | 弦刃、舞台跳水、極限反擊：羽刃迴響 | 「弦刃」進行最多四段相屬性攻擊，每次明音凜造成傷害時都能產生最多 30 點「弦能」。「舞台跳水」從空中下墜造成範圍相屬性傷害。「極限反擊：羽刃迴響」在極限閃避後觸發，造成相屬性傷害並保留「弦刃」的連段進度。 |
| 技能 | 律動音浪、同調共振 | 點按「律動音浪」對單一目標施加「泛音列」，或長按部署「音域」；兩者皆可伴隨額外傷害傳導普通攻擊與「羽刃迴響」，且場上同時只能存在一個。累積 30 點「弦能」時可施放「同調共振」，消耗能量並在無敵狀態下造成高額傷害。 |
| 極軌終結 | 音障爆鳴 | 造成多段範圍相屬性傷害並進入提高抗打斷能力的「華彩連段」狀態，此狀態獨立於「泛音列」與「音域」。在「華彩連段」結束前可手動再次施放一次，造成範圍傷害並提前結束狀態。非戰鬥狀態下可持續回復極軌終結能量。 |
| 支援技能 | 變奏和絃 | 強力撥動琴弦，造成一次相屬性傷害。 |
| 被動 1 | 絕對音準 | 「延滯」強化：隊伍首次觸發「延滯」後，持續定期對帶有「泛音列」或位於「音域」內的目標施加「延滯」，直到脫離戰鬥。重複施加「延滯」會觸發額外相屬性傷害，該傷害視為變軌技能傷害，並隨目標剩餘的「延滯」持續時間提高。 |
| 被動 2 | 爍星激昂 | 施放「音障爆鳴」後提高明音凜的攻擊力。此效果不可疊加，再次觸發時重置持續時間。 |

## 覺醒

每取得一個重複角色可任選一項覺醒解鎖；覺醒數達 3 與 6 時解鎖共鳴。

| 覺醒 | 效果 |
| --- | --- |
| 教室後的吉他譜 | 每次釋放強化變軌技能「同調共振」時，立即回覆一次相當於明音凜1000%基礎攻擊力的生命值，並且明音凜的防禦力提升50%，抗打斷能力提升60%，持續15秒。 |
| 琴行中的變調夾 | 被「泛音列」附著，或者處於「音域」內的敵人相屬性抗性降低12%。 |
| 樹蔭下的膠囊罐 | 點按「變軌技能：律動音浪」釋放「泛音列」時，該技能增加1000%的固定倍率；「音域」的半徑擴大30%，且長按「變軌技能：律動音浪」釋放「音域」時，吸附範圍內的敵人。 |
| 耳機裡的底噪聲 | 釋放強化變軌技能「同調共振」後，明音凜暴擊傷害提升30%，持續15秒。 |
| 樂隊間的節拍器 | 「泛音列」傳導普通攻擊的倍率提升效果提高至64%；「音域」傳導普通攻擊的傷害提升效果提高至90%。 |
| 舞台前的超新星 | 「爍星激昂」額外使明音凜獲得16%的無視防禦。 |
| 共鳴 3：全音階 | 明音凜的普通攻擊、變軌技能、極軌終結的技能等級提高1級；進入戰鬥時立即充滿「弦能」。強化變軌技能「同調共振」增加800%的固定倍率。「極軌終結：音障爆鳴」第二段增加1000%的固定倍率。 |
| 共鳴 6：復調式 | 每次釋放強化變軌技能「同調共振」後返還10點「弦能」。釋放強化變軌技能「同調共振」後，明音凜暴擊傷害提升64%，持續25秒。 |
