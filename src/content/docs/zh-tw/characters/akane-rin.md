官方介紹形容明音有著如太陽般耀眼的金髮、天生屬於聚光燈下，卻常待在安靜的角落戴著耳機，沉浸在自己的音樂中。公告中也稱她為明音。

## 取得方式

| 項目 | 內容 |
| --- | --- |
| 棋盤 | 位於「斯卡布羅集市」的限定棋盤「燦爛的星」 |
| 首次開放 | 2026-10-21 維護後至 2026-11-11 05:59 (UTC+8) |
| 開放條件 | 完成正篇任務「序章 - 全新的目的地 - 前往『伊波恩古董店』」 |
| 同棋盤 A 級角色 | [哈尼婭](/zh-tw/characters/haniel/)、[海月](/zh-tw/characters/aurelia/)與[翳](/zh-tw/characters/skia/) |
| 擲骰獎勵 | 滑翔翼造型「迷茫日」、「舊時光」單車塗裝「音速流星」、時裝「舞台之星」：累計擲骰 50、120、200 次可在「空箱禮遇」介面領取，也可能提前擲到對應格子獲得 |

棋盤機制詳見：[棋盤與弧盤研募](/zh-tw/systems/boards/)。

## 技能

明音凜透過 Stringblade 累積 String Energy，並以 Rhythm Wave 施加單體 Overtone 或部署範圍 Reverb Field 來傳導普通攻擊，隨後消耗 30 點 String Energy 施放 Synced Resonance，同時善用 Sonic Boom 的兩段式 Solo Cadenza 狀態。

| 欄位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻擊 | Stringblade, Stage Dive, Critical Riposte: Featherblade Reverb | Stringblade 進行最多四段相屬性攻擊，每次明音凜造成傷害時都能產生最多 30 點 String Energy。Stage Dive 從空中下墜造成範圍相屬性傷害。Critical Riposte: Featherblade Reverb 在極限閃避後觸發，造成相屬性傷害並保留 Stringblade 的連段進度。 |
| 技能 | Rhythm Wave, Synced Resonance | 點按 Rhythm Wave 對單一目標施加 Overtone，或長按部署 Reverb Field；兩者皆可伴隨額外傷害傳導普通攻擊與 Featherblade Reverb，且場上同時只能存在一個。累積 30 點 String Energy 時可施放 Synced Resonance，消耗能量並在無敵狀態下造成高額傷害。 |
| 極軌終結 | Sonic Boom | 造成多段範圍相屬性傷害並進入提高抗打斷能力的 Solo Cadenza 狀態，此狀態獨立於 Overtone 與 Reverb Field。在 Solo Cadenza 結束前可手動再次施放一次，造成範圍傷害並提前結束狀態。非戰鬥狀態下可持續回復極軌終結能量。 |
| 支援技能 | Altered Chord | 強力撥動琴弦，造成一次相屬性傷害。 |
| 被動 1 | Perfect Pitch | Remora Enhancement：隊伍首次觸發 Remora 後，持續定期對帶有 Overtone 或位於 Reverb Field 內的目標施加 Remora，直到脫離戰鬥。重複施加 Remora 會觸發額外相屬性傷害，該傷害視為變軌技能傷害，並隨目標剩餘的 Remora 持續時間提高。 |
| 被動 2 | Starlit Anthem | 施放 Sonic Boom 後提高明音凜的攻擊力。此效果不可疊加，再次觸發時重置持續時間。 |
