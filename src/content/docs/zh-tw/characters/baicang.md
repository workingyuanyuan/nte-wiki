## 角色資料

| 項目 | 內容 |
| --- | --- |
| 等級 | S 級，常駐 |
| 屬性 | 咒 |
| 弧盤類型 | 聚合 (Condensate) |
| 加入版本 | 1.0 版 |
| 配音員 | 中文：桑毓澤；英文：Griffin Burns；日文：中村悠一；韓文：심규혁 |

官方介紹指出，白藏是異象管理局 E.T.D 四隊隊長：隨性散漫、直言不諱，還是個工作摸魚大師。

## 取得方式

| 方式 | 說明 |
| --- | --- |
| 常駐棋盤 | 根據 Game8 與 Prydwen 的資料，常駐 S 級角色位於斯卡布羅集市的常駐棋盤 |
| 自選箱，1.2 版 | 向所有在 2026-08-19 05:59 (UTC+8) 前創建角色的玩家以信件發放「S 級常駐角色自選箱」 |
| 自選箱，1.4 版 | 來自都市大亨「噗卡計畫」的「S 級常駐角色自選箱」 |

此自選箱可從六名角色中任選一名：早霧、白藏、哈索爾、法帝婭、達芙蒂爾或九原。棋盤機制說明見[棋盤與弧盤研募](/zh-tw/systems/boards/)。

## 技能

白藏會消耗當前生命值，透過普通攻擊、閃避連段與「不吝賜教」衍生技生成「言靈字」（「祝」、「噤」與「詈」），再於「判予秋」領域內觸發其額外傷害、治療與低生命值處決效果。

| 欄位 | 技能 | 效果 |
| --- | --- | --- |
| 普通攻擊 | 言行合一、無狀之言、無諱之語、於風中、極限反擊：避實擊虛、如影隨形 | 「言行合一」最多可進行五段咒屬性攻擊，「如影隨形」每命中三次消耗當前生命值生成一個「祝」字，最多三個。「無狀之言」與「無諱之語」會發射三道引爆指令。「於風中」為下墜攻擊；「極限反擊：避實擊虛」會生成「祝」。 |
| 技能 | 不吝賜教、天地之心、噤念、如此罪狀 | 「天地之心」會以地脈文字在目標位置進行攻擊。閃避後按下變軌技能可施放「噤念」，造成單體咒屬性傷害並生成「噤」字；在「無狀之言」或「無諱之語」後施放則會觸發「如此罪狀」，造成範圍傷害並生成「詈」字。 |
| 極軌終結 | 判予秋 | 展開領域並進入「言靈字」狀態，持續造成咒屬性傷害並處決低於生命值門檻的目標。賦予暫時的致命傷害免疫效果，結束領域並擴散已記錄的傷害。依標記觸發額外效果：「噤」造成額外單體傷害，「詈」造成範圍傷害，「祝」則提供治療與傷害。 |
| 支援技能 | 摸魚結束 | 短暫蓄力並書寫咒言指令，造成一次範圍咒屬性傷害，命中時在目標身上生成一個「噤」字。 |
| 被動 1 | 適度惡趣味 | 「濁燃」強化：在處於「濁燃」狀態的目標身上生成「言靈字」時，額外施加一次相同效果的「濁燃」。 |
| 被動 2 | 適度上工 | 提升白藏的攻擊力，並與 E.T.D 四隊隊友觸發協同效果：在翳潛行期間切換登場時進行攻擊並生成「噤」字；法帝婭生命值過低時進行攻擊並為她治療；或在安魂曲處於蝙蝠型態期間切換登場時觸發超級跳躍。 |

## 覺醒

每取得一個重複角色可任選一項覺醒解鎖；覺醒數達 3 與 6 時解鎖共鳴。

| 覺醒 | 效果 |
| --- | --- |
| 唷 隊長！ | 「判予秋」期間，觸發「噤」字可提升30%白藏下次釋放技能的傷害，可疊加。觸發「詈」字可縮短白藏技能冷卻4秒時長，可疊加（若無技能處於冷卻狀態，則下次使用時生效）。 |
| 招魂幡 | 與那座山巒一樣，層層疊疊。每生成任意1個言靈字，白藏的攻擊力將提升6%，效果最多疊加4層，每層持續時間10秒。 |
| 惡詛不過一開口 | 生成言靈字的上限提升至4個。 |
| 亦或是祝禱 | 「判予秋」期間，當任意1個言靈字被觸發時，白藏額外恢復5%的最大生命值。 |
| 敬此月色 | 尚未結束。「判予秋」的持續時間提升至16秒。 |
| 於五色為白 | 「判予秋」期間，白藏的暴擊率提升30%。 |
| 共鳴 3：序屬歸藏 | 「言行合一」、「不吝賜教」、「判予秋」的技能等級提升1級。 |
| 共鳴 6：駐於此處 | 偶爾展現隊長的庇護力。「判予秋」期間，領域內的所有隊伍成員獲得20%的攻擊力加成，並均可觸發「即刻斬殺」效果。 |
