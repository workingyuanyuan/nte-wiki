## 運作方式

| 部件 | 作用 |
| --- | --- |
| 空幕 | 每名角色的格盤；格子配置與加成因角色而異 |
| 卡帶 | 決定套裝效果；帶 1 個主屬性與 4 個副屬性，掉落時隨機決定 |
| 驅動塊 | 擺進格盤；1 個主屬性與最多 4 個副屬性，依型號（占用格數）與形狀分類 |
| 套裝效果 | 裝上卡帶指定形狀的驅動塊 2 塊與 4 塊時，分別啟動 2 件與 4 件效果 |
| 角色加成 | 每名角色每裝一塊特定型號的驅動塊就獲得一項屬性加成，見下表 |

## 取得方式

| 物品 | 來源 |
| --- | --- |
| 卡帶 | 異象界域「兔子洞」 |
| 驅動塊 | 空幕頁面的「倒帶」，消耗兔子洞掉落的蘿蔔幣：胡蘿蔔幣用於初級、銀蘿蔔幣用於中級、金蘿蔔幣用於高級倒帶 |
| 驅動塊升級 | 兔子洞掉落的井小屑、井屑達人、超屑井主 |
| 額外驅動塊 | 四處[房產](/zh-tw/systems/properties/)中的異象家具「倉鼠球」 |

## 升級與分解

驅動塊與卡帶用井屑道具升級。分解升級過的驅動塊，會返還它從升級累積的全部經驗與 80% 的甲硬幣；直接拿它餵給其他裝備則會損失部分經驗。升級過的驅動塊，分解比直接餵划算。

NGA 論壇的玩家實測補充了細節，卡帶與驅動塊皆適用：

| 操作 | 實測結果 |
| --- | --- |
| 拿裝備餵裝備 | 驅動塊與卡帶可以互相餵。被餵掉的裝備傳過去的是它升級累積經驗的 80%，加上它的全部基底經驗 |
| 甲硬幣花費 | 每 50 點經驗 1 枚：用井屑道具時按道具經驗計，拿裝備餵時按被餵裝備的基底經驗計。超出等級上限那部分經驗的甲硬幣不返還 |
| 超出上限的經驗 | 以井屑道具返還；不足 1,000 的零頭不返還 |
| 分解 | 升級累積的經驗全數以井屑道具返還，甲硬幣返還 80%。基底經驗以井屑道具返還，或改換成同品質的蘿蔔幣：卡帶 12 枚、驅動塊 8 枚 |

## 驅動塊型號

驅動塊共有 12 種形狀，每種分藍、紫、金三種品質。

| 驅動塊型號 | 格數 | 形狀 |
| --- | --- | --- |
| Ⅱ型 | 2 | 橫向、直向 |
| Ⅲ型 | 3 | 橫向、直向、四種 L 形 |
| Ⅳ型 | 4 | 橫向、直向、兩種 Z 形 |

## 卡帶套裝

六套提升單一屬性的傷害，六套為通用功能套裝。

| 「迪亞波羅斯」 | 暗屬性異能傷害提升10%。 | 無視敵人12%暗屬性異能抗性。當裝備者參與觸發「黯星」或「濁燃」反應之後則提升至無視敵人24%暗屬性異能抗性，持續20秒。 | Ⅱ型直向、Ⅲ型 L 形 ×2、Ⅳ型橫向 |
| 「森林螢火之心」 | 靈屬性異能傷害提升10%。 | 附近每有敵人受到由己方編隊造成的靈屬性異能傷害，則裝備者暴擊傷害提升8%，最多疊加7層，每層持續10秒，角色位於後台依舊生效。 | Ⅱ型橫向、Ⅲ型直向、Ⅲ型 L 形、Ⅳ型 Z 形 |
| 「真紅：雙生蝶」 | 咒屬性異能傷害提升10%。 | 附近敵人每受到一次己方編隊造成的咒屬性異能傷害，則裝備者攻擊力提升6%，最多疊加6層，每層持續10秒，角色位於後台依舊生效。 | Ⅱ型直向、Ⅲ型橫向、Ⅲ型 L 形、Ⅳ型 Z 形 |
| 「惡魔之血：詛咒」 | 魂屬性異能傷害提升10%。 | 造成的傷害提升18%。攻擊受到「黯星」或「浸染」影響的單位時，傷害提升效果變為36%。 | Ⅱ型直向、Ⅲ型直向、Ⅲ型 L 形、Ⅳ型 Z 形 |
| 「街頭拳王」 | 相屬性異能傷害提升10%。 | 暴擊率提升14%。己方編隊觸發「延滯」或「浸染」之後，則暴擊率額外提升14%，持續20秒。 | Ⅱ型橫向、Ⅲ型橫向、Ⅲ型 L 形、Ⅳ型 Z 形 |
| 「守衛王國」 | 防禦力提升15%。 | 裝備者的護盾效果提升20%。 | Ⅲ型橫向、Ⅲ型直向、Ⅲ型 L 形 ×2 |
| 「影之信條」 | 攻擊力提升10%。 | 裝備者釋放「變軌技能」以後，攻擊力增加25%，持續20秒。 | Ⅱ型橫向、Ⅱ型直向、Ⅳ型橫向、Ⅳ型 Z 形 |
| 「緹婭的夜間酒館」 | 生命值提升10%。 | 裝備者的治療效率提升20%。 | Ⅲ型橫向、Ⅲ型直向、Ⅲ型 L 形 ×2 |
| 「小小大冒險」 | 生命值提升10%。 | 裝備者每次降低血量時，生命值上限提升4%，最多疊加10層，每層持續10秒。釋放「極軌終結」時，直接獲得10層該效果。 | Ⅱ型橫向、Ⅱ型直向、Ⅳ型橫向、Ⅳ型 Z 形 |
| 「音速藍刺蝟」 | 充能效率提高12%。 | 裝備者釋放「極軌終結」以後，全隊角色獲得15%攻擊力提升(該效果不可疊加)，持續20秒。 | Ⅲ型 L 形 ×4 |
| 「靜謐山莊」 | 心靈傷害提高10%。 | 裝備者普通攻擊後，造成的心靈傷害提升12%，最多疊加3層，每層持續6秒。 | Ⅱ型橫向、Ⅱ型直向、Ⅳ型直向、Ⅳ型 Z 形 |
