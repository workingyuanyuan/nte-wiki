## 伺服器與帳號

| 項目 | 規則 |
| --- | --- |
| 伺服器 | Asia、America、Europe、SEA |
| 跨伺服器進度 | 不互通；每個伺服器各自獨立 |
| 跨平台進度 | 在同一伺服器使用相同帳號登入時互通 |
| UID | 跨平台共用，建立時隨機指派 |
| iOS 與 Mac 登入方式 | Facebook、Google、Sign in with Apple 或電子信箱 |
| Windows PC、Steam、Epic、Galaxy Store 登入方式 | Facebook、Google 或電子信箱 |
| PlayStation 登入方式 | PSN 或電子信箱 |
| 第三方登入 | 透過不同平台授權建立的帳號彼此獨立，資料不互通 |
| 客服支援 | 遊戲內：設定 - 客服中心 |

## 系統需求

| 平台 | 最低配備 | 推薦配備 |
| --- | --- | --- |
| PC 處理器 | Intel Core i7-10700 | Intel Core i7-12700 或以上 |
| PC 顯示卡 | NVIDIA GeForce GTX 1660 或 AMD Radeon RX 5600 | NVIDIA GeForce RTX 3060 或 AMD Radeon RX 6700 或以上 |

| Steam 版 PC | 16 GB 記憶體、DirectX 11、70 GB 儲存空間；亦列出 Snapdragon X 搭配 Adreno X1 | 32 GB 記憶體、DirectX 12、70 GB 儲存空間；亦列出 Snapdragon X2 Elite 搭配 Adreno X2 |
| Android | 高通驍龍 855 或聯發科天璣 8000；Android 10.0；20 GB 可用空間 | 高通驍龍 8 Gen 2、驍龍 8 Gen 3 或聯發科天璣 9200 或以上 |
| iOS | iPhone 12 Pro Max；iOS 15.0；20 GB 可用空間 | iPhone 14 Pro 或更新機型；iOS 17.0 或以上版本 |

## 更新方式

| 平台 | 操作步驟 |
| --- | --- |
| PC | 關閉當前遊戲，重新開啟啟動器並點擊更新 |
| Android | 啟動遊戲並依畫面提示進行更新 |
| iOS 與 Mac | 前往 App Store 下載或更新 |
| PlayStation | 開啟系統介面，選擇《異環》，按下 OPTIONS 鍵後選擇檢查更新 |
| Steam | 關閉遊戲，重新啟動 Steam 用戶端，在「收藏庫」中找到《異環》並點擊更新 |

版本更新於週三 06:00 至 11:00 (UTC+8) 進行；維護期間暫停登入。
