## 運作方式

| 項目 | 規則 |
| --- | --- |
| 位置 | 棋盤位於斯卡布羅集市；弧盤研募計畫位於弧盤商店 - 弧盤研募計畫 |
| 開放條件 | 完成正篇任務「序章 - 全新的目的地 - 前往『伊波恩古董店』」 |
| 限定棋盤 | 包含 1 位限定 S 級角色與 3 位 A 級角色；玩家透過擲骰並停在格子上取得獎勵 |
| 開放天數 | 三週，自週三維護後起至週三 05:59 (UTC+8) 止；「無歸路」開放時間為兩週 |
| 擲骰獎勵 | 每個棋盤都有對應的禮遇介面，累計擲骰 50、120、200 次可分別獲得滑翔翼造型、載具塗裝與時裝；同一批獎勵也有機率提前從棋盤格子中擲出 |
| 擲骰計數 | 依棋盤名稱分別累計，同名棋盤返場時會保留進度 |
| A 級角色 | [薄荷](/zh-tw/characters/mint/)、[埃德嘉](/zh-tw/characters/edgar/)與[阿德勒](/zh-tw/characters/adler/)，或[哈尼婭](/zh-tw/characters/haniel/)、[海月](/zh-tw/characters/aurelia/)與[翳](/zh-tw/characters/skia/) |
| 限定弧盤 | 每位限定角色對應一個限定 S 級弧盤，各自有專屬的弧盤研募計畫，開放期間與對應棋盤相同 |
| 弧盤研募消耗 | 三重鑰匙；自 1.2 版起也可使用該研募計畫的專屬鑰匙，例如決意鑰匙 |
| 常駐棋盤 | 常駐開放，收錄常駐 S 級與 A 級角色，另有獨立卡池與保底機制 |

Prydwen 指出，限定 S 級角色的保底計數會在不同限定棋盤之間繼承，而弧盤研募計畫與常駐棋盤則各自獨立計算保底。該保底計數與禮遇介面的擲骰次數不同。
