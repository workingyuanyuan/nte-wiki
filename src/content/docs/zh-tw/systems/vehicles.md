## 大眾運輸

海特洛設有列車與公車，玩家皆可搭乘。遊戲內不顯示時刻表，等下一班車有時會花上不少時間。搭乘列車不收車資。[^1]

[^1]: [GameWith 的移動方式指南（英文）](https://gamewith.net/nte/74171)

| 項目 | 細節[^2] |
| --- | --- |
| 路線 | 多條軌道線採環狀行駛；有一條路面電車路線會跨越一段海面 |
| 公車 | 路線名稱只標示在站牌上，車身不顯示。公車遇到紅燈會停等 |
| 駕駛公車 | 營運中的公車無法駕駛或搶奪；停放在駕校停車場的兩輛公車可以駕駛 |
| 未開放車站 | 城內部分地下車站上鎖 |
