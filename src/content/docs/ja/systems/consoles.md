## 仕組み

| 部位 | 役割 |
| --- | --- |
| ギア | 各キャラが持つマス目の盤面。配置とボーナスはキャラごとに異なる |
| 駆動コア | セット効果を決める。メインステータス1つとサブステータス4つを持ち、ドロップ時に決まる |
| 駆動ブロック | 盤面を埋める。メインステータス1つとサブステータス最大4つを持つ。型（占めるマスの数）と形で分類される。メインステータスは固定である。[^1] |
| セット効果 | 駆動コアが指定する形の駆動ブロックを2つ、4つ置くと、2セット効果、4セット効果が発動する |
| キャラボーナス | 各キャラは特定の型の駆動ブロック1つごとにステータスを得る |

[^1]: [叫我棉被、ナナリ攻略動画、Bilibili、簡体字中国語（2026-04-23）、5:24](https://www.bilibili.com/video/BV1ybo8BPEpx/?t=324)

## 入手方法

| アイテム | 入手元 |
| --- | --- |
| 駆動コア | 異象界「ウサギの穴」 |
| 駆動ブロック | ギア画面のRewind。「ウサギの穴」で得るニンジンコインを支払う：EasyのRewindには「ニンジンコイン」、Normalには「銀のニンジンコイン」、Hardには「金のニンジンコイン」 |
| 駆動ブロックの強化 | 「ウサギの穴」で得る「ウサゲス-普通」、「ウサゲス-希少」、「ウサゲス-伝説」 |
| 追加の駆動ブロック | 4つの[物件](/ja/systems/properties/)にある異象家具「ハムスターボール」 |

## 強化と分解

駆動ブロックと駆動コアはウサゲスのアイテムで強化する。強化した駆動ブロックを分解すると、強化で蓄えた経験値がすべて戻り、甲虫コインは80%戻る。そのまま別の装備の素材にすると経験値の一部を失う。

駆動ブロックと駆動コアには同じルールが適用される。

| 操作 | 結果[^2] |
| --- | --- |
| 装備を素材にする | どの駆動ブロックや駆動コアも、他のどれの素材にもできる。素材にした装備からは、強化で蓄えた経験値の80%と、基礎経験値のすべてが移る |
| 甲虫コインの消費 | 使ったウサゲスのアイテムの経験値50、または素材にした装備の基礎経験値50ごとに1枚。レベル上限を超えた経験値に使ったコインは戻らない |
| 上限を超えた経験値 | ウサゲスのアイテムで戻る。1,000未満の端数は失われる |
| 分解 | 強化で得た経験値はウサゲスのアイテムで全額戻り、そのコインは80%戻る。基礎経験値はウサゲスのアイテムか、装備のレアリティに応じたニンジンコインで戻る：駆動コアは12枚、駆動ブロックは8枚 |

[^2]: [NGAフォーラム、駆動コアと駆動ブロックの経験値のプレイヤー検証、簡体字中国語（2026-11-21閲覧）](https://bbs.nga.cn/read.php?tid=46767393)

## 駆動ブロックの型

駆動ブロックの形は12種類ある。それぞれに青、紫、金のレアリティがある。

| 駆動ブロックの型 | マス | 形 |
| --- | --- | --- |
| Ⅱ型 | 2 | 横、縦 |
| Ⅲ型 | 3 | 横、縦、L字4種 |
| Ⅳ型 | 4 | 横、縦、Z字2種 |
