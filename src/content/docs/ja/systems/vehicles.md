## 公共交通

ヘテロシティには電車とバスがあり、プレイヤーはどちらにも乗れる。時刻表は表示されないため、次の電車やバスまで長く待つことがある。GameWithによると、電車は運賃がかからない。

| 項目 | 詳細（あるプレイヤーの路線図が載ったNGAフォーラムのスレッドより） |
| --- | --- |
| 路線 | 複数の鉄道路線が環状に走る。路面電車の1路線は海の一部を渡る |
| バス | 路線名はバス停の標識にだけ表示され、バスには表示されない。バスは赤信号で止まる |
| バスの運転 | 運行中のバスは運転も乗っ取りもできない。教習所の駐車場に停まっている2台のバスは運転できる |
| 閉鎖された駅 | 市内の一部の地下駅は施錠されている |

別のNGAの投稿によると、橋間地で四輪車が入れないのはハンカク街だけであり、四輪車はその入口の駐車場で止まる。
