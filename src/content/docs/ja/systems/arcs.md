## タイプとランク

弧盤には5つのタイプと、S（金）、A（紫）、B（青）の3つのランクがある。どの弧盤も1つ目のステータスが攻撃力で、2つ目のステータスと、5段階の効果を持つ。弧盤のレベル上限は80で、レベル30、40、50、60、70、80で突破する。限定Sランク弧盤は弧盤研究プロジェクトから入手する。[ボードと弧盤研究プロジェクト](/ja/systems/boards/)を参照。

## 効果

数値は1段階目から5段階目までの範囲である。

| 弧盤 | 効果（1段階目〜5段階目） |
| --- | --- |
| 熱狂の渦 | 装備者が待機中、現在操作中のキャラの攻撃力+10%〜14%、装備者がダメージを与えるたびに、現在操作中のキャラの攻撃力+2%〜3.2%（最大4スタックまで、2秒ごとに最大1スタック）。装備者が操作キャラに切り替わると、この効果は消失する。 装備者が操作キャラの場合、魂異能ダメージ+12%〜20%、「通常攻撃」で魂異能ダメージを与えるたびに、自身の魂異能ダメージ+2%〜3.2%（最大10スタックまで）。この効果は0.3秒に1回しか発動しない。キャラ切り替え時に効果はリセットされる。 |
| 休息日 | 装備者の攻撃力+30%〜50%。また、調弧「日蝕」が使用可能になる。 調弧「日蝕」：日蝕の力を一時的に行使し、40秒間の日蝕を引き起こす。日蝕の間、装備者が敵を1体撃破するたびに終結エネルギーが6〜10回復する。期間中に最大5回まで発動可能（クールダウン300秒）。 |
| あなたを待ってる | 攻撃力+15%〜30%。 装備者が「EXレール終結」を発動後、3回の「追撃ダメージ」を与えた場合、チーム全員が12%〜20%の防御無視を獲得し、装備者は追加で10%〜20%の防御無視を獲得する。20秒持続、重複して発動すると持続時間が更新される。この効果はチーム内で1つのみ発動可能。 装備者がバイレールスキルを発動すると、チーム全員が敵の光異能ダメージ耐性を8%〜20%無視する。20秒持続、重複して発動すると持続時間が更新される。この効果はチーム内で1つのみ発動可能。 装備者が戦闘開始時に上記全ての効果を発動する。 |
| 不敵な綿 | 装備者が「EXレール終結」を発動後、自身の攻撃力+25%〜45%（10秒持続）。この効果はスタックしない。 |
| ヘテロシティの平穏 | 攻撃力+15%〜25%。 ボスユニットに与えるダメージ+15%〜25%。 調弧「見回りラット」を使用可能。 調弧「見回りラット」：「見回りラット」を召喚して戦闘を支援させる。「見回りラット」は継続的に攻撃を行い、毎回の攻撃で装備者の攻撃力の100%〜200%にあたるダメージを与える（30秒持続、クールダウン60秒）。 |
| 時間外を行く | 攻撃力+16%〜32%。 装備者が「バイレールスキル」を発動後、「荒時の迷宮」状態に入り、現在の「荒時」をクリアする。「荒時の迷宮」状態中に仲間が「バイレールスキル」または「サポートスキル」を発動すると、そのたびに「荒時」を1スタック獲得する（最大3スタックまで）。「荒時の迷宮」状態中に「EXレール終結」を発動すると、全ての「荒時」を消費して「荒時の迷宮」を終了し、「EXレール終結」のクリティカルダメージ+24%〜48%。1スタックにつき、装備者の「EXレール終結」が与えるクリティカルダメージが追加で+8%〜16%。一度に3スタックの「荒時」を消費した場合、追加でダメージ計算時に敵の防御力を12%〜24%無視する（70秒持続）。 |
| 現実の避難所 | 霊異能ダメージ+15%〜25%。 装備者のマーカーダメージ+10%〜15%。「EXレール終結」発動時、マーカーダメージ増加効果が20%〜30%に変化する（6秒持続）。この効果はスタック不可。 |
| 「傾世の雨」 | 装備者の「バイレールスキル」と「EXレール終結」による光異能ダメージ+30%〜42%。 装備者が「バイレールスキル」を発動後、自身の連環パワー+36〜72（15秒持続）。スタック追加時に持続時間が更新される。 |
