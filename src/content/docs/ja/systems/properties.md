## 物件

レジスCREST（バージョン1.1）と閑野雅邸（バージョン1.3）の購入には、シティ名声レベル13が必要である。閑野雅邸で栽培した作物は、シティスタミナを消費して売却し、ファンスに換えられる。

| 物件 | 価格（ファンス） | 異象家具の枠数 |
| --- | --- | --- |
| メゾンVINA | 200,000 | 7 |
| レジスEDEN | 1,000,000 | 9 |
| 天景の館 | 1,400,000 | 9 |
| パレス雲都 | 2,000,000 | 9 |
| 閑野雅邸 | 6,900,000 | 8 |
| レジスCREST | 7,500,000 | 10 |
| シルヴァ邸苑 | 8,000,000 | 11 |

## 異象家具

| 異象家具 | Lv.1の効果 | 物件 |
| --- | --- | --- |
| ホーホー警報 | 住宅に戻ると「ホーホー警報」が全ての指名手配値をリセットしてくれる | すべて |
| 無人着信 | 対応する住宅内にクイック転送できる | すべて |
| マモン | 「マモン」の専用異象界「貪欲の宝庫」を解放。クリアすると一定量のファンス報酬を獲得できる。 | メゾンVINA、シルヴァ邸苑 |
| ハムスターボール | 「ハムスターボール」への餌やりで、さまざまな品質の「駆動ブロック」を受け取れる。受取回数：1 | レジスEDEN、天景の館、閑野雅邸、レジスCREST |
| シルバー執事 | 執事が「異象界」探索のクイック完了サービスを解放。クイック完了回数：1 | レジスEDEN、天景の館、パレス雲都、レジスCREST |
| 古い郵便箱 | メールボックスで特別市内配達を受注できる。受注回数：1 | レジスEDEN、パレス雲都、閑野雅邸、レジスCREST |
| 壊れた木箱 | 「壊れた木箱」を開けると、一定数の「甲虫コイン」を獲得できる。デイリー受取上限：1 | 天景の館、パレス雲都、閑野雅邸、レジスCREST |
| 誰かのヘルメット | レース中の車両耐久度消耗が減少する | レジスEDEN、パレス雲都、レジスCREST |
| 夢織り結び | 「本性ピクセル」の上限が増加 | レジスEDEN、パレス雲都、閑野雅邸 |
| 圧縮ポムポムド | 72時間ごとに「モフモフコットン」を1個獲得する。収納上限：2 | メゾンVINA、レジスEDEN、シルヴァ邸苑 |
| 名無しの刃 | 出撃キャラの攻撃力が増加 | 天景の館、シルヴァ邸苑 |
| 休憩中の拳王 | 出撃キャラのクリティカルダメージが増加 | メゾンVINA、パレス雲都、レジスCREST |
| 空骸甲 | 出撃キャラの防御力が増加 | 天景の館、シルヴァ邸苑 |
| レプリカ幽霊車 | 出撃キャラの乗り物の耐久度消耗が減少 | レジスCREST、シルヴァ邸苑 |
| 古いスケボー | 出撃キャラのダッシュ、回避のスタミナ消費が減少 | 天景の館、シルヴァ邸苑 |
| 紙飛行機 | クライミング状態の操作キャラのスタミナ消費が減少する | メゾンVINA、シルヴァ邸苑 |
| 双魚旗 | 水泳状態の操作キャラのスタミナ消費が減少する | 閑野雅邸、シルヴァ邸苑 |
| メカニック | 車両修理サービスを提供 | すべて |
