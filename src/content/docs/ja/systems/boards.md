## 仕組み

| 項目 | ルール |
| --- | --- |
| 場所 | ボードはスカボロー市場にあり、弧盤研究プロジェクトは「弧盤ストア」-「弧盤研究プロジェクト」にある |
| 開放条件 | 本編クエスト「序章 - 新たな目的地 - 『骨董品屋エイボン』へ」をクリア |
| 限定ボード | 限定Sランクキャラ1名とAランクキャラ3名が登場する。プレイヤーはサイコロを振ってマスに止まる |
| 開催期間 | 3週間。水曜日のメンテナンス終了後から水曜日の05:59 (UTC+8) まで。「還らざる路」は2週間だった |
| サイコロ報酬 | ボードごとにギフト画面があり、累計50、120、200回でグライダースキン、乗り物スキン、コスチュームを受け取れる。同じアイテムはマスから先に手に入ることもある |
| サイコロの回数 | ボード名ごとに保持され、同じボードの復刻に引き継がれる |
| Aランクキャラ | [ミント](/ja/characters/mint/)、[エドガー](/ja/characters/edgar/)、[アドレー](/ja/characters/adler/)の組か、[ハニア](/ja/characters/haniel/)、[海月](/ja/characters/aurelia/)、[翳](/ja/characters/skia/)の組 |
| 限定弧盤 | 限定キャラ1名につき限定Sランク弧盤が1つあり、専用の弧盤研究プロジェクトでボードと同じ期間に開催される |
| 弧盤研究プロジェクトのコスト | トリプルキー。バージョン1.2以降は「反逆キー」などプロジェクト専用のキーも使える |
| 常設ボード | Game8とPrydwenによると、常設で、常設のSランクとAランクのキャラが登場し、独自の排出テーブルと天井を持つ |

Prydwenによると、限定Sランクキャラの確定までのカウントは限定ボードから次の限定ボードへ引き継がれ、弧盤研究プロジェクトと常設ボードはそれぞれ独自のカウントを持つ。このカウントはギフト画面のサイコロの回数とは別である。
