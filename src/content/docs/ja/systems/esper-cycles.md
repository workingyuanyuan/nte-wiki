## 連環

6つの属性は、光、霊、呪、闇、魂、相の順に環をなし、相の次は光に戻る。「充蓄」と「失諧」は隣り合う3つの属性を組み合わせる。

Prydwenによる発動条件：連環値が満タンの時に、フィールド上のキャラと隣り合う属性のキャラに切り替えると、入ってきたキャラの登場時のスキルが反応を起こす。零号攻略组によると、連環値は通常攻撃とバイレールスキルでのみたまり、サポートスキルとEXレール終結ではたまらない。

## 反応

| 反応 | 属性 | 効果 |
| --- | --- | --- |
| 創生 | 光、霊 | ターゲットの近くに「創生株」が生え、「創生花」を5輪咲かせる。2秒ごとに創生花が1輪、範囲内のターゲットに飛んで爆発し、範囲ダメージを与える。創生株は同時に最大3株 |
| 覆紋 | 霊、呪 | 12秒間、ターゲットが受けた霊または呪のダメージに、そのダメージの20%分の追加攻撃が加わる |
| 濁燃 | 呪、闇 | ターゲットは15秒間、継続ダメージを受ける |
| 暗星 | 闇、魂 | ターゲットは5秒間「暗星」状態になり、終了時に大きな精神ダメージを受ける |
| 浸染 | 魂、相 | 12秒間、ターゲットが受ける魂と相のダメージが20%増える |
| 延滞 | 相、光 | 5秒間、ターゲットの移動と攻撃が遅くなり、時間とともに戻る。繰り返し「延滞」をかけると早く切れる |
| 充蓄 | 相、光、霊 | 創生花が「延滞」中のターゲットに命中すると、操作キャラが終結エネルギーを追加で10得る |
| 失諧 | 呪、闇、魂 | 「暗星」と「濁燃」を同時に受けているターゲットは、ブレイク耐性の一部を失う |

## 誰のステータスが使われるか

切り替えで起きる反応には2人のキャラが関わる。フィールドにいたキャラと、切り替えで入ってきたキャラである。どちらのステータスが使われるかは反応によって異なる。

| 反応 | ステータスが使われるキャラ |
| --- | --- |
| 創生、濁燃、暗星 | 2人のうち連環パワーとレベルが高い方。入ってきたか出ていったかは問わない。「創生」と「濁燃」はそのキャラの属性のダメージを与える |
| 覆紋、浸染 | 効果中に霊または呪のダメージ（覆紋）、魂または相のダメージ（浸染）を与えるキャラ |

反応ダメージのうち、通常クリティカルが発生するのは「濁燃」だけである。そのクリティカル率は50%で固定され、ステータスが使われるキャラのクリティカルダメージを用いる。GameWithはさらに、連環パワーはダメージを与えない「延滞」、「充蓄」、「失諧」には影響しないとしている。

NGAフォーラムのプレイヤー分析によると、「創生」、「濁燃」、「暗星」では、ゲームは各キャラの反応の基礎ダメージ（レベルとともに上がる）に連環パワーの係数を掛けた値を比べる。同じ値の場合は、登場時の攻撃で反応を起こしたキャラが使われ、その選択は反応の発動時に確定する。「覆紋」と「浸染」の20%は連環パワー0の時の値で、ダメージを与えるキャラの連環パワーに応じて上がる。

零号攻略组によると、レベル80での反応の基礎ダメージは「創生」9,000、「濁燃」2,700、「暗星」45,000で、連環パワーの係数は1 + 連環パワー ÷ 600である。「創生」と「濁燃」の防御と耐性は、ステータスが使われるキャラとその属性で計算される。そのキャラは反応の間は変わらないが、そのキャラにかかったバフはその時点の状態で反映される。防御無視の効果が切れると、それ以降の創生花は防御を無視しない。異能連環の反応はどれもダメージバフの影響を受けない。

零号攻略组によると、「覆紋」と「浸染」は20%に24 × 連環パワー ÷ (連環パワー + 180) ポイントを加え、連環パワー100では28.57%になる。創生花は「覆紋」を発動させない。新しい「濁燃」はターゲットにある「濁燃」を置き換え、重ならない（[残虹](/ja/characters/zankou/)のパッシブを除く）。「暗星」は防御の影響を受けず、常に精神ダメージを与える。1体のターゲットにかかった2つの「暗星」は、ステータスが使われるキャラが異なれば共存してそれぞれ爆発し、同じキャラなら新しい「暗星」が前の「暗星」をすぐに爆発させる。「『暗星』状態が終了した際」の効果は、ターゲットにある最後の「暗星」が時間切れで爆発した時に発動し、先に爆発させられた「暗星」では発動しない。
