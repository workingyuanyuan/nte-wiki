## プラットフォーム

| プラットフォーム | 開始 | 備考 |
| --- | --- | --- |
| Windows PC（公式ランチャー） | 2026-04-29 | インストールパスは半角英数字のみにする |
| iOS（App Store） | 2026-04-29 | |
| Android（Google Play） | 2026-04-29 | |
| Mac（App Store） | 2026-04-29 | |
| Google Play PC | 2026-04-29 | |
| PlayStation 5、PlayStation 5 Pro | 2026-04-29 | PSNアカウントかメールアドレスでログイン |
| Steam | 2026-07-08に告知 | 他のプラットフォームと同じバージョン。支払いにはゲームを起動したSteamアカウントが使われる |
| Epic Games Store | 2026-07-08に告知 | 他のプラットフォームと同じバージョン。支払いにはゲームを起動したEpicアカウントが使われる |
| Samsung Galaxy Store | 2026-07-08に告知 | 規約と仕様は他のプラットフォームと同じ |

## サーバーとアカウント

| 項目 | ルール |
| --- | --- |
| サーバー | Asia、America、Europe、SEA |
| サーバー間の進捗 | 共有されない。各サーバーは独立している |
| プラットフォーム間の進捗 | 同じアカウントでログインすれば、同じサーバー上で共有される |
| UID | 全プラットフォームで共通で、ランダムに割り当てられる |
| iOSとMacのログイン | Facebook、Google、Sign in with Apple、メールアドレス |
| Windows PC、Steam、Epic、Galaxy Storeのログイン | Facebook、Google、メールアドレス |
| PlayStationのログイン | PSNアカウント、メールアドレス |
| サードパーティアカウント | 異なるサービスで作ったアカウントは別のアカウントで、データは共有されない |
| サポート | ゲーム内の設定、Support Center |

## 動作環境

| プラットフォーム | 最低 | 推奨 |
| --- | --- | --- |
| PCのプロセッサー | Intel Core i7-10700 | Intel Core i7-12700以上 |
| PCのグラフィック | NVIDIA GeForce GTX 1660またはAMD Radeon RX 5600 | NVIDIA GeForce RTX 3060またはAMD Radeon RX 6700以上 |
| PCのOS | Windows 10 64ビット | Windows 10 64ビット |
| PCのストレージ、公式ランチャー | 空き容量60 GB、さらに展開中は一時的に60 GB | SSDにインストール |
| Steam版PC | メモリ16 GB、DirectX 11、70 GB。Snapdragon XとAdreno X1も記載 | メモリ32 GB、DirectX 12、70 GB。Snapdragon X2 EliteとAdreno X2も記載 |
| Android | Snapdragon 855またはMediaTek Dimensity 8000、Android 10.0、空き容量20 GB | Snapdragon 8 Gen 2、Snapdragon 8 Gen 3、MediaTek Dimensity 9200以上 |
| iOS | iPhone 12 Pro Max、iOS 15.0、空き容量20 GB | iPhone 14 Pro以降、iOS 17.0以降 |

## アップデート方法

| プラットフォーム | 手順 |
| --- | --- |
| PC | ゲームを終了し、ランチャーを再起動して「アップデート」をクリック |
| Android | ゲームを起動し、アップデートの案内に従う |
| iOSとMac | App Storeでダウンロードまたはアップデート |
| PlayStation | ホーム画面でNTEを選び、OPTIONSボタンを押して「アップデートを確認」を選ぶ |
| Steam | ゲームを終了し、Steamクライアントを再起動して「ライブラリ」からNTEを選び、「アップデート」をクリック |

バージョンアップデートは水曜日の06:00から11:00 (UTC+8) に行われ、メンテナンス中はログインできない。
