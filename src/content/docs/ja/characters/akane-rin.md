## スキル

明音凛は「ストブレ」で「弦音」を溜め、「リズムウエーブ」で単体向けの「ハーモナイズ」か範囲の「ライブエリア」を設置して通常攻撃を伝導させる。その後「弦音」30を消費して「オーバードライブ」を放ちつつ、「サウンドブラスト」による2段階の「ソロ・パート」の時間を使う。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | ストブレ、ステージダイブ、極限反撃：リバーブ | 「ストブレ」は最大4段の相属性攻撃を行い、明音凛がダメージを与えるたびに「弦音」を最大30まで獲得する。「ステージダイブ」は空中から急降下し、相属性の範囲ダメージを与える。「極限反撃：リバーブ」は極限回避の後に発動し、相属性ダメージを与え、「ストブレ」の段数を維持する。 |
| バイレールスキル | リズムウエーブ、オーバードライブ | 「リズムウエーブ」を押すとターゲット1体に「ハーモナイズ」を付与し、長押しで「ライブエリア」を展開する。どちらも通常攻撃と「リバーブ」を追加ダメージ付きで伝導させ、同時に存在できるのは一方のみである。「弦音」が30のとき、「オーバードライブ」を発動して「弦音」を消費し、無敵状態で大ダメージを与える。 |
| EXレール終結 | サウンドブラスト | 相属性の範囲多段ダメージを与え、よろめき耐性が増加する「ソロ・パート」状態に入る。この状態は「ハーモナイズ」と「ライブエリア」から独立している。「ソロ・パート」の終了前に1回だけ手動で再発動でき、範囲ダメージを与えて状態を早めに終える。非戦闘状態の間、終結エネルギーを獲得する。 |
| サポートスキル | キーチェンジ | 激しく弦をかき鳴らし、相属性ダメージを1回与える。 |
| パッシブ 1 | 絶対音感 | 「延滞」強化：チームが初めて「延滞」を発動した後、戦闘を離脱するまで、「ハーモナイズ」を付与されたターゲットや「ライブエリア」内のターゲットに定期的に「延滞」を付与する。「延滞」を再付与すると、バイレールスキルダメージとみなされる相属性の追加ダメージが発生し、各ターゲットの残りの「延滞」時間に応じて増加する。 |
| パッシブ 2 | ステラ・パッション | 「サウンドブラスト」の発動後、明音凛の攻撃力を高める。この効果はスタックせず、再度発動すると持続時間が更新される。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 教室のギター譜 | 強化バイレールスキル「オーバードライブ」を発動するたびに、明音凛の基礎攻撃力の1000％に相当するHPを即座に1回回復する。さらに明音凛の防御力+50％、よろめき耐性+60％、15秒持続。 |
| 楽器屋のカポタスト | 「ハーモナイズ」のマーカーを付与された敵、または「ライブエリア」内にいる敵の相異能ダメージ耐性-12％。 |
| 木陰のタイムカプセル | 短押しで「バイレールスキル：リズムウエーブ」の「ハーモナイズ」を発動する時、該当スキルの固定倍率+1000％。「ライブエリア」の半径+30％、長押しで「バイレールスキル：リズムウエーブ」の「ライブエリア」を発動する時、範囲内の敵を引き寄せる。 |
| イヤホンノイズ | 強化バイレールスキル「オーバードライブ」を発動後、明音凛のクリティカルダメージ+30％、15秒持続。 |
| 絆のメトロノーム | 「ハーモナイズ」の通常攻撃伝導の倍率増加効果が64％まで増加する。「ライブエリア」の通常攻撃伝導のダメージ増加効果が90％まで増加する。 |
| ステージの超新星 | 「ステラ・パッション」により、明音凛は追加で防御無視16％を獲得する。 |
| 共振 3：全音階 | 明音凛の通常攻撃、バイレールスキル、EXレール終結のスキルレベル+1。戦闘開始時、即座に「弦音」が満タンになる。強化バイレールスキル「オーバードライブ」の固定倍率+800％。「EXレール終結：サウンドブラスト」2段目の固定倍率+1000％。 |
| 共振 6：ポリフォニー | 強化バイレールスキル「オーバードライブ」を発動するたびに「弦音」が10返還される。強化バイレールスキル「オーバードライブ」を発動後、明音凛のクリティカルダメージ+64％、25秒持続。 |
