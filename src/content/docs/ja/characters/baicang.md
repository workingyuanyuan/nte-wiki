## スキル

白蔵は通常攻撃、回避からの連携、「ご教示いただこう」の派生技で、現在HPを消費して言霊文字「祝」「黙」「詈」を生成する。そして領域「判決と秋」の中でそれらを発動させ、追加ダメージ、回復、低HPの敵への即死効果を発揮する。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 形名参同、形状無き言の葉、忌無き言の葉、風中一閃、極限反撃：虚実反転、離れぬ影 | 「形名参同」は最大5段の呪属性攻撃を行い、「離れぬ影」により3回命中するごとに現在HPを消費して言霊文字「祝」を生成する（最大3つ）。「形状無き言の葉」と「忌無き言の葉」は起爆する呪令を3枚放つ。「風中一閃」は急降下攻撃で、「極限反撃：虚実反転」は「祝」を生成する。 |
| バイレールスキル | ご教示いただこう、天地の心、黙念、この罪状にて | 「天地の心」は地脈の文字で目標地点を攻撃する。回避の後にバイレールスキルを押すと「黙念」を発動し、単体に呪属性ダメージを与えて言霊文字「黙」を生成する。「形状無き言の葉」または「忌無き言の葉」の後に発動すると「この罪状にて」となり、範囲ダメージを与えて言霊文字「詈」を生成する。 |
| EXレール終結 | 判決と秋 | 領域を展開して言霊状態に入り、呪属性の継続ダメージを与え、HPが一定以下のターゲットを撃破する。一時的に致死ダメージを無効化し、無効化すると領域が終了して記録したダメージを分散して受ける。「黙」は単体への追加ダメージ、「詈」は範囲ダメージ、「祝」は回復とダメージを発生させる。 |
| サポートスキル | サボり終了 | 短く力を溜めて呪令を描き、呪属性の範囲ダメージを1回与え、命中するとターゲットに言霊文字「黙」を1つ生成する。 |
| パッシブ 1 | 適度な悪趣味 | 「濁燃」強化：「濁燃」状態のターゲットに言霊文字が生成されたとき、同じ効果の「濁燃」をもう1回付与する。 |
| パッシブ 2 | 適度出勤 | 白蔵の攻撃力を高め、E.T.D第4小隊の仲間と連携効果を発揮する。翳のステルス中に切り替えると攻撃して言霊文字「黙」を生成し、ファルディーヤのHPが低下すると攻撃してファルディーヤを治療し、レクイエムのコウモリ状態中に切り替えるとスーパージャンプを発動する。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| ヨッ、隊長！ | 「判決と秋」の持続中に「黙」の文字が発動すると、白蔵の次に使用するスキルダメージ+30％、スタック可能。「詈」の文字が発動すると、白蔵のスキルのクールダウン-4秒、スタック可能。スキルがクールダウン中でない場合は、次回使用時に効果が発動。 |
| 招魂の旗 | あの山並みのように、幾重にも重なっていく。任意の言霊文字を1つ生成するたびに、白蔵の攻撃力+6％。最大4スタックまで、1スタックにつき10秒持続。 |
| 悪しき呪いを口にした瞬間 | 生成できる言霊文字の上限が4つまで増加する。 |
| あるいは祝詞 | 「判決と秋」の持続中、言霊文字が1つ発動するたびに、白蔵は最大HPの5%を追加で回復する。 |
| 月の光に乾杯 | まだ終わらないよ。「判決と秋」の持続時間が16秒に延長される。 |
| 五色の中の白 | 「判決と秋」の持続中、白蔵のクリティカル率+30％。 |
| 共振 3：典籍封蔵 | 「形名参同」「ご教示いただこう」「判決と秋」のスキルレベルが+1。 |
| 共振 6：この場に駐留 | たまには隊長らしく庇護する。「判決と秋」の持続中、範囲内のチーム全員の攻撃力+20％、さらに全員が「即刻斬殺」効果を発動可能となる。 |
