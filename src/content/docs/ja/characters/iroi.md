## スキル

イロヒは通常攻撃、バイレールスキル、サポートスキル、そして味方が「トランス」に入ることで「白昼夢」を溜める。バイレールスキルは回復と攻撃力バフを行い、味方を「トランス」にする。EXレール終結は「白昼夢」を消費して回復の夢を開くか、「トランス」の味方1人を一時的に復活させる攻撃の夢を開く。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 共同さぎょう、まどろみの刻、明晰夢、目覚めの鐘、無意識の応答 | 「共同さぎょう」は子羊で最大5段の攻撃を行い、「目覚めの鐘」は落下攻撃を行い、「無意識の応答」は極限回避の後に反撃してブレイク耐性を削る。いずれも「白昼夢」を溜める。通常攻撃を長押しすると「白昼夢」を消費して「まどろみの刻」を最大3段放ち、もう一度長押しするとモルペウスを呼び出して「明晰夢」を撃ち続ける。 |
| バイレールスキル | 自己連続性の仮説、自己同一性の拡張 | 押すと「自己同一性の拡張」を発動し、チームを回復して、イロヒの基礎攻撃力に基づく攻撃力ボーナスを与え、3匹の子羊で敵を引き寄せ、「白昼夢」を溜める。長押しの「自己連続性の仮説」は味方3人を戦闘終了まで「トランス」にする。パッシブとして、戦闘不能になった味方は「トランス」に入り、「白昼夢」が溜まる。 |
| EXレール終結 | 38億年の蜃気楼 | 「白昼夢」が尽きるまで消費し続ける夢を開く。「白昼夢」が一定量未満なら角の門の夢を開き、チームを持続的に回復する。一定量以上なら象牙の門の夢を開き、霊属性ダメージを与え、「まどろみの刻」と「明晰夢」を消費なしで使えるようにし、「トランス」の味方1人を一時的に復活させる。 |
| サポートスキル | バンッ！ | モルペウスで前方を攻撃して霊属性ダメージを1回与え、チーム全員を回復し、「白昼夢」を溜める。 |
| パッシブ 1 | ミラージュ | 「創生」強化：創生株が存在し続けると「創生株複製体」を1株生成し、「複製創生花」を近くのターゲットに放つ。 |
| パッシブ 2 | 神経同調 | 治療を行うと、チーム全員に追加の防御無視を付与する。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 反復性囚人のジレンマ | イロヒが場にいない時、毎秒「白昼夢」を3回復する。同時に「白昼夢」の蓄積効率+30％、かつ戦闘開始時に「白昼夢」の蓄積量が最大になる。 |
| 戦略：「因果応報」 | 任意の仲間がスキルを発動すると、イロヒはモルペウス/イケロス/パンタソスのうちいずれか1体をランダムに召喚し、支援攻撃を1回行って合計でイロヒ自身の攻撃力の200％分のダメージを与え、味方全体のHPをイロヒ自身の攻撃力の120％分回復する。クールダウン5秒。 |
| 戦略特性：善意 | イロヒの治療効果+36％。 |
| 戦略特性：報復 | 「トランス」状態中の子羊たちの攻撃倍率が増加する。モルペウス：「もう少し寝てて」の倍率増加。増加値は基礎倍率の30％に相当する。「もっと寝てて」の倍率増加。増加値は基礎倍率の30％に相当する。イケロス：「お注射しよう」の倍率増加。増加値は基礎倍率の30％に相当する。「いっぱい打とう」の倍率増加。増加値は基礎倍率の30％に相当する。パンタソス：「歌でも聴いて」の倍率増加。増加値は基礎倍率の30％に相当する。「良くない？」の倍率増加。増加値は基礎倍率の30％に相当する。 |
| 戦略特性：明晰 | 「神経同調」効果追加：イロヒの基礎攻撃力の15％分、チーム内のキャラの攻撃力を増加させる。20秒持続。 |
| 戦略特性：寛容 | イロヒの「EXレール終結：38億年の蜃気楼」で復活したキャラは、HPを100％回復し、連環値を50、EXレール終結エネルギーを50獲得する。 |
| 共振 3：万物の霊長たる者 | 「通常攻撃：共同さぎょう」「バイレールスキル：自己連続性の仮説」「EXレール終結：38億年の蜃気楼」のスキルレベル+1。イロヒがチームにいる時、チーム全員の防御力+30％。 |
| 共振 6：自称・宇宙の最高傑作 | イロヒがチームに編成されている時、チーム全員のクリティカルダメージ+25％。チーム内に「トランス」状態の仲間が1人いるごとに、イロヒの与ダメージ+15％、クリティカル率+5％。 |

## 仕様の詳細

- 「白昼夢」の上限は100。[^1]
- 「白昼夢」の一定量は30で、達するとゲージの目盛りが星に変わり、左のアイコンが月から太陽に変わる。[^2]
- 「共同さぎょう」の1セットで「白昼夢」が20、バイレールスキルで16、サポートスキルで10溜まるため、バイレールスキル2回で一定量に届く。[^3]
- 「白昼夢」が一定量（30）に達しているとき、通常攻撃の長押しは全4段で、「まどろみの刻」3段の後に「明晰夢」が続く。「明晰夢」は敵を追尾するミサイルを約8秒撃ち続け、敵の攻撃で中断されることがある。[^4]
- 「明晰夢」の間にキャラを切り替えても射撃は止まらず、イロヒは無敵になる。[^5]
- 「無意識の応答」、サポートスキル、バイレールスキル、EXレール終結の動作中に通常攻撃を先に長押しすると、「まどろみの刻」の3段目から始まる。[^6]
- 「共同さぎょう」の3段目を放った直後に回避すると後隙をキャンセルでき、ダメージはそのまま入る。[^7]
- コマ送りで測った所要時間：「共同さぎょう」3段＋回避は2.5秒、3段＋落下攻撃は2.67秒、3段＋キャラ切り替えは3秒、長押し通常攻撃の3・4段目＋キャラ切り替えは8秒。[^8]
- バイレールスキルが敵を引き寄せる範囲は[早霧](/ja/characters/sakiri/)より広く、速さも上で、イロヒの背後の敵も引き寄せる。[^9]
- イロヒの回復量は攻撃力の合計値に応じて増える。[^10]
- バイレールスキルを長押しすると、「トランス」になった味方1人につき子羊が1匹召喚され、代わりに戦う。[^11]
- 子羊はフィールドに常駐して共に戦い、常に無敵で、イロヒのステータスを引き継ぎ、決まったスキル順で攻撃する。[^12]
- イロヒの連環値が満タンになると、子羊のアイコンを押してサポートスキルを発動できる。[^13]
- 象牙の門の夢の間の一時的な復活を除き、「トランス」中の味方は回復アイテムや切り替えキーでは戻せず、戦闘終了後に元に戻る。[^14]
- EXレール終結の回復エリアは操作中のキャラについて移動し、控えの味方も回復し続ける。[^15]
- 夢の間は「白昼夢」が溜まらない。[^16]
- 「白昼夢」16で、夢はちょうど2秒続く。[^17]
- 夢の間に始めた長押し通常攻撃は、「白昼夢」が尽きた後も出る。EXレール終結の直後に通常攻撃を長押しし、イロヒが跳んだ時にもう一度通常攻撃を押す。[^18]
- EXレール終結で一時的に復活した味方は、最大12.5秒とどまる。[^19]
- バイレールスキル、EXレール終結、サポートスキルのレベルを上げると主に回復量が増え、攻撃力ボーナス、防御無視、「創生株複製体」は変わらない。[^20]
- 「ミラージュ」の「創生株複製体」は創生株が生えた3秒後に現れ、創生株の上限に数えられず、0.5秒ごとに「複製創生花」を1輪放ち、計20輪、10秒続く。[^21]
- 「神経同調」の防御無視5%（20秒間）は重ならない。[^22]
- ワールドで猫や犬をなでると、ランダムな育成アイテムを獲得できる。1日最大3回、累計999回まで（パッシブ「9500万年前の分岐」）。[^23]
- ギアを最大まで育てたイロヒで計算すると、戦略：「因果応報」は1回の発動で約16,000ダメージ増える。[^24]
- 戦略特性：寛容は、復活した味方固有のエネルギー（[潯](/ja/characters/hotori/)や[真紅](/ja/characters/shinku/)のものなど）を回復しない。[^25]
