## スキル

海月は「華麗なるカデンツァ」で「カデンツァ」状態に入り、「マルカート」でクラゲに乗って定期的にクラゲ弾を放つ。「クレッシェンド」の攻撃力スタックを重ねつつ、「カノン」で敵をまとめ、「暗星」の終了後に魂属性の追加ダメージを与える。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | アカペラ、レガート、マルカート、スタッカート、極限反撃：シンコペーション | 「レガート」は最大4段の魂属性攻撃を行う。「マルカート」は移動中に回避を長押しするとクラゲに乗り、スタミナが少なくなるまで定期的にクラゲ弾を放つ。この間の極限反撃はクラゲ弾を4発放つ。「スタッカート」は空中から急降下し、「極限反撃：シンコペーション」は極限回避の後に反撃してブレイク耐性を削る。 |
| バイレールスキル | 華麗なるカデンツァ | 魂属性の範囲ダメージを1回与え、「カデンツァ」状態に入る。 |
| EXレール終結 | カノン | 近くのクラゲを集め、魂属性の範囲ダメージを6回与え、ターゲットを少し引き寄せる。 |
| サポートスキル | 不協和音 | クラゲに攻撃を指示し、命中すると魂属性の範囲ダメージを1回与える。 |
| パッシブ 1 | ハーモニクス | 「暗星」強化：ターゲットの「暗星」状態が終了した後、そのターゲットに魂属性ダメージを3回与える。 |
| パッシブ 2 | クレッシェンド | クラゲ弾がターゲットに命中すると海月の攻撃力が上がり、最大10回までスタックする。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 未来への序曲 | 「カデンツァ」状態中、海月のクリティカル率+15％。 |
| 特別なナンバー | 極限回避を成功させるか、「サポートスキル：不協和音」を発動すると、海月は5秒間の「カデンツァ」状態に入る。すでにこの状態にある場合、持続時間が5秒追加される（最大12秒まで）。 |
| 三重奏の休止符 | 「カデンツァ」状態中、海月が発動する「EXレール終結：カノン」の与ダメージ+20％。 |
| 五線譜の余白 | 「通常攻撃：マルカート」を発動すると、海月の防御力+20％。 |
| 名もなき一曲 | 「EXレール終結：カノン」のクリティカル率+15％。 |
| 往日のフーガ | 「クレッシェンド」効果が最大20スタックまで可能になる。「バイレールスキル：華麗なるカデンツァ」を発動すると、直ちに「クレッシェンド」効果を10スタック獲得する。 |
| 共振 3：万象のユニゾン | 「通常攻撃：アカペラ」、「バイレールスキル：華麗なるカデンツァ」、「EXレール終結：カノン」のスキルレベル+1。 |
| 共振 6：共鳴セッション | 「カデンツァ」状態に入る、または「カデンツァ」状態の持続時間が延長された時、チーム全員の魂異能ダメージ+8％（15秒持続、スタック追加時に持続時間が更新される）。 |
