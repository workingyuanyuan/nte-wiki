## スキル

ミントは場に出て戦う霊属性のアタッカーで、5段コンボ、スタミナを消費して回転する「竜巻」、突進攻撃、多段の範囲斬撃をつなげる。場にいる間は防御力とよろめき耐性が上がり、「創生」強化で創生花のダメージ範囲が広がる。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 満点収容術、正義執行、キャラメルクランチ、竜巻 | 最大5段の霊属性連続攻撃を行い、空中からの急降下攻撃「正義執行」もある。通常攻撃を長押しすると「竜巻」になり、回転し続けて周囲に霊属性ダメージを与え、スタミナを消費する。極限回避の後は「キャラメルクランチ」で範囲に霊属性ダメージを与え、ブレイク耐性を削る。 |
| バイレールスキル | 奥義・スーパー連風爪 | 前方へ突進して元の位置に戻り、ルート上の敵に霊属性の範囲ダメージを2回与える。 |
| EXレール終結 | 奥義・疾風斬 | 双刀に風を集めて霊属性の範囲ダメージを複数回与え、最後の一撃で大きな霊属性の範囲ダメージを与える。 |
| サポートスキル | 奥義・無敵タイフーン | 力を溜めて空中へ跳び、貫通攻撃で霊属性の範囲ダメージを1回与える。 |
| パッシブ 1 | 変身！スーパーミント！ | 「創生」強化。創生花の命中時のダメージ範囲を広げる。 |
| パッシブ 2 | これで終わりっ！ | 場にいる間、ミントの防御力とよろめき耐性が上がる。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 特殊派遣 | 「極限反撃：キャラメルクランチ」が敵に命中すると、「バイレールスキル：奥義・スーパー連風爪」のクールダウンがリセットされる。この効果は3秒に1回しか発動しない。 |
| 追加試験 | 「バイレールスキル：奥義・スーパー連風爪」のダメージ+40％。 |
| 皆勤手当 | 敵に「創生」または「覆紋」反応を発動した後、ミント自身の攻撃力+15％（15秒）。 |
| お昼休憩 | ミントが場に一体のみ存在する敵にダメージを与えると、自身のクリティカル率+12％。 |
| 第一直感 | ミントが「バイレールスキル：奥義・スーパー連風爪」を発動すると、自身のクリティカルダメージ+25％（6秒持続）。 |
| 精鋭隊員 | HPが40％未満のターゲットに与えるダメージが追加で+15％。 |
| 共振 3：ミントタピオカ | 「通常攻撃：満点収容術」「バイレールスキル：奥義・スーパー連風爪」「EXレール終結：奥義・疾風斬」のスキルレベル+1。 |
| 共振 6：ふわっふわムース | 「バイレールスキル：奥義・スーパー連風爪」を発動すると、ミントの連環値が追加で+2。 |
