## スキル

リンコは通常攻撃で「ハーモニクス」を溜め、待機中に「小娘！」マークを付与して、仲間またはさだちゃんを呼び出し、その属性に応じた「シンクロ攻撃」を行わせる。EXレール終結で異能オーバーロード状態に入って「共鳴領域」を展開し、「シンクロ攻撃」を連続で発動させ、仲間のサポートスキルを追加攻撃に変える。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 悪霊CQC、悪霊大ビンタ！、悪霊式・登場！、悪霊・電撃戦！、お返しは『手』で！ | 最大5段の霊属性攻撃で「ハーモニクス」を溜め、「全帯域パルス」の「シンクロ攻撃」を強化する。長押しの「悪霊大ビンタ！」、空中からの急降下攻撃「悪霊式・登場！」、極限回避の反撃「お返しは『手』で！」もある。待機中は「悪霊・電撃戦！」で定期的にさだちゃんを送り出して急襲させ、「小娘！」マークを付与する。 |
| バイレールスキル | 全帯域パルス | 霊属性攻撃を最大4回与え、選択ホイールを開いて仲間またはさだちゃんを呼び出し、その属性に応じた「シンクロ攻撃」を行わせる。「ハーモニクス」をすべて消費して「シンクロ攻撃」のダメージバフを追加するか、行動不能またはいない仲間1人ごとにさだちゃんをさらに強化する。 |
| EXレール終結 | 超負荷共鳴 | 異能オーバーロード状態に入り、「共鳴領域」を展開して最大3名の仲間とシンクロする。バイレールスキルで最大3回の「シンクロ攻撃」を発動し、霊属性の範囲攻撃が追加される。最後にターゲットのデバフ数に応じて強まる霊属性の爆発を起こす。その後は領域内の仲間のサポートスキルが追加の「シンクロ攻撃」扱いになる。 |
| サポートスキル | 悪霊左ストレート！ | さだちゃんと共に攻撃し、霊属性の範囲ダメージを与える。「小娘！」マークの破壊、「全帯域パルス」または「超負荷共鳴」の発動時に仲間を呼び出して「シンクロ攻撃」を行わせ、「シンクロ攻撃」のダメージは「悪霊左ストレート！」のレベルに応じて高まる。 |
| パッシブ 1 | 弱点感知 | 「覆紋」強化。リンコがチームにいる間、「覆紋」による追加攻撃の基礎ダメージを高め、「覆紋」状態のターゲットが受ける追加攻撃ダメージを増やす。 |
| パッシブ 2 | 精密シンクロ | 「シンクロ攻撃」を発動したキャラの属性に対応する、ターゲットの異能ダメージ耐性を下げる。異なる属性の耐性減少は共存し、同じ属性では重ならず、再発動で持続時間が更新される。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 万物ラジオ接続！ | リンコが場にいない時、「通常攻撃：悪霊・電撃戦！」の発生間隔-25％。 |
| おばけって可愛い！ | 「EXレール終結：超負荷共鳴」の霊異能の爆発ダメージ倍率+30％。 |
| 繋がりあう孤島！ | 「EXレール終結：超負荷共鳴」を発動すると、「バイレールスキル：全帯域パルス」のクールダウンがリセットされる。 |
| お星様の内緒話！ | 「共鳴領域」内では、「シンクロ攻撃」が発動するたび、追加で霊異能の範囲ダメージを1回与える。現在の「EXレール終結：超負荷共鳴」スキルレベルでの倍率は{0}％となる。この攻撃は「小娘！」マークを消費して「シンクロ攻撃」を誘発できる。 |
| 全帯域へ愛を！ | 「バイレールスキル：全帯域パルス」によって発動した「シンクロ攻撃」は連環効果を発動できる。選択した仲間がリンコと連環を発動できない場合は、その「シンクロ攻撃」の与ダメージ+50%。 |
| 世界のこだま！ | リンコがチームにいる時、チームキャラの「シンクロ攻撃」のクリティカル率が追加で+25％、仲間の「シンクロ攻撃」はチャージ効果を獲得できる。 |
| 共振 3：重なりあう鼓動！ | 「サポートスキル：悪霊左ストレート！」、「バイレールスキル：全帯域パルス」、「EXレール終結：超負荷共鳴」のスキルレベル+1。リンコ自身の攻撃力+20％。 |
| 共振 6：万物のシンクロ！ | 「共鳴領域」の持続時間+5秒、期間中チーム全員の霊異能および呪異能ダメージ+30％。 |

「チャージ効果」は終結エネルギーの獲得を指し、異能連環「充蓄」ではない。韓国語版のゲームテキストは、リンコとその仲間が終結エネルギーを得ると明記している。
