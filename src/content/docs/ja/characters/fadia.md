## スキル

ファルディーヤはHPが1を上回っている間、仲間が受けるダメージの一部を自分に移し、HPが1になると受けたダメージを仲間と分担する。バイレールスキルで敵1体を結び付けて自分の被ダメージを分担させ、一定量のHPを失うとEXレール終結がチャージされ、強化される。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 会話中断の否定、目撃された犠牲、墜落偽装の軽蔑、極限反撃：回避条件作用 | 「会話中断の否定」は最大5段の攻撃を行い、「墜落偽装の軽蔑」は空中から落下攻撃を行う。「極限反撃：回避条件作用」は極限回避の後に反撃し、ブレイク耐性を削る。「目撃された犠牲」はHPが1を上回っている間、仲間のダメージをファルディーヤに移し、HPが1の時は受けたダメージを分担させる。 |
| バイレールスキル | 存在証明の体験 | 魂属性の範囲ダメージを与え、範囲内で最大HPが最も高い敵に「破滅体験」を付与する。効果が終わるか、共有ダメージが上限に達するか、双方が戦闘を離脱するまで、そのターゲットはファルディーヤの被ダメージの一部を分担する。 |
| EXレール終結 | 痛みを狂喜に | 「敵神者」状態に入り、精神ダメージを6回与えてHPを回復する。再び「会話中断の否定」を発動すると、精神ダメージの追撃を最大5段行う。HP減少量が「破滅しきい値」に達するとエネルギーが満タンになり、「敵神者」状態が終わるか別の行動で中断されるまで、ダメージと回復量が上がる。 |
| サポートスキル | 脱落者の嘲笑 | 十字の盾を振り回し、魂属性の範囲ダメージを1回与える。 |
| パッシブ 1 | 罪悪感のるつぼ | 「暗星」強化：「暗星」が終了すると、味方全員がターゲットから最大HPを吸収する。吸収量にはファルディーヤの基礎最大HPに基づく上限があり、戦闘を離脱すると双方のステータスは元に戻る。 |
| パッシブ 2 | 拒絶と強奪 | ファルディーヤがチームにいる間、チームの最大HPが上がる。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 隠せぬ聖性 | ファルディーヤの分担ダメージ割合+75％。 |
| 否定できぬ本能 | 敵ユニットが「破滅体験」によって受けるダメージの共有率が600％まで上昇し、その上限がファルディーヤの最大HPの25％まで増加する。「破滅体験」が解除されると、その間に敵ユニットが受けたダメージと「破滅体験」のダメージ上限の差分を、即座にダメージとして与える。 |
| 祝福を呪う者 | バトル開始後、ファルディーヤのHP上限が30％増加する。バトルが終了するとリセットされる。 |
| 禁忌を越える者 | 「敵神者」状態の間、ファルディーヤの回復割合が最大HPの30％まで増加し、HP減少量が「破滅しきい値」以上の時、回復割合が最大HPの60％まで増加する。 |
| 死を回顧する者 | 「敵神者」状態の間、ファルディーヤのクリティカル率+50％。 |
| 愛と死の使徒 | 「バイレールスキル：存在証明の体験」は範囲内の最大10体のターゲットに「破滅体験」を付与できる。各ターゲットごとに「破滅体験」の持続時間および「破滅体験」によって受けるダメージ上限を個別に計算する。 |
| 共振 3：不敬なる聖者 | 「通常攻撃：会話中断の否定」「バイレールスキル：存在証明の体験」「EXレール終結：痛みを狂喜に」のスキルレベル+1。 |
| 共振 6：帰結する聖者 | ファルディーヤがチームにいる場合、チーム全員の最大HP+10％ |

共振6の英語版ゲームテキストは攻撃力10%と書いているが、中国語版・日本語版・韓国語版のゲームテキストは最大HP10%と書いている。
