## プロフィール

| 項目 | 内容 |
| --- | --- |
| ランク | Sランク、常設 |
| 属性 | 相 |
| 弧盤タイプ | プラズマ (Plasma) |
| 実装 | バージョン1.0 |
| 声優 | 中国語：洪海天、英語：Allegra Clark、日本語：市ノ瀬加那、韓国語：이다은 |
| アーカイブ | [ハソールのアーカイブ](/ja/characters/hathor/archive/) |

公式プロフィールでは、ハソールは「先生」から与えられたエリート配達員の仕事に就いているとされている。正確で時間に厳しく、嵐の中でも地図なしで目印のない届け先を見つけられる。

## 入手方法

| 方法 | 詳細 |
| --- | --- |
| 常設ボード | Game8とPrydwenによると、常設Sランクキャラはスカボロー市場の常設ボードに登場する |
| 選択箱、バージョン1.2 | 2026-08-19 05:59 (UTC+8) までにキャラクターを作成した全プレイヤーに、「Sランク常設キャラ選択箱」がメールで配布された |
| 選択箱、バージョン1.4 | シティ名声「プカプラン」で「Sランク常設キャラ選択箱」を獲得できる |

この選択箱では、早霧、白蔵、ハソール、ファルディーヤ、ダフォディール、九原の6名から1名を選べる。ボードの仕組みは[ボードと弧盤研究プロジェクト](/ja/systems/boards/)を参照。

## スキル

ハソールはバイレールスキル、「極限反撃：ノーミス行動」、パッシブ「効率化遂行」で「サンダースピード」を溜める。EXレール終結を発動すると「緊急配達」状態になり、溜めたスタックに応じて攻撃力ボーナスを得て、「空中指令」が「フル回転配達」にアップグレードされる。「フル回転配達」はスタックを消費して素早い連続攻撃を行う。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | ハイスピ配達、圧巻配達、空中を制する者、極限反撃：ノーミス行動 | 「ハイスピ配達」で最大5段の相属性攻撃を行い、「圧巻配達」は空中から落下攻撃を行う。通常攻撃を長押しすると「空中を制する者」で敵を打ち上げ、叩きつける。「極限反撃：ノーミス行動」は極限回避の後に反撃し、相属性の範囲ダメージを与えてブレイク耐性を削り、「サンダースピード」を獲得する。 |
| バイレールスキル | 空中指令、フル回転配達 | 「空中指令」は前方の敵を斬りつけて「サンダースピード」を2スタック獲得する。長押しでチャージすると相属性の攻撃範囲が広がり、「星5追跡」を付与する。その間、敵の攻撃が味方に当たると3スタック獲得する。「緊急配達」中は「フル回転配達」になり、スタックを消費してバイクによる素早い連続攻撃を行う。 |
| EXレール終結 | 鉄騎速達 | 茨のバイクを召喚して旋回し、敵に急降下して相属性の範囲ダメージを与え、「緊急配達」状態になる。この間は「サンダースピード」を獲得しなくなり、「空中指令」が「フル回転配達」にアップグレードされ、移動速度が上がり、溜めたスタックに応じて攻撃力ボーナスを得る。キャラを切り替えると「緊急配達」は即座に終了する。 |
| サポートスキル | 配送指示 | 空中から攻撃し、ターゲットを蹴って衝撃を起こし、相属性の範囲ダメージを2回与える。 |
| パッシブ 1 | 時間延長警報 | 「延滞」強化：ターゲットの「延滞」の持続時間を延ばし、「延滞」状態のターゲットを攻撃する時のクリティカル率を上げる。 |
| パッシブ 2 | 効率化遂行 | ターゲットを撃破すると「サンダースピード」を1スタック獲得する。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| エリート配達員 | 戦闘開始後、初めて「バイレールスキル」を長押しすると、ただちに「サンダースピード」を6スタック獲得する。 |
| いばらの支配 | 「高評価ロックオン」と「星5追跡」が終了した時も（キャラ変更などによる強制終了を除く）、ハソールが「サンダースピード」を獲得する。 |
| アンバランスな片翼 | ハソールがボス以外のターゲットに与えるダメージ+15％ |
| エンジン共鳴 | 「緊急配達」状態中、「バイレールスキル：フル回転配達」を使用するたび、次に使用する「バイレールスキル：フル回転配達」のクリティカル率+25%。この効果は、現在の「緊急配達」状態が終了するとリセットされる。 |
| いつものサンドイッチ | 「サンダースピード」を1スタック獲得するたび、ハソールがターゲットに与えるダメージ+1％（スタック可能、最大+15％まで）。バトルから離脱すると効果が解除される。 |
| 日常生活攻略中 | 「緊急配達」状態中、自身のクリティカルダメージ+30%。 |
| 共振 3：ダブルアクセル | 「通常攻撃：ハイスピ配達」、「バイレールスキル：空中指令」および「EXレール終結：鉄騎速達」のスキルレベル+1。 |
| 共振 6：無障害通行 | 「緊急配達」状態の間、ハソールの与ダメージは、ターゲットの防御力を10％無視する。 |
