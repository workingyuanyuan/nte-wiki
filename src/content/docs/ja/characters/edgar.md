## スキル

エドガーは継続発動するバイレールスキルとEXレール終結の領域で味方を回復する。バイレールスキルとサポートスキルで「真理の鍵」を獲得してEXレール終結の持続時間を延ばし、「充蓄」強化で終結エネルギーを回復する。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 実戦体術、精確な着地、極限反撃：ピンチはチャンス | 「実戦体術」で最大5段の光属性攻撃を連続で行う。「精確な着地」は空中から落下攻撃を行い、高度に応じた光属性の範囲ダメージを与える。極限回避の後に「実戦体術」を使うと「極限反撃：ピンチはチャンス」が発動し、前方へ突進して「流」の攻撃を放ち、光属性の範囲ダメージを与えてブレイク耐性を削る。 |
| バイレールスキル | 狂流 | 長押しでターゲットに「流」を当て続け、光属性ダメージを与えながら、HPが最も低い味方を継続的に回復する。クールダウンは使用時間に応じて延びる。 |
| EXレール終結 | フィネガンの通夜 | 迷宮のような領域を展開し、光属性の範囲ダメージを1回与え、持続時間中は出撃中のキャラを回復する。 |
| サポートスキル | 知識の重み | ターゲットに向かって突進してカバンを振り回し、光属性の範囲ダメージを1回与える。 |
| パッシブ 1 | 優しい刃先 | 「充蓄」強化：キャラがサポートスキルで「充蓄」を発動すると、即座に終結エネルギーを獲得する。その後しばらく、創生花が「遅延」状態のターゲットに命中しても終結エネルギーを獲得できなくなる。 |
| パッシブ 2 | 不変の温もり | 「バイレールスキル：狂流」または「サポートスキル：知識の重み」を発動すると「真理の鍵」を1つ獲得する（最大3つ）。鍵1つごとに、EXレール終結（「フィネガンの通夜」）の持続時間が延びる。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 熱心な異象観察員 | 任意の仲間が「サポートスキル」を発動した時、エドガーは「真理の鍵」を1つ獲得する。 |
| 新米異象ハンター | 「バイレールスキル：狂流」の継続使用によるクールダウン延長は最大3秒まで。 |
| エイボンの探偵 | 「バイレールスキル：狂流」が現在HPが30％未満の仲間に与える回復効果+15％ |
| 熟練のプランナー | 「バイレールスキル：狂流」のダメージ+50％ |
| 骨董品屋の灯守り | エドガーの最大HP+20％ |
| 興味津々な来訪者 | 「EXレール終結：フィネガンの通夜」範囲内の仲間全員の防御力+15％。 |
| 共振 3：熱心な探求 | 「バイレールスキル：狂流」「EXレール終結：フィネガンの通夜」「サポートスキル：知識の重み」のスキルレベル+1 |
| 共振 6：鋭い洞察 | 仲間の安否はエドガーの思考を揺さぶる。任意の仲間が最大HPの3％を失うたびに、「EXレール終結：フィネガンの通夜」のチャージゲージ+1。最大20までチャージされ、「EXレール終結：フィネガンの通夜」を発動するとリセットされる。 |
