## スキル

イェルムは通常攻撃のコンボ、バイレールスキル、サポートスキルで「電波強度」を「電波：弱」から「電波：強」へ上げ、EXレール終結と、控えから発動する追加攻撃「おもいで」を強化する。同時にチームの攻撃力と追加攻撃ダメージを高める。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 瞬断ノイズ、混線ノイズ、干渉ノイズ、記憶の錨、落ちる夢、はい！握手！ | 「瞬断ノイズ」は「電波：弱」で最大5段の攻撃を行い、「不連続な存在」を解放する。長押しで「干渉ノイズ」になる。「混線ノイズ」は「電波：中」または「電波：強」で最大3段の攻撃を行い、「またね」を解放する。照準で「記憶の錨」、極限回避の後に「はい！握手！」を発動し、「落ちる夢」は空中から落下攻撃を行う。 |
| バイレールスキル | 電子の夢へ、去りゆく人々、不連続な存在、またね | 「去りゆく人々」は光属性の範囲ダメージを与え、「電波：弱」で「不連続な存在」を解放する。「不連続な存在」は電波強度を「電波：中」に上げ、「錯視」を付与し、ターゲットを検索してEXレール終結の形態を決める。「混線ノイズ」の後の「またね」は「錯視」のスタックを消費してダメージを高め、「電波：強」へ進めて再び検索する。 |
| EXレール終結 | 昨日と同じ景色 | 検索の結果に応じて単体形態と複数形態を自動で切り替え（「電波：弱」では複数形態）、電波強度に応じてダメージ倍率が上がり、発動後に「電波：弱」に戻る。チームの攻撃力と追加攻撃ダメージを高め、「通話中」を付与する。「通話中」の間、控えにいると連携の追加攻撃「おもいで」が回数の上限まで発動する。 |
| サポートスキル | ここにいるよ | 光属性ダメージを与える。出撃中なら「電波：弱」を「電波：中」に上げて「錯視」を付与し、近くのターゲットを検索して「昨日と同じ景色」の単体形態と複数形態を切り替える。 |
| パッシブ 1 | 中継ノード | 「充蓄」強化：出撃中のキャラが終結エネルギーを獲得すると、チームの光異能ダメージが最大8スタックまで上がる。「延滞」強化：味方が「延滞」を付与すると、少し後に同じターゲットへ「延滞」を再び付与する。この再付与からは連鎖しない。 |
| パッシブ 2 | 保証機構 | イェルムのクリティカルダメージが上がる。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 404 遥かなる孤島 | 「EXレール終結：昨日と同じ景色」を発動後、発動前に累計消費した「錯視」1スタックごとに、チーム全員のクリティカルダメージ+10％、20秒持続。重複して発動した時、このバフの効果と持続時間が更新され、「錯視」の累計消費スタック数がリセットされる。 |
| 200 隣接するノード | 「EXレール終結：昨日と同じ景色」のダメージ倍率+30％。「バイレールスキル：またね」を発動する時、「錯視」を1スタック消費するごとに、今回のスキルによる与ダメージがターゲットの防御を5％無視する。 |
| 504 タイムアウト | 「電波強度」が「電波：中」から「電波：強」に強化された際、「錯視」を3スタック獲得する。「錯視」は最大4までスタック可能。 |
| 302 願いのリダイレクト | イェルムがチームに編成され、かつ生存している場合、チーム全員のクリティカルダメージ+20％。 |
| 304 変わらぬ日常 | 「バイレールスキル：去りゆく人々」のダメージ倍率+100％。戦闘に入る時、イェルムの「連環値」が100になる。この効果は30秒のクールダウンがあり、1回の戦闘につき最大1回のみ発動する。 |
| 301 アドレスの恒久的移動 | 「EXレール終結：昨日と同じ景色」を発動後、発動前に累計消費した「錯視」1スタックごとに、イェルムの追加攻撃ダメージ+25％、20秒持続。重複して発動した場合、このバフの効果と持続時間が更新され、「錯視」の累計消費スタック数がリセットされる。 |
| 共振 3：拝啓、古き友へ | 「通常攻撃」、「バイレールスキル」、「EXレール終結」のスキルレベル+1。「サポートスキル：ここにいるよ」または「バイレールスキル：不連続な存在」を発動後、「電波：弱」の状態であれば、直接「電波：強」まで強化され、「電波：弱」から「電波：中」、「電波：中」から「電波：強」への強化時の効果を順次発動する。「電波強度」が「電波：強」まで強化された際、即座に「バイレールスキル：またね」を発動できる。 |
| 共振 6：さらば、新しき友よ | イェルムがチームに編成されており、かつ生存している場合、チーム全員の与ダメージがターゲットの全異能ダメージ耐性を12％無視する。「バイレールスキル：またね」の最終段が命中した時、スキルで「錯視」を消費していた場合、追加で光異能ダメージを1回与える。現在の「バイレールスキル：電子の夢へ」のスキルレベルに応じた倍率は{0}％×「錯視」の消費スタック数となる。 |

## 仕様の詳細

- 「電波強度」はイェルムのHPバーの上に3区画のゲージとして表示される。[^1]
- 「電波：強」でも「混線ノイズ」3段を出し切ると再び「またね」が解放される。電波強度はもう上がらないが、発動中は「軌道外領域」などの制限時間タイマーが止まる。[^2]
- 「電波：強」のとき、「混線ノイズ」の2段目が終わる前に3段目を先行入力しておくと、交代した後もイェルムが3段目を出し切る。[^3]
- 「電波：弱」で発動する「去りゆく人々」は連環値を即座に満タンにする。「不連続な存在」と「またね」にはこの効果がない。[^4]
- 「電波：弱」から「電波：中」に上がると「錯視」を1スタック獲得し、1スタックごとに次の「またね」の倍率が100%上がる。[^5]
- EXレール終結の形態は「不連続な存在」「またね」またはサポートスキルの発動時に、範囲内の敵の数で決まる。1体なら単体形態、2体以上なら複数形態になる。[^6]
- EXレール終結の倍率は「電波：中」で50%、「電波：強」で100%上がり、単体形態と複数形態で同じである。[^7]
- EXレール終結はイェルムの基礎攻撃力の20%分だけチーム全員の攻撃力を20秒間上げる。電波強度や形態は問わない。[^8]
- 控えにいる間、「おもいで」は3秒ごとに1回、最大6回攻撃し、単体形態と複数形態で同じである。[^9]
- 「おもいで」の形態と倍率は、それを始めたEXレール終結の時点で決まる。「電波：強」で発動した後は、電波強度が「電波：弱」に戻っていても、その回の「おもいで」には「電波：強」の倍率が乗る。[^10]
- 「おもいで」の回数が残っているうちにEXレール終結を再発動すると、回数は加算されずリセットされる。[^11]
- 「おもいで」には[リンコ](/ja/characters/linko/)の追加攻撃ダメージバフも乗る。[^12]
- 「中継ノード」の「充蓄」強化は1スタックごとにチーム全員の光異能ダメージを3.75%上げ、30秒持続、最大8スタック（30%）で、再発動で持続時間が更新される。[^13]
- チームの誰かがターゲットに「延滞」を付与すると、「中継ノード」の「延滞」強化が7.5秒後にそのターゲットへ「延滞」を再付与する。7秒に1回まで発動し、再付与された「延滞」からは再び発動しない。[^14]
- 「保証機構」はイェルムのクリティカルダメージを10%上げる。[^15]
- 覚醒をすべて揃えると、「またね」は消費した「錯視」のスタックに応じて1,000%以上の倍率が上乗せされる。[^16]
