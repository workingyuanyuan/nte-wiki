## スキル

レクイエムは「トマトメタル」と「トマトドラム」の形態を切り替えて「悪夢」を重ね、「平日最終裁判」の攻撃方法を変える。「悪魔の閃き」で敵の技を習得し、一時的に「寝覚めロード中」を「悪魔のプレゼント」に置き換えることもできる。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 甘酸っぱい制裁、トマトメタル、トマトドラム、フレーバー変奏、悪魔の閃き、トマト座流星群、fff休止符、悪夢 | 「フレーバー変奏」で5段の闇属性コンボ「トマトメタル」と「トマトドラム」を切り替え、「平日最終裁判」の形態を決める。急降下攻撃「トマト座流星群」、極限回避の反撃「fff休止符」、照準モードで敵の技を習得して「寝覚めロード中」と置き換える「悪魔の閃き」を含む。命中ごとに「悪夢」を最大10スタックまで重ねる。 |
| バイレールスキル | 寝覚めロード中、悪魔のプレゼント | 「寝覚めロード中」は造物を投げつけて闇属性の範囲ダメージを与え、「悪夢」を付与し、「トマトメタル」または「トマトドラム」の5段目につなげる。「悪魔の閃き」で置き換えた場合、バイレールスキル「悪魔のプレゼント」が習得した敵のスキルを複製して発動し、その持ち主の攻撃力の一部を得る。 |
| EXレール終結 | 平日最終裁判 | 使用中の通常攻撃のスタイルに応じて変化する。「トマトメタル」ではトラックを操って闇属性ダメージを10回、「トマトドラム」では自動車を解体して闇属性ダメージを5回与え、範囲内の全ターゲットに「悪夢」を付与する。 |
| サポートスキル | 緊急覚醒 | 異能造物を操り、範囲内に闇属性ダメージを1回与える。 |
| パッシブ 1 | トマトパーティー | 「失諧」強化。すでにブレイク状態のターゲットに「失諧」が発動すると、攻撃力に基づく追加ダメージを与える。 |
| パッシブ 2 | 自然に目覚めたい | スキルのクールダウン中に「トマトメタル」または「トマトドラム」を5回使用すると、「寝覚めロード中」を追加で1回発動できる。クールダウンごとに1回発動する。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 残業なし赦免 | 「悪夢」のダメージ倍率が増加する（現在のスキルレベルでは{0}%に増加）。 |
| 目覚ましだらけ | レクイエムが「サポートスキル」で出撃時、自身の与ダメージ+15％（15秒持続）。 |
| ドロドロアイス | 「通常攻撃：トマトメタル」または「通常攻撃：トマトドラム」の5段目がターゲットに命中すると、ターゲットに蓄積されている全ての「悪夢」の継続ダメージを一括で精算し、即座にダメージを与える。 |
| 戦魔トマト大王 | 「悪夢」状態の持続時間が6秒に延長される。 |
| 強化ガラス裁判 | レクイエムが「悪夢」ダメージを与えた時、追加でターゲットの最大HPを、そのダメージの200％分削る。3秒ごとに、直近3秒間に与えた「悪夢」の総ダメージ量の1.5%分、自身のHPを回復する。ターゲットがHP回復効果を受けた際、「悪夢」のスタックは消費されなくなる。 |
| 早起き出勤のうた | レクイエムが「バイレールスキル：悪魔のプレゼント」を発動してから5秒以内に、「暗星」「濁燃」「失諧」の異能連環を起こせるキャラからレクイエムへ切り替えた場合、「連環値」を溜めることなく即座に「サポートスキル」が発動し、対応する連環が発生する。この効果は5秒に1回しか発動しない。 |
| 共振 3：心に燃ゆる眠気 | 「通常攻撃：甘酸っぱい制裁」、「バイレールスキル：寝覚めロード中」、「バイレールスキル：悪魔のプレゼント」、「EXレール終結：平日最終裁判」のスキルレベル+1。コウモリ形態で飛行する時、スタミナ消費量が通常の85%になる。 |
| 共振 6：良夢の時来たる | レクイエムの与ダメージが、ターゲットの防御力を20％無視する。コウモリ形態で飛行する時、スタミナ消費量が通常の70%になる。 |
