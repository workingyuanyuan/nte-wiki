## スキル

九原は攻撃と創生花で「薔薇の弾丸」を生成し、敵に「致命的な薔薇の誓約」を結び付け、弾丸を消費して自動照準の射撃を行う。EXレール終結「終局の清算」で、結び付けたすべてのターゲットに「誓約の清算」を同時に行い、創生株の上限も増やす。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 秘密形成の時、全域俯瞰、情報指向型、好機捕捉、形勢逆転 | 最大5段の霊属性攻撃で「薔薇の弾丸」を獲得し、最後の一撃で「致命的な薔薇の誓約」を付与する。落下攻撃と照準射撃もある。通常攻撃を長押しすると「薔薇の弾丸」を消費して自動射撃し、誓約を結んだターゲットを優先して狙う。極限回避の後の「形勢逆転」は誓約を付与し、ブレイク耐性を削り、弾丸を獲得する。 |
| バイレールスキル | 情報ハンター | 戦場を駆け巡ってターゲットを制圧範囲に引き寄せ、霊属性ダメージを複数回与える。「薔薇の弾丸」を獲得し、ターゲットに「致命的な薔薇の誓約」を付与する。 |
| EXレール終結 | 終局の清算 | 高速で駆けながら周囲のターゲットを撃ち、最後に霊属性の大爆発を起こす。「終局の清算」を発動し、近くの「致命的な薔薇の誓約」を持つターゲットをすべて「誓約の清算」の段階に移し、最後の一撃ですべての清算を同時に行う。 |
| サポートスキル | 機密捕捉 | カーブ弾を放って霊属性ダメージを1回与え、命中すると「薔薇の弾丸」を獲得する。 |
| パッシブ 1 | 虎視眈々 | 「創生」強化：創生株を追加で1株生成し、フィールド上の創生株の上限を6株に上げる。 |
| パッシブ 2 | 噂話の利用価値 | 創生花が敵に命中すると、誓約のないターゲットに「致命的な薔薇の誓約」を付与し、すでに誓約を結んだターゲットには「追加清算」を発動して霊属性の追加ダメージを与える。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 知悉と均衡 | フィールド上に「致命的な薔薇の誓約」を結んだターゲットがいる場合、1体につき九原の攻撃力+5％、最大+15％まで。 |
| 過去の報せを刃と成す | 「致命的な薔薇の誓約」のダメージ倍率+100％。「EXレール終結：終局の清算」を発動して「誓約の清算」を誘発すると、その誓約で蓄積された総ダメージの5％分、チーム全員のHPを回復する。 |
| 優勢の始まり | 「EXレール終結：終局の清算」を発動して「誓約の清算」を誘発すると、清算対象のブレイク耐性を追加で-4。 |
| 一撃必殺 | 能動的に発動した「誓約の清算」のダメージ倍率+50％となり、範囲ダメージに変化する。 |
| 掌握者の優越 | 九原が「致命的な薔薇の誓約」を結んだターゲットに与えるダメージ+8％ |
| 全ての秘密を知る者 | 「致命的な薔薇の誓約」を付与された敵がスキルを発動するたび、対象に攻撃力の200%分のダメージを与える（クールダウン5秒） |
| 共振 3：ダブルアクセル | 「通常攻撃：秘密形成の時」、「バイレールスキル：情報ハンター」および「EXレール終結：終局の清算」のスキルレベル+1。 |
| 共振 6：無障害通行 | 「致命的な薔薇の誓約」を結んだターゲットの霊異能ダメージ耐性-10％ |
