## スキル

ハニアはスピーカー「ホーホーちゃん」を設置してチームの攻撃力を高め、出撃中のキャラの攻撃で「四部合唱」を溜めて、魂属性の範囲ダメージを与える「合奏」を発動する。EXレール終結で「超異能課のエース」状態になり、「ホーホーちゃん」の時間経過を止め、「主役オーラ」を溜める「合奏・交響」の追加発動を加える。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 超異能課登場、超異能課魔法砲、極限反撃：エースの歩法 | 「超異能課登場」は魔法弾を最大5発放ち、空中から落下攻撃を行って魂属性ダメージを与えることもできる。1段目の最中に通常攻撃を長押しすると「超異能課魔法砲」をチャージする。「極限反撃：エースの歩法」は極限回避の後に反撃し、ブレイク耐性を削って、フルチャージの「超異能課魔法砲」を放つ。 |
| バイレールスキル | 静かなる月森の守護者 | ポータブルスピーカー「ホーホーちゃん」を投げて魂属性の範囲ダメージを与え、ハニアの基礎攻撃力に基づいてチームの攻撃力を高める。出撃中のキャラが攻撃すると「ホーホーちゃん」に「四部合唱」が溜まり、4スタックで「合奏」が発動して魂属性の範囲ダメージを与える。「ホーホーちゃん」は1体までしか存在できず、キャラを切り替えても残る。 |
| EXレール終結 | 『ハニア』という名の旋律 | 強化領域を展開して「超異能課のエース」状態になり、ハニアの基礎攻撃力に基づいてチームの攻撃力を高め、「ホーホーちゃん」の持続時間のカウントを止める。「合奏」の発動時には強化された「合奏・交響」も発動し（「主役オーラ」は溜まらない）、出撃中のキャラの次の攻撃を強化する。 |
| サポートスキル | イースターエッグ | 敵に魔法弾を1発放ち、魂属性ダメージを1回与える。 |
| パッシブ 1 | 友情だね | 「暗星」強化：「暗星」が終了すると、味方がハニアの基礎攻撃力に基づいてターゲットから攻撃力を吸収する。吸収量には上限があり、戦闘を離脱すると双方のステータスは元に戻る。 |
| パッシブ 2 | 絆だね | 出撃中のキャラが「合奏」を発動するたびにハニアは「主役オーラ」を獲得し、「超異能課魔法砲」の跳弾回数の上限が増える。「超異能課のエース」状態中は「合奏」1回ごとに2倍のスタックを獲得し、合計で最大4スタックまで。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 新人！天才転校生現る | 「主役オーラ」の蓄積上限が6スタックまで増加し、「超異能課魔法砲」の跳弾回数が最大で6回になる。 |
| 伝説！ 窓際最後列のマイホーム | 「ホーホーちゃん」の持続時間+4秒。 |
| 集結！主人公チーム結成 | 「超異能課のエース」状態中、ハニア自身のクリティカル率+20％ |
| 海辺！永遠の七八の法則 | 「超異能課のエース」状態中、ハニアが「合奏」を発動すると、次の攻撃で発生する追加ダメージ+100％ |
| 危機！砕け散る信頼 | 「超異能課のエース」状態中、ハニア自身が与える魂異能ダメージ+30％ |
| 決戦！訪れる夜明け | 「ホーホーちゃん」のクールダウン-4秒。 |
| 共振 3：前日譚 | 「通常攻撃：ガイロセクト術法」、「バイレールスキル：静かなる月森の守護者」、「EXレール終結：『ハニア』という名の旋律」のスキルレベル+1。 |
| 共振 6：続編 | 「超異能課のエース」状態中、チーム全員のクリティカルダメージ+12％。 |
