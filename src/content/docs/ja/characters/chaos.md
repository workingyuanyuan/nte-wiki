## スキル

カオスは攻撃で「ギルト」を溜め、EXレール終結の「カルマ・エコー」状態では急速に溜める。上限に達した「ギルト」を「ジャッジメント」で消費して高威力の清算ダメージを与えつつ、「追撃指令」を付与し、「延滞」を強化する。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 追猟、ジャッジメント、フェイタル、直感/本能 | 「追猟」は最大5段の相属性攻撃を行う。通常攻撃を長押しすると「ジャッジメント」が発動し、「ギルト」が上限なら消費して2段目の高威力の清算ダメージを与え、上限でなければ1撃のみとなる。「フェイタル」は空中から急降下し、落下高度に応じた相属性の範囲ダメージを与える。極限回避の後の「追猟」で「直感/本能」が発動し、ブレイク耐性を削る。 |
| バイレールスキル | 疑惑の照準 | 前方を射撃し、猟犬を召喚してターゲットに飛びかからせ、往復で2回噛みつく。命中すると最大2体の敵に「追撃指令」を付与し、「追撃指令」を付与されたターゲットへの与ダメージが増加する。 |
| EXレール終結 | カルマ・パージ | 猟犬を召喚して周囲の敵を制圧し、範囲内の全ての敵に「追撃指令」を付与して「カルマ・エコー」状態に入る。「カルマ・エコー」の間は「ギルト」が時間とともに急速に増え、「ジャッジメント」をより頻繁に発動して高威力の清算ダメージを与えられる。 |
| サポートスキル | 強襲 | 鎌を振り上げて相属性ダメージを1回与える。 |
| パッシブ 1 | 逃れられぬ正義 | 「延滞」強化は、「延滞」の終了時にターゲットへ攻撃力に応じた相属性ダメージを与える。「延滞」の基本持続時間を超えた時間に応じて総ダメージが増加し、再付与すると「延滞」の持続時間がリセットされる。 |
| パッシブ 2 | 特別警戒！ | 「追撃指令」を付与された敵を攻撃するときのダメージ増加効果を高める。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 看破 | カオスが「追撃指令」を付与された敵を攻撃した際、追加で40％の「ギルト」を獲得できる。 |
| 罪名/悪行 | カオスが「追撃指令」を付与された敵を攻撃した際、ターゲットの防御力を20％無視する。 |
| 花火 | 「EXレール終結：カルマ・パージ」使用後、自身のクリティカルダメージ+30％、20秒持続。再度発動すると効果時間がリセットされる。 |
| ミスト・タイド | カオスが「追撃指令」を付与されたターゲットを撃破した際、その「追撃指令」は付近のマークされていない敵に移り、持続時間がリセットされる。 |
| 虚空の孤眼 | 「追撃指令」を付与されたターゲットがフィールド上に1体のみ残っている場合、カオスが該当のターゲットに与えるダメージ+20％。 |
| 偽りの原点 | カオスが「EXレール終結：カルマ・パージ」を使用すると、「ギルト」が瞬時に最大ゲージまで回復する。 |
| 共振 3：正義/正解 | 「通常攻撃：追猟」「バイレールスキル：疑惑の照準」「EXレール終結：カルマ・パージ」のスキルレベル+1。 |
| 共振 6：光明/白昼 | 「追撃指令」を付与された敵の相異能ダメージ耐性-10％。 |
