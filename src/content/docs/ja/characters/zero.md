## プロフィール

| 項目 | 内容 |
| --- | --- |
| ランク | Sランク、主人公 |
| 属性 | 光 |
| 弧盤タイプ | ソリッド (Solid) |
| 実装 | バージョン1.0 |
| 声優 | 中国語：马洋、英語：Hunter McCoy、日本語：内田雄馬、韓国語：박기욱 |

零は主人公であり、鑑定士である。公式プロフィールでは、虚無から現れた異能者で、あらゆる異象の中にある「奇点」を不思議なほど鋭く感じ取り、異象ハンターの免許を持たないまま管理局から骨董品屋エイボンに送り込まれたと紹介されている。零は男性でも女性でもプレイできる。

## 入手方法

零は全プレイヤーが最初から持っているキャラである。

## スキル

零は「鑑痕」のコンボで光属性ダメージを与え、「鑑痕の極み」で異能砲を放ってレベルの低いターゲットに追加攻撃を加え、「奇零退散」で一気にダメージを与える。「鑑定士」は「充蓄」強化により、操作キャラが終結エネルギーを得るたびに仲間のHPを回復する。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 鑑痕、鑑痕・断、鑑痕・破、極限反撃：一瞬の霊感 | 「鑑痕・断」は最大5段の光属性連続攻撃を行う。「鑑痕・破」は空中から急降下し、落下高度に応じた光属性の範囲ダメージを与える。「極限反撃：一瞬の霊感」は極限回避の後に反撃して光属性の範囲ダメージを与え、ブレイク耐性を削る。 |
| バイレールスキル | 鑑痕の極み | 武器で3段の連続攻撃を行い、空中に跳んで力を溜め、異能砲を発射して光属性の範囲ダメージを与える。さらに、零よりレベルの低い最初のターゲットに光属性攻撃を1回追加する。 |
| EXレール終結 | 奇零退散 | 剣舞で見えない線を一掃し、範囲内に光属性ダメージを複数回与える。 |
| サポートスキル | 裂断 | 空間を斬り裂いて亀裂を炸裂させ、範囲内に光属性ダメージを2回与える。 |
| パッシブ 1 | 鑑定士 | 「充蓄」強化を付与し、操作キャラが終結エネルギーを得るたびに、零の基礎攻撃力に基づいてHPを回復する。 |
| パッシブ 2 | 異象感知能力 | 「EXレール終結：奇零退散」の与ダメージが増加する。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 夜明けの凝視 | 「バイレールスキル：鑑痕の極み」が最初に命中した敵（自身のレベル以下）に、攻撃力の200％にあたる追加ダメージを1回与える。このダメージは、ターゲットの防御力を75％無視する。 |
| 天職解放 | 「バイレールスキル：鑑痕の極み」を発動すると、自身は追加で終結エネルギーを8獲得する。 |
| 珍談叙事 | 「EXレール終結：奇零退散」のクリティカル率+50％。 |
| 不確定事象 | 零の基礎攻撃力1ごとに「EXレール終結：奇零退散」が与えるダメージ+0.1％（最大+25％）。 |
| 黙示の魂 | 零が「サポートスキル」を発動させると、自身の攻撃力+10％（20秒持続）。 |
| 禁則解放 | 「バイレールスキル：鑑痕の極み」の追加ダメージ倍率が、攻撃力の300％まで増加する。 |
| 共振 3：鑑解 | 「鑑痕」「鑑痕の極み」「奇零退散」のスキルレベル+1。 |
| 共振 6：零示 | 零が光異能連環を発生させると、チーム全員の攻撃力+12％（20秒持続）。 |

夜明けの凝視の英語版ゲームテキストは「レベルが低い敵」と書いているが、中国語版・日本語版・韓国語版のゲームテキストは自身のレベル以下と書いている。
