## スキル

翳は「拘束格闘術」と「潜影追撃」で、ターゲット1体につき最大3体の「影獣牙突」を付着させる。バイレールスキルで「追尾」を発動して「影獣牙突」を残し続け、「咬牙潜影」に入って接触時に追加攻撃を起こす。「犬群の遠吠え」は強化と妨害を加える。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 拘束格闘術、現場執行、影獣牙突、極限反撃：揮毫サイン | 「拘束格闘術」は最大5段の相属性攻撃を行い、「影獣牙突」の影を分裂させる。影はターゲットを追尾し、1体につき最大3体まで付着し、相属性攻撃を1回与えると消える。急降下攻撃「現場執行」と、極限回避の後の反撃「極限反撃：揮毫サイン」を含む。 |
| バイレールスキル | 潜影追撃、追尾、咬牙潜影 | 「追尾」に入り、相属性の範囲攻撃を6回与え、ターゲット1体につき「影獣牙突」を3体分裂させて「咬牙潜影」に入る。「追尾」中は「影獣牙突」が命中しても消えない。「咬牙潜影」中は気づかれずに移動でき、接触時に「影獣牙突」の追加攻撃を起こし、終了時に範囲ダメージを与える。 |
| EXレール終結 | 犬群の遠吠え | 影を外へ広げて相属性の範囲攻撃を1回与え、次に集めて範囲攻撃を3回与える。発動後は「影獣牙突」のダメージ（「咬牙潜影」の接触ダメージを含む）が増加し、攻撃のたびに妨害効果を与える。 |
| サポートスキル | 逮捕令 | 警察犬のように影を操ってターゲットに噛みつかせ、範囲内に相属性ダメージを1回与える。 |
| パッシブ 1 | 現場制御 | 「延滞」強化を付与する。「延滞」状態のターゲットを「影獣牙突」がロックオンすると、追加で「延滞」を1回付与する。 |
| パッシブ 2 | 捕獲落着 | 「犬群の遠吠え」の発動後、「影獣牙突」のダメージ（「咬牙潜影」モードの接触ダメージを含む）が増加する。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 裏切り禁止規程 | 「影獣牙突」の自動攻撃のダメージ倍率+60％。 |
| 理路整然フロー | 翳が「バイレールスキル：潜影追撃」を発動すると、自身のクリティカル率+10％、よろめき耐性+50％。15秒持続。 |
| 異物処理プラン | 「影獣牙突」がロックオンしたターゲットへの与ダメージ+4％。「影獣牙突」がロックオンしたターゲットが場に1体しかいない場合、さらに与ダメージ+4％。 |
| 慣例制定決議 | 「追尾」状態の持続時間が12秒に延長される。ターゲットが付着されている場合、1秒ごとに受ける付着ダメージ+2％、最大40％まで。 |
| 社会適応の重責 | 「影獣牙突」がターゲットをロックするごとに、そのターゲットの重量+50、移動速度−20％。 |
| 無意味な外観 | 「咬牙潜影」モード中、「影獣牙突」でロック中の敵ターゲットに触れると、「影獣牙突」が与える追加ダメージ倍率+20％。 |
| 共振 3：職場の生存法則 | 「通常攻撃：拘束格闘術」「バイレールスキル：潜影追撃」「EXレール終結：犬群の遠吠え」のスキルレベル+1。 |
| 共振 6：業務模範規則 | 各「影獣牙突」はロックオンしたターゲットの相異能系統ダメージ耐性-2％、最大-6％まで。 |
