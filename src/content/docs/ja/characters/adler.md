## スキル

アドレーは通常攻撃で「業」を重ね、バイレールスキル「諸悪加持」でそれを消費して呪属性の範囲継続ダメージを与え、シールド「悟りの叡智」を付与する。EXレール終結は呪属性の多段ダメージを与え、パッシブ「克己」は「濁燃」状態の敵にデバフを付与する。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 渡悪、滅苦、無明、極限反撃：羯諦、業 | 「渡悪」で最大5段の呪属性の連続攻撃を行い、「滅苦」で単体を狙った射撃を行い、「無明」で急降下攻撃を行う。極限回避の後に「渡悪」を使うと「極限反撃：羯諦」が発動し、ブレイク耐性を削る。「渡悪」「無明」「滅苦」の命中で「業」を得て、最大20スタックまで重なる。 |
| バイレールスキル | 諸悪加持 | 「空若」の虚影を召喚して呪属性の範囲ダメージと呪属性の継続ダメージを与え、出撃中のキャラに「悟りの叡智」のシールドを付与する。発動時に「業」をすべて消費し、消費したスタック数に応じてスキルダメージが増加する。 |
| EXレール終結 | 万象静寂 | 「色」「受」「想」「識」「行」の5体の「空若」を召喚し、敵全員にそれぞれ呪属性ダメージを5回与える。フィールドに残った敵が1体のみの場合、「空若」は2回目の攻撃を行い、合計10回の呪属性ダメージを与える。 |
| サポートスキル | 真心に汚れなし | 敵に照準を合わせて圧縮弾を1発発射し、命中すると呪属性の範囲ダメージを1回与える。 |
| パッシブ 1 | 克己 | 「濁燃」強化：ターゲットに「濁燃」が付与されるたびに、攻撃力ダウン、異能ダメージ耐性ダウン、ブレイク効率アップの3種のデバフのうち1つをランダムで付与する。同じデバフ効果はスタックしない。 |
| パッシブ 2 | 正心 | アドレーの防御力を高める。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 無色 | 「EXレール終結：万象静寂」発動後、アドレーは自身に「業」を20スタック付与する。 |
| 無受 | 「業」1スタックにつきダメージアップ効果が3％まで増加する。 |
| 無想 | 「悟りの叡智」のシールド値+20％ |
| 無行 | 「悟りの叡智」が砕けたとき、超過分のダメージのうち、アドレーの防御力の50％相当分を吸収する。 |
| 無識 | 「EXレール終結：万象静寂」発動後、アドレーは終結エネルギーを20回復する。 |
| 諸法は空相なり | 「悟りの叡智」の持続時間が12秒に延長される。 |
| 共振 3：業の浄化 | 「通常攻撃：渡悪」「バイレールスキル：諸悪加持」「EXレール終結：万象静寂」のスキルレベル+1。 |
| 共振 6：庇護の知恵 | 「悟りの叡智」に守られている間、チーム全員の呪異能ダメージ+10％。 |
