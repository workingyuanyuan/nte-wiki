## スキル

潯はクールダウンや終結エネルギーを使わず、時間の経過とともに「非閉合式時計」にエネルギーを溜める。バイレールスキルはエネルギーを60消費して味方のサポートスキルまたはバイレールスキルを最大3つ記録し、EXレール終結で時間停止を起こしてそれらを再現し、太刀の連続攻撃を繰り出す。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 朧月流、非閉合式時計、さざ波、勾月、極限反撃：半瞬 | 「朧月流」で最大5段の光属性攻撃を行い、「さざ波」は戦闘中に長押しすると前方へ突進し、「勾月」は空中から落下攻撃を行う。「非閉合式時計」は潯が出撃すると自動で回転し、エネルギーを最大120まで溜める。「極限反撃：半瞬」は極限回避の後に反撃し、ブレイク耐性を削る。 |
| バイレールスキル | 今景再映 | クールダウンはない。「非閉合式時計」のエネルギーが60以上の時に60を消費して光属性ダメージを7回与え、針を巻き戻し、味方のサポートスキルまたはバイレールスキルを最大3つ（味方1人につき1つ）記録する。戦闘の開始や離脱で記録は消え、再使用すると以前の記録は上書きされる。 |
| EXレール終結 | 浮世の波 | クールダウンも終結エネルギーのコストもない。「非閉合式時計」のエネルギーが満タンの時に発動し、光属性攻撃を10回行い、太刀を持って時間停止に入る。この間はキャラ切り替えができず、時間制御への耐性を得る。記録した攻撃を1回再現し、太刀の連続攻撃で10スタックまで溜めて終結ダメージを与え、針を巻き戻す。 |
| サポートスキル | 店長の威勢 | 傘を投げ、光属性の範囲ダメージを1回与える。 |
| パッシブ 1 | 蘭の家紋 | 「創生」強化：時間停止中も「創生株」の攻撃が止まらない。 |
| パッシブ 2 | 万物須らくお宝 | 「浮世の波」の終結ダメージ倍率が上がる。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 漸進 | 「サポートスキル」または「バイレールスキル」を1つ記録するたびに、潯が時間停止中に与えるダメージ+12％。 |
| 記憶は遥か | 時間停止中、潯の与ダメージ+20％。 |
| 愛しき刹那の間 | 「バイレールスキル：今景再映」を使用して記録を完了した後、「バイレールスキル：今景再映」で使用したエネルギーを急速に回復する。60秒に1回のみ発動可能。エネルギー回復中にエネルギーを消費する行動を行うと、エネルギー回復は中断される。 |
| 失われゆく宝物 | 針が逆回転していない間、チーム全員がターゲットを1体撃破するたびに、「非閉合式時計」は追加でエネルギーを10蓄積する。最大3回まで発動可能。「EXレール終結：浮世の波」を発動するとカウントがリセットされる。 |
| 全容監視 | 潯の出撃時、フィールド上の敵が1体のみの場合、チーム全員がその敵に与えるダメージ+15％。潯が戦闘不能になると、この効果は消失する。 |
| 時の歯車雪積る | 時間停止中に潯がダメージを与えると、ターゲットの防御力を30％無視する。 |
| 共振 3：ちぐはぐな永遠 | 「通常攻撃：朧月流」、「バイレールスキル：今景再映」、「EXレール終結：浮世の波」のスキルレベル+1。 |
| 共振 6：胸奥の至宝 | 潯がチームに編成され、かつ生存している場合、チーム全員の攻撃力+30％。 |
