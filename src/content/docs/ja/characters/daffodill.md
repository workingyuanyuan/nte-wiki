## スキル

ダフォディールはブレイクダメージと素早い交代に特化している。味方のサポートスキルで「共振」のスタックが溜まると「共鳴即応」に変わり、EXレール終結は「インサイト」を付与して「ファントムシフト」の使用回数を解放する。「失諧」強化は敵のブレイク発動値を下げる。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 止水、分光、水鏡の影、錯綜する刃先、十字確認、極限反撃：一線 | 「止水」は最大5段の闇属性攻撃を行い、「分光」はブレイクダメージへの寄与を高める。長押しで「水鏡の影」の旋風のような突進と痕跡を発動し、連続攻撃の途中で回避すると無敵の「錯綜する刃先」が発動し、「止水」は中断されない。「十字確認」は空中から急降下し、極限回避の後は「極限反撃：一線」でブレイク耐性を削る。 |
| バイレールスキル | 共振、共鳴即応 | 「共振」はターゲットにダメージを与え、チームの誰かがサポートスキルを発動すると「共振」のスタックを獲得し、「共振」のダメージとブレイクパワーが最大2スタックまで増加する。スタックが最大になると「共振」は強化されて「共鳴即応」に置き換わり、構えを変えて鎖付きの刃を振り回し、闇属性ダメージを与える。 |
| EXレール終結 | 終幕の刻 | 闇属性の範囲ダメージを与え、左眼を解放して与ダメージを高め、近くの敵に「インサイト」を付与する。さらに「ファントムシフト」を最大2回まで使えるようにし、発動時に「ファントムシフト」の回数をリセットする。 |
| サポートスキル | 交刃 | 刃を振るって斬りつけ、ターゲットに闇属性ダメージを1回与える。 |
| パッシブ 1 | 破鞘 | 「失諧」強化は、「失諧」状態のターゲットのブレイク発動値を下げる。この効果は初期ブレイク発動値に応じた上限までスタックし、戦闘離脱時に元に戻る。 |
| パッシブ 2 | 空蝉 | 「ファントムシフト」の与ダメージを高める。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 瞳 | チーム内のキャラがサポートスキルを発動するたびに、「バイレールスキル：共振」のダメージ増加量+100%、ブレイクパワー増加量+250% |
| 機械の行進 | 「ファントムシフト」によるターゲットのレール反撃に失敗した場合、最後の一撃がターゲットに大ダメージを与え、ブレイクパワーを生成するとともに、「EXレール終結：終幕の刻」のチャージを最大まで溜める。 |
| 造物の衆 | ターゲットに「インサイト」が付与された後、解除されなくなる（ターゲットの戦闘不能/戦闘離脱を除く）。重複して付与することでスタック可能、最大2スタック。 |
| 潜伏 | ターゲットが「インサイト」の効果中にブレイク状態に入ると、「インサイト」1スタックにつき、ダフォディールが与える追加ブレイクダメージ+15%。 |
| 完璧な真相 | ターゲットが「インサイト」効果中にブレイク状態に入ると、「インサイト」1スタックにつき、ターゲットはダフォディールによるブレイクダメージを追加で1回受ける。 |
| 湖心の花 | ダフォディールが与える全てのダメージは、ターゲットの防御力を15%無視する。 |
| 共振 3：秘密行動 | 「通常攻撃：止水」、「バイレールスキル：共振」、「EXレール終結：終幕の刻」のスキルレベル+1。 |
| 共振 6：陽だまりと帰る場所 | ターゲットがブレイク状態の時、ターゲットの闇異能ダメージ耐性-15%。 |
