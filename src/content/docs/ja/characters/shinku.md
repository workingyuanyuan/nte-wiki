## スキル

真紅は通常攻撃、「竜牙突」、「突破戦術」で「反逆の闘志」を溜め、「爆熱竜炎」でそれを消費して「逆鱗解放」に入る。この状態では「正気の境目」を得て「紅蓮の急襲」を発動し、「紅蓮断罪」と「竜炎断罪」につなげる。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 真紅流・格闘術、空穿ち、真紅流・格闘術【変】、極限反撃：一閃、瞬華、重墜、瞬華-冷眼、極限反撃：息根止め | 最大5段の光属性攻撃、急降下攻撃、長押し攻撃、極限反撃で「反逆の闘志」を溜める。「逆鱗解放」中は「瞬華」、「重墜」、「瞬華-冷眼」、「極限反撃：息根止め」がこれらの技に代わり、代わりに「正気の境目」を得る。「見切り竜眼」中は追加ダメージがある。 |
| バイレールスキル | 竜牙突、紅蓮の急襲 | 「竜牙突」はターゲットに突進して光属性攻撃を複数回与え、「反逆の闘志」を得る。「逆鱗解放」中は「紅蓮の急襲」になり、「正気の境目」をすべて消費してターゲットの頭上へ跳び、急降下の爪撃を放つ。1回の状態中に最大5回使える。 |
| EXレール終結 | 爆熱竜炎、紅蓮断罪、竜炎断罪 | 「反逆の闘志」をすべて消費して「逆鱗解放」に入り、与ダメージ、よろめき耐性、機動力が上がり、通常のスキルが置き換わる。状態の終了間際に、「紅蓮の急襲」の使用回数に応じて「紅蓮断罪」を最大3回発動し、もう一度押すと「竜炎断罪」になる。 |
| サポートスキル | 突破戦術 | 渾身の膝蹴りを放ち、光属性ダメージを1回与えて「反逆の闘志」を得る。 |
| パッシブ 1 | 独歩 | 「充蓄」強化を付与する。操作キャラが終結エネルギーを得ると、待機中の仲間も同量のチャージを得る。真紅を操作中で充蓄状態の時、発動するたびに範囲ダメージを与え、攻撃力バフを最大10スタックまで重ねる。 |
| パッシブ 2 | 逆鱗 | ボス以外の敵に与えるEXレール終結のダメージが増加する。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 雨煙る路地 | ターゲットの防御力を12％無視する。 |
| 深夜の訓練場 | 「EXレール終結」命中時、敵の光異能ダメージ耐性-10％、20秒持続。 |
| 黄昏ビーチ | キャラを切り替えても「見切り竜眼」は解除されず、待機中もスタック数が増加する。 |
| 雪降る坂道 | 「見切り竜眼」のスタック上限が16スタックまで増加する。「見切り竜眼」が16スタックに達した時に発動する「刹那の猛撃」は、「レール反撃」または「極限反撃」で発動する「刹那の猛撃」に付随する追加効果、すなわち敵を強制ノックバックさせて一時的に行動不能にする効果（ボスには無効）と、「刹那の猛撃」の20％分のダメージを再度与える効果を獲得する。 |
| 和みリビング | 「逆鱗解放」中、真紅の防御力+50％、よろめき耐性係数+50％。さらに「バイレールスキル：紅蓮の急襲」発動時、基礎攻撃力の300％分のHPを回復する。 |
| 赤竜の財宝 | 「バイレールスキル：紅蓮の急襲」、「EXレール終結：紅蓮断罪」、「EXレール終結：竜炎断罪」のダメージ倍率+30％。また、「バイレールスキル：紅蓮の急襲」と「EXレール終結：紅蓮断罪」は範囲内の敵を引き寄せる。 |
| 共振 3：変貌の決意 | 「通常攻撃」、「バイレールスキル」、「EXレール終結」のスキルレベル+1。「逆鱗解放」中、与ダメージが追加で+30％。 |
| 共振 6：英雄真紅 | クリティカル率+10％、ターゲットの防御力を15％無視する。 |
