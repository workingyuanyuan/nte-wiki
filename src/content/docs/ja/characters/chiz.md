## 入手方法

シティ名声のレベルを上げると入手でき、[^1]ちぃちゃん本人とその重複分は課金なしで入手できる。[^2]

## スキル

ちぃちゃんは通常攻撃で「金穀」を獲得し、ストックしたバイレールスキルの発動でそれを消費する。EXレール終結の「金穀市場」と「黒字」状態を使い、「金穀ローン」と変動する「金穀チャート」を光属性ダメージに変える。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 失郷剣術、粗穀、豊玉、極限反撃：ミンスキー・モーメント | 「失郷剣術」は最大5段の攻撃で光属性ダメージを与え、「金穀」を獲得する。「粗穀」は押すか長押しで光属性ダメージを与え、「金穀」とファンスを獲得する（撃破時は追加あり）。「豊玉」は空中から急降下して「金穀」を獲得し、極限回避の後は「極限反撃：ミンスキー・モーメント」でブレイク耐性を削り、「金穀」を獲得する。 |
| バイレールスキル | にくきゅうの原則 | バイレールスキルの使用回数を最大3回までストックする。連続で押すと「空倉」「半倉」「満倉」を順に発動する。長押しでは2回または3回分を消費し、「半倉」の間は「金穀」を消費し続け、すべての「金穀」と「赤字」状態の「金穀ローン」を消費してクリティカルしない光属性の追加ダメージを与える。「黒字」状態では強化される。 |
| EXレール終結 | ゼロサムゲーム | 「黒糖ボボ」を投げて光属性の範囲ダメージを与え、「金穀ローン」を「金穀」に変換し、「黒字」状態と「金穀市場」に入って「金穀」をすべて投入する。初回の「穀価決済」ダメージは必ずクリティカルになる。「にくきゅうの原則」を押すか長押しすると「金穀チャート」に基づいて「穀価決済」が行われ、その後「金穀ローン」が返済される。 |
| サポートスキル | 臨時入場 | 「黒糖ボボ」にちぃちゃんが乗ってターゲットに体当たりし、光属性ダメージを1回与える。 |
| パッシブ 1 | 飛鳥症候群 | 「充蓄」強化：出撃中のキャラに追加のエネルギーを与える。 |
| パッシブ 2 | 収集癖 | ちぃちゃんがフィールドにいる間、ちぃちゃんのチャージ率を高める。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 太陽さん答えて | 「金穀」と「金穀ローン」の所持上限+10％。 |
| 静かな花火 | ちぃちゃんが「黒字」状態の間、毎秒現在の「金穀」の10％分の利息を獲得する。 |
| 雨の日がなければ | 「金穀チャート」における「金穀」価格上昇確率+50％。 |
| おにぎり・包帯・ファンスへ | 「金穀」の獲得率+20％。 |
| 日記の空白ページ | ちぃちゃんが戦闘に入ると、現在の「金穀」所持上限の100％分の「金穀」を獲得する。 |
| 三十三日 | 「金穀」による追加光異能ダメージ+15％。 |
| 共振 3：友達であり家族 | 「赤字」状態中、「金穀」の獲得効率が追加で+50％。 |
| 共振 6：帰郷 | ちぃちゃんがダメージを与えた時、ターゲットの光異能ダメージ耐性を10％減少させる。 |

## 仕様の詳細

- シティ名声で、ちぃちゃん本人、「心象の欠片-ちぃちゃん」6個、Sランク弧盤「思考ニャン」5本を無料で解放できる。[^3]
- シティ名声レベル18でちぃちゃん本人を入手できる。[^4]
- 「粗穀」は2.5秒に1回まで発動する。[^5]
- 「粗穀」で得るファンスには1日の上限と累計上限があり、どちらも名声レベルを上げると上がる。1日の上限は最大50,000、累計上限は最大500,000。[^6]
- HPバーの上の赤いバーは所持している「金穀」、緑のバーは借りられる「金穀ローン」の枠で、EXレール終結を発動すると緑のバーが赤に変わる。[^7]
- 「金穀」の上限はキャラのレベルで上がる。Lv. 80では赤いバーの上限が15,000で、緑のバーも同じなので、EXレール終結中は最大30,000の「金穀」を持てる。[^8]
- 「金穀」による固定ダメージ＝「金穀」の数 × 100% × 防御 × 耐性 × ダメージバフ × クリティカル（クリティカルが出る場合）で、攻撃力ボーナスの影響を受けない。[^9]
- バイレールスキルのクールタイムは3秒。[^10]
- フィールドにいる間、バイレールスキルの連続発動を途切れさせるのは被弾と通常攻撃だけである。[^11]
- 1回目のバイレールスキルの後にキャラを切り替えると、戻った時には連続発動が最初からやり直しになる。[^12]
- 「金穀市場」での最初のバイレールスキルの確定クリティカルは、「金穀」による追加ダメージにも及ぶ。[^13]
- 「金穀市場」は7秒続き、理想的にはその間にバイレールスキルを5回使える。[^14]
- 「金穀市場」中、赤い縦線が「金穀チャート」の山を通る時にバイレールスキルを押すと、所持「金穀」に応じて「金穀」が増え、谷では割合に応じて減る。[^15]
- EXレール終結の後は借りた「金穀ローン」を返す必要がある。返し終わるまではバイレールスキルを押しても「金穀」による追加ダメージは出ず、通常攻撃で「金穀」を溜めて返済する。[^16]
- 「金穀市場」中にちぃちゃんを控えに戻すと、EXレール終結の状態はすぐに終わる。[^17]
- 「飛鳥症候群」により、「充蓄」で操作キャラが得る終結エネルギーが10から14になる。[^18]
