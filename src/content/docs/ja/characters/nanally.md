## スキル

ナナリは中断されない5段コンボを「渾身の一撃！」につなげ、「一代目の権限」で自身を強化して、チームの異能連環ダメージに合わせて追加攻撃を行う。EXレール終結で「相棒」を呼び出して敵を引き寄せ、連携攻撃を行わせる。「創生」強化は創生株の発射を速める。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | コリンスの秘伝技、渾身の一撃！、コリンスの秘伝銃技、主役の登場！、傷一つつけさせないぞ！ | 回避で中断されない最大5段の霊属性の爪攻撃を行い、照準モードの「コリンスの秘伝銃技」と急降下攻撃「主役の登場！」もある。特定の段の後や極限反撃の後に通常攻撃を長押しすると、「渾身の一撃！」を3段つなげる。極限回避の後は「傷一つつけさせないぞ！」で範囲を蹴り、ブレイク耐性を削る。 |
| バイレールスキル | コリンス・アウー術 | 周囲の敵に霊属性ダメージを5回与え、「一代目の権限」状態を得る。ナナリが控えに戻る、再発動する、または持続時間が切れると終了する。 |
| EXレール終結 | コリンス・アルティメット | 周囲の敵にただちに霊属性攻撃を7回与え、「相棒」を召喚する。「相棒」がいる間、ナナリの攻撃は近くの敵を少し引き寄せ、「相棒」はすべての攻撃に連携して、追加攻撃ダメージとして扱われる攻撃を行う。 |
| サポートスキル | 正義の降臨 | 回転して力を溜め、蹴りを放って霊属性の範囲ダメージを1回与える。 |
| パッシブ 1 | 「満ちる」ことのない熱血 | 「創生」強化。各創生株が創生花を10輪発射し、発射間隔が短くなる。 |
| パッシブ 2 | 絶対「公正」な決闘 | 「一代目の権限」状態の間、チームの誰かが異能連環ダメージを与えるたびに、通常攻撃のレベルに応じた霊属性の追加攻撃を敵単体に行う。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| ファミリーの始まり | ナナリが追加攻撃を1回行うたびに、自身の終結エネルギーが2.5回復する。この効果は1秒に1回しか発動しない。 |
| 二人目のメンバー | 「相棒」の持続時間が3秒延長される。 |
| 姉御と呼ぶべし | 「一代目の権限」状態中、ナナリが敵にダメージを与えた時、対象の敵に追加攻撃を1回行い、攻撃力の{0}％にあたる霊異能ダメージを与える。倍率は通常攻撃のスキルレベルに応じて増加し、レベル11で107.9％まで増加する。この効果は毎秒1回しか発動しない。 |
| トラブルメーカーじゃない | 「相棒」の与ダメージ+100％。 |
| 子分がいっぱい | 追加攻撃を1回行うたびに、ナナリ自身の攻撃力が2％増加する（最大+20％）。この効果はナナリが控えに戻るか、戦闘状態が終了すると解除される。 |
| 家族だから | 「一代目の権限」状態の持続時間が15秒に延長される（非戦闘状態では、さらに20秒まで延長）。 |
| 共振 3：「コリンスの秘伝・上」 | 「通常攻撃：コリンスの秘伝技」、「バイレールスキル：コリンス・アウー術」、「EXレール終結：コリンス・アルティメット」のスキルレベル+1。 |
| 共振 6：「コリンスの秘伝・下」 | ナナリの与ダメージが追加で+15％。 |
