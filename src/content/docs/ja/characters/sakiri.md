## スキル

早霧は呪属性のサポーターで、「丸吞み」と「暴食の饗宴」で敵を吸い寄せて拘束しつつ、自身の基礎攻撃力に基づいてチームの攻撃力を高める。パッシブは「浮遊」または「制圧」を付与した後に敵の防御力を下げ、「濁燃」状態の敵が受ける継続ダメージを増やす。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 鬼郎丸の頭突き、ぶん回し、摂食モード、嚥下、極限反撃：イタズラ | 「ぶん回し」で最大5段の呪属性攻撃を行い、「嚥下」で空中から急降下攻撃を行う。極限回避の後は「極限反撃：イタズラ」で反撃し、ブレイク耐性を削る。長押しで「摂食モード」になり、空腹状態の間は近くのターゲットを吸い寄せ、満腹になるまで弱い敵を飲み込む。 |
| バイレールスキル | 丸吞み、ゲップ、重力喰い | 押すと「ゲップ」を発動し、近くの敵を吸い寄せてから鬼郎丸を膨らませて敵を打ち倒す。長押しで「重力喰い」を発動し、近くの敵を吸い寄せ、その場所の重力を飲み込んで敵を浮遊させる。強力な敵には効かない。 |
| EXレール終結 | 暴食の饗宴 | 鬼郎丸が上空から「重力瘴液」を吐き出し、範囲内に呪属性ダメージを6回与える。強い重力で敵を地面に押し付け、制圧された敵を移動不能にする（ボスには無効）。さらに、早霧の基礎攻撃力に基づいて早霧以外のチームの攻撃力を高める。 |
| サポートスキル | 潰れちゃえ！ | 巨大化した鬼郎丸をターゲットに叩きつけ、範囲内に呪属性ダメージを1回与える。 |
| パッシブ 1 | 食べていい？ | 「濁燃」強化を付与する。「濁燃」状態のターゲットが受ける継続ダメージを、付与されている継続ダメージ効果の種類ごとに上限まで増やす。 |
| パッシブ 2 | 悪だくみ | 早霧が「浮遊」または「制圧」を付与した敵の防御力を下げる。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 拡散性の白 | 「EXレール終結：暴食の饗宴」による移動不能効果の持続時間が6秒に延長される。 |
| 乖離性の洗練 | 「EXレール終結：暴食の饗宴」は空中の敵に対して追加ダメージを与え、追加ダメージ量はターゲットの重量が増えるほど増加し、最大で攻撃力×600％となる。 |
| 粘着性のかみ合わせ | チーム全員のキャラが撃破した敵の数に基づいて、その後15秒間、「バイレールスキル：丸吞み」と「EXレール終結：暴食の饗宴」のダメージを増加させる。敵を1体撃破するたびにダメージ+6％、最大で+60％まで増加する。この効果は戦闘状態を離脱すると解除される。 |
| 祈願性のよすが | 「EXレール終結：暴食の饗宴」を発動すると、早霧以外のチーム全員の攻撃力が、早霧の基礎攻撃力の30％相当分増加する（20秒持続） |
| 失覚性の崩落 | 「バイレールスキル：丸吞み」でターゲットを空中に浮かせると、「EXレール終結：暴食の饗宴」の終結エネルギーが最大までチャージされ、クールダウンをリセットする。 |
| 溶解性の暴食 | 鬼郎丸は「摂食モード」の間、最大3体のターゲットを飲み込み、同時に消化することができる。各ターゲットの消化時間は個別に計算される。 |
| 共振 3：尽きない食欲 | 「通常攻撃：鬼郎丸の頭突き」、「バイレールスキル：丸呑み」、「EXレール終結：暴食の饗宴」のスキルレベル+1。 |
| 共振 6：薄霧の恩恵 | ターゲットがデバフ効果を1つ付与されるたびに、早霧の与ダメージ+3％、最大で+12％まで。 |
