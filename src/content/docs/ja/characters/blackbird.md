## スキル

クロバネは「怨念」を溜め、敵に「失楽の羽」を刻んで場外からの連携攻撃を発生させる。その後「鎮魂の祈歌」で「救世の魔女」となり、「怨念」を消費する強化攻撃を行い、「万火帰一」で締めくくる。

| 枠 | スキル | 効果 |
| --- | --- | --- |
| 通常攻撃 | 掠影、還鳥の影、癒えぬ呪い、極限反撃：黒羽の直感、浄化の炎、救済の恩澤、衆生に福音を、灼烙、極限反撃：災厄の申し子、祝祷 | 「掠影」「還鳥の影」「癒えぬ呪い」「黒羽の直感」は魂属性ダメージを与え、「祝祷」により「怨念」を溜める。「救世の魔女」状態では攻撃が「浄化の炎」「救済の恩澤」「衆生に福音を」「灼烙」「災厄の申し子」に変わり、「怨念」を溜める代わりに消費して追加の「怨念」ダメージを与える。 |
| バイレールスキル | 冥き葬羽、渡世の死焔 | 「冥き葬羽」は魂属性ダメージを与えて「怨念」を獲得し、「失楽の羽」を付与する。これにより味方が「失楽鳥」の範囲連携攻撃を最大5回発生させる。「救世の魔女」状態では、「浄化の炎」の5段目または「無悲」の後に「渡世の死焔」が解放され、突進して魂属性ダメージを与え、「怨念」を消費する。 |
| EXレール終結 | 鎮魂の祈歌、万火帰一 | 「鎮魂の祈歌」でクロバネは「救世の魔女」に変身し、硬直無効化と移動速度の増加を得るとともに、チームの攻撃力を高める。場にいない間は持続時間が減らない。再発動すると「万火帰一」が発動し、状態を解除して高威力の魂属性ダメージを与える。 |
| サポートスキル | 我に断罪を、慈悲の余韻 | 「我に断罪を」は「孤独なる翼」に変身して魂属性ダメージを与え、「怨念」を獲得する。「救世の魔女」状態では「慈悲の余韻」となり、魂属性ダメージを与え、命中時に「怨念」を消費する。 |
| パッシブ 1 | 鶫の歌 | 「浸染」強化は「浸染」のダメージ増加効果を高め、持続時間を延ばす。「暗星」強化は、「暗星」の終了時に、「暗星」の間にターゲットが実際に受けたダメージに応じて精神ダメージを追加で与え、その後「暗星」を1回付与し直す。この付与し直しでは効果は再発動しない。 |
| パッシブ 2 | 長き旅路 | クロバネが「我に断罪を」を発動すると、「怨念」を20獲得する。 |

## 覚醒

重複したキャラを1体入手するごとに、好きな覚醒を1つ解放できる。共振は覚醒3つと6つで解放される。

| 覚醒 | 効果 |
| --- | --- |
| 叛逃者 | 「救世の魔女」で「EXレール終結：万火帰一」を発動すると、全ての「怨念」を消費できる。「バイレールスキル：渡世の死焔」のダメージ倍率+150％。 |
| 放浪記 | 「バイレールスキル：冥き葬羽」のダメージ倍率+100％。「救世の魔女」状態の時、防御力+20％。「バイレールスキル：渡世の死焔」の発動に成功すると、自身の基礎攻撃力×400％にあたるHP回復を獲得する。 |
| 失明症 | クロバネが「怨念」を消費して与えるダメージの倍率+50％。 |
| 悪党 | クロバネが「EXレール終結：鎮魂の祈歌」を発動後、チーム全員の攻撃力増加の持続時間が25秒まで延長され、その期間中はチーム全員の与ダメージが12％増加する。 |
| 爛柯の者 | クロバネがダメージを与えた時、命中したターゲットの魂、相、闇異能ダメージ耐性を8％減少させる。25秒持続。 |
| 死と生 | クロバネが「EXレール終結：鎮魂の祈歌」を発動すると、自身の魂異能ダメージ+25％、25秒持続。クロバネが「救世の魔女」状態にない時、「失楽鳥」が連携攻撃を発動すると、「怨念」を4Pt獲得する。 |
| 共振 3：謝罪という名の啓示 | 「通常攻撃：掠影」、「通常攻撃：浄化の炎」、「バイレールスキル：冥き葬羽」、「バイレールスキル：渡世の死焔」、「EXレール終結：鎮魂の祈歌」、「EXレール終結：万火帰一」のスキルレベル+1。「EXレール終結：鎮魂の祈歌」のダメージ倍率+100％、「EXレール終結：万火帰一」のダメージ倍率+50％。クロバネが「EXレール終結：鎮魂の祈歌」を発動すると、「怨念」を20Pt獲得する。 |
| 共振 6：星々の弔いの言葉 | クロバネがチームにいる時、チーム全員のクリティカルダメージ+30％。 |

## 仕様の詳細

- 「怨念」はクロバネのHPバーの上にあるカラスのアイコン付きのゲージで、上限は60である。[^1]
- クロバネは戦闘に入ると「怨念」を20獲得し、「冥き葬羽」は1回で40を与える。そのため最初のローテーションでは「冥き葬羽」を1回使えばゲージが満タンになる。[^2]
- 通常状態の通常攻撃を1セット出し切ると「怨念」を20獲得する。以降のローテーションでは戦闘開始時の「怨念」がないため、満タンにするには「冥き葬羽」に加えて通常攻撃1セットが必要になる。[^3]パッシブ 2「長き旅路」を解放すると、「我に断罪を」の発動でも「怨念」を20獲得する。
- 「渡世の死焔」の間に通常攻撃を長押しすると「衆生に福音を」が出て、その後に通常攻撃を押すと「浄化の炎」の3段目から続く。[^4]
- 「冥き葬羽」は連環値を即座に満タンにする。ゲーム内のクロバネの「即時連環」タグはこの効果を指す。[^5]
- 「失楽の羽」は15秒持続する。味方が出場中に印の付いたターゲットを攻撃すると「失楽鳥」の連携攻撃が発生し、最短2秒間隔、1つの印につき最大5回である。[^6]
- 「渡世の死焔」には「即時連環」の効果がなく、ダメージを与えるだけである。[^7]
- 「渡世の死焔」は「怨念」が足りていれば13消費して追加ダメージを与える。クールダウンはないが、使うたびに解放し直す必要がある。[^8]
- 「渡世の死焔」のダメージが出る前に「万火帰一」を発動すると、「渡世の死焔」は中断される。発動直後にキャラを交代した場合は中断されず、クロバネは場に残って「渡世の死焔」を最後まで出す。[^9]
- 「鎮魂の祈歌」はチーム全員の攻撃力を15秒間20%高める。[^10]「万火帰一」にはこのバフはない。[^11]
- 「救世の魔女」は16秒持続し、残り時間はEXレール終結のアイコンを囲むリングで示される。[^12]
- クロバネが場にいない間、「救世の魔女」のタイマーは止まるが、15秒の攻撃力バフは止まらない。[^13]
- 「鎮魂の祈歌」の演出が終わった時、クロバネは空中にいる。ここで通常攻撃を押すと「浄化の炎」の3段目から始まり、最初の「渡世の死焔」を約2秒早く出せる。[^14]
- 「万火帰一」を発動しないまま「救世の魔女」の時間が切れると、クロバネは元に戻り、そのダメージは失われる。[^15]
- 「鶫の歌」は「浸染」の基礎ダメージ増加を30%に、持続時間を20秒に引き上げる。[^16]
- パッシブ 1「鶫の歌」により、「暗星」終了時の追加の精神ダメージはその「暗星」の間にターゲットが実際に受けたダメージの20%となり、さらに「暗星」が再付与される。再付与された「暗星」からはパッシブは再び発動しない。[^17]
- 「叛逃者」があると、「万火帰一」は残りの「怨念」をすべて一度に消費する。ゲージが満タンなら、この部分だけで倍率は約3,360%になる。[^18]
- 「放浪記」の100%は独立乗算で、「冥き葬羽」のダメージはそのまま2倍になる。「失楽鳥」の連携攻撃には適用されない。[^19]
- 「失明症」の50%も独立乗算である。[^20]
- 「爛柯の者」の耐性減少は重ならず、以降の命中で持続時間が更新される。[^21]
- 「鎮魂の祈歌」と「万火帰一」のどちらも、「罪と罰」の15秒間のクリティカルダメージバフを発動させる。[^22]装備者は自身へのバフに加えてチーム全体へのバフも受け、1段階目では16%と32%で合計48%になる。[^23]
