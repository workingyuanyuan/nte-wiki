## 타입과 등급

아크는 5개 타입과 S(금색), A(보라색), B(파란색)의 3개 등급으로 나뉜다. 모든 아크는 첫 번째 스탯으로 공격력을, 그 밖에 두 번째 스탯 하나와 5단계로 강해지는 효과 하나를 가진다. 아크는 80레벨까지 오르며 30, 40, 50, 60, 70, 80레벨에서 돌파한다. 한정 S급 아크는 아크 연구 모집 계획에서 얻는다. [보드와 아크 연구 모집](/ko/systems/boards/)을 참고한다.

## 효과

수치는 1단계부터 5단계까지의 범위이다.

| 아크 | 효과, 1단계부터 5단계까지 |
| --- | --- |
| 폭발 현장 | 착용자가 필드 밖에 있을 시, 조작 중인 캐릭터의 공격력이 10%–14% 증가하며, 착용자가 피해를 줄 때마다 조작 중인 캐릭터의 공격력이 2%–3.2% 증가한다(최대 4중첩). 2초마다 최대 1회 중첩되며, 착용자가 조작 중인 캐릭터로 전환될 시 소멸한다. 착용한 캐릭터 조작 시, 혼속성 이능력 피해가 12%–20% 증가하며, 「일반 공격」으로 혼속성 이능력 피해를 줄 때마다 자신의 혼속성 이능력 피해가 2%–3.2% 증가한다(최대 10중첩). 0.3초마다 최대 1회 발동하며 캐릭터 전환 시 소멸한다. |
| 휴일 | 착용자의 공격력이 30%–50% 상승하고, 변형 아크·「일식」을 사용할 수 있다. 변형 아크·「일식」: 착용자는 일식의 힘을 빌려 40초간 지속되는 일식을 발동할 수 있으며, 일식이 지속되는 동안, 착용자가 적 유닛을 처치할 때마다 울트에너지를 6–10 회복한다. (최대 5회 발동 가능, 쿨타임 300초) |
| 연결음이 흐르는 동안 | 공격력+15%–30%. 착용자가 「울티메이트」 발동 후 「추가 공격 피해」를 3회 주었다면, 파티 전체가 방어 무시 효과를 12%–20% 획득하고, 착용자는 방어 무시 효과를 추가로 10%–20% 획득한다. (20초 지속, 중복 발동 시 지속 시간 갱신, 해당 효과는 파티 내에서 하나만 발동 가능) 착용자가 바이레일 스킬 발동 시 파티 전체가 적의 빛속성 이능력 저항을 8%–20% 무시한다. (20초 지속, 중복 발동 시 지속 시간 갱신, 해당 효과는 파티 내에서 하나만 발동 가능) 착용자가 전투에 진입할 때 위의 모든 효과가 즉시 발동한다. |
| 용맹의 솜뭉치 | 착용자가 「울티메이트」 시전 시, 자신의 공격력이 25%–45% 증가한다. (10초간 지속, 해당 효과 중첩 불가) |
| 헤테로의 안녕 | 공격력+15%–25% 보스 유닛에게 주는 피해+15%–25% 변형 아크·「순찰쥐」를 사용할 수 있다. 변형 아크·「순찰쥐」: 「순찰쥐」를 소환해 전장에 투입한다. 「순찰쥐」는 지속적으로 적을 공격해 피해를 주며, 공격 1회당 착용자의 100%–200%에 해당하는 피해를 준다. (30초간 지속, 쿨타임 60초) |
| 시간 밖으로의 행진 | 공격력 +16%–32% 착용자가 「바이레일 스킬」 시전 후 「흉년 미궁」 상태에 돌입하고 현재 부여된 「흉년」을 제거한다. 착용자가 「흉년 미궁」 상태에 있는 동안, 파티원이 「바이레일 스킬」 또는 「서포트 스킬」을 시전할 때마다 「흉년」을 1중첩 획득한다(최대 3중첩). 착용자가 「흉년 미궁」 상태에서 「울티메이트」 시전 시 「흉년 미궁」 상태가 해제되며, 모든 「흉년」 중첩을 소모해 「울티메이트」로 주는 치명 피해를 24%–48% 증가시킨다. 또한, 소모한 「흉년」 1중첩당 착용자가 「울티메이트」로 주는 치명 피해가 8%–16% 추가 증가한다. 한 번에 「흉년」을 3중첩 소모할 경우, 추가로 12%–24%의 방어 무시 효과를 획득한다. (70초간 지속) |
| 현실 도피처 | 령속성 이능력 피해+15%–25% 착용자의 부착물 피해가 10%–15% 증가하며, 「울티메이트」 시전 시 부착물 피해 증가 효과가 20%–30%(으)로 변한다. (6초 지속, 해당 효과 중첩 불가) |
| 세상을 뒤흔든 비 | 착용자가 「바이레일 스킬」과 「울티메이트」로 주는 빛속성 이능력 피해가 30%–42% 증가한다. 착용자가 「바이레일 스킬」 시전 시, 자신의 사이클 강도가 36–72 상승한다. (15초간 지속, 중복 발동 시 지속 시간 갱신) |
| 백만불짜리 미소 | HP+24%–40% 착용자가 「울티메이트」 시전 시, 무작위로 다음 중 1가지 효과를 획득한다. 1. 파티 내 HP 비율이 가장 낮은 캐릭터가 자신 최대 HP의 20%–40%를 회복한다. 2. 착용자 최대 HP의 20%–40%에 해당하는 방어막을 1개 획득한다. (15초간 지속) 3. 전체 파티원이 HP를 10%–20% 회복한다. (해당 효과는 30초마다 최대 1회 발동) |
| 달의 대척점 | 치명 확률+15%–27% 착용자의 「바이레일 스킬」 피해가 28%–56% 증가한다. 착용자가 「바이레일 스킬」 발동 후, 자신의 「일반 공격」으로 주는 피해가 28%–56% 증가하며, 상속성 피해가 20%–40% 증가한다. (15초 지속) |
| 광속의 솜뭉치 | 착용한 캐릭터를 조작 시, 1초마다 공격력이 5%–9% 상승한다. (최대 5중첩, 착용자가 필드 이탈 시 초기화) |
