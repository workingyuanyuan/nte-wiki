## 작동 방식

| 항목 | 규칙 |
| --- | --- |
| 위치 | 보드는 스카버러 마켓에, 아크 연구 모집 계획은 「아크 상점」-「아크 연구 모집 계획」에 있다 |
| 개방 조건 | 메인 임무 「프롤로그 - 새로운 목적지 - '에이본 골동품 가게'로 이동」 완료 |
| 한정 보드 | 한정 S급 캐릭터 1명과 A급 캐릭터 3명이 등장한다. 플레이어는 주사위를 던져 칸에 도착한다 |
| 오픈 기간 | 3주. 수요일 점검 종료부터 수요일 05:59 (UTC+8)까지이며, 「돌아올 수 없는 길」은 2주간 열렸다 |
| 주사위 보상 | 보드마다 특전 화면이 있으며, 누적 주사위 50, 120, 200회에 글라이더 리버리, 탈것 리버리, 코스튬을 받는다. 같은 아이템이 칸에서 먼저 나올 수도 있다 |
| 주사위 횟수 | 보드 이름별로 유지되며, 같은 보드가 복각되면 이어진다 |
| A급 캐릭터 | [민트](/ko/characters/mint/), [에드가](/ko/characters/edgar/), [아들러](/ko/characters/adler/) 또는 [하니엘](/ko/characters/haniel/), [우미츠키](/ko/characters/aurelia/), [스키아](/ko/characters/skia/) |
| 한정 아크 | 한정 캐릭터마다 한정 S급 아크 1개가 전용 아크 연구 모집 계획에 있으며, 보드와 같은 기간에 열린다 |
| 아크 연구 모집 비용 | 삼중 열쇠. 1.2 버전부터는 「결의 열쇠」 같은 계획 전용 열쇠도 쓴다 |
| 상시 보드 | Game8과 Prydwen에 따르면 상시 운영되며, 상시 S급·A급 캐릭터가 등장하고 별도의 풀과 천장을 가진다 |

Prydwen에 따르면 한정 S급 캐릭터 확정까지의 카운트는 한 한정 보드에서 다음 한정 보드로 이어지며, 아크 연구 모집 계획과 상시 보드는 각자 별도의 카운트를 가진다. 이 카운트는 특전 화면의 주사위 횟수와 다르다.

## 한정 아크

각 아크는 해당 캐릭터의 보드가 열리는 기간에 열린다.

| 아크 | 캐릭터 | 아크 연구 모집 계획 | 삼중 열쇠 외의 열쇠 |
| --- | --- | --- | --- |
| 준비, 준비 | 나나리 | 타이거 특간 | 타이거 열쇠 |
| 시간 밖으로의 행진 | 호토리 | 밝은 달 특간 | 밝은 달 열쇠 |
| 마지막 장미 | 라크리모사 | 녹턴 특간 | 녹턴 열쇠 |
| 만인의 갈망 | 카오스 | 사냥꾼 특간 | 유일한 기간에는 없음 |
| 홍염의 신기루 | 신쿠 | 결의 특간 | 결의 열쇠 |
| 금기의 문 | 일로이 | 꿈의 문 특간 | 꿈의 문 열쇠 |
| 심장을 좀먹는 칼 | 잔홍 | 미혹 특간 | 미혹 열쇠 |
| 원행자의 목소리 | 링코 | 만물의 소리 특간 | 만물의 소리 열쇠 |
| 죄와 벌 | 레이븐 | 깃털 특간 | 깃털 열쇠 |
| 달의 대척점 | 아카네 린 | 해달별 특간 | 해달별 열쇠 |

「밝은 달 특간」과 「녹턴 특간」은 1.0 버전과 1.1 버전의 첫 기간에는 삼중 열쇠만 사용했고, 전용 열쇠는 복각에서 등장한다.
