## 작동 방식

| 부품 | 역할 |
| --- | --- |
| 콘솔 | 캐릭터마다 있는 격자판으로, 배치와 보너스가 캐릭터마다 다르다 |
| 카트리지 | 세트 효과를 정한다. 주 스탯 1개와 부 스탯 4개를 가지며, 드롭될 때 정해진다 |
| 드라이브 모듈 | 격자를 채운다. 주 스탯 1개와 최대 4개의 부 스탯을 가진다. 유형(차지하는 칸 수)과 모양으로 나뉜다 |
| 세트 효과 | 카트리지가 지정한 모양의 드라이브 모듈 2개와 4개가 각각 2세트 효과와 4세트 효과를 발동한다 |
| 캐릭터 보너스 | 캐릭터마다 특정 유형의 드라이브 모듈 1개당 스탯을 얻으며, 아래에 정리했다 |

## 획득처

| 아이템 | 획득처 |
| --- | --- |
| 카트리지 | 토끼굴 Anomaly Zone |
| 드라이브 모듈 | 콘솔 화면의 Rewind. 토끼굴에서 얻는 당근 화폐로 지불한다: Easy는 당근 동화, Normal은 당근 은화, Hard Rewind는 당근 금화 |
| 드라이브 모듈 강화 | 토끼굴에서 얻는 맨홀 갱스터, 맨홀 마스터, 맨홀 보스 |
| 추가 드라이브 모듈 | 4곳의 [부동산](/ko/systems/properties/)에 있는 이상 가구 「햄스터 볼」 |

## 강화와 분해

드라이브 모듈과 카트리지는 맨홀 아이템으로 레벨을 올린다. 강화한 드라이브 모듈을 분해하면 강화로 쌓인 경험치 전부와 비틀 코인의 80%가 돌아온다. 다른 장비에 바로 먹이면 그 경험치의 일부를 잃는다. 강화한 드라이브 모듈은 먹이는 것보다 분해하는 편이 낫다.

NGA 포럼의 플레이어 테스트가 드라이브 모듈과 카트리지 모두에 대해 세부 사항을 덧붙인다.

| 행동 | 테스트 결과 |
| --- | --- |
| 장비 먹이기 | 어떤 드라이브 모듈이나 카트리지든 다른 어느 것에나 먹일 수 있다. 먹인 장비는 강화로 쌓인 경험치의 80%와 기본 경험치 전부를 넘겨준다 |
| 비틀 코인 비용 | 사용한 맨홀 아이템 경험치 50당, 또는 먹인 장비의 기본 경험치 50당 1코인. 레벨 상한을 넘는 경험치에 쓴 코인은 돌려받지 못한다 |
| 상한을 넘는 경험치 | 맨홀 아이템으로 돌아오며, 1,000 미만의 나머지는 사라진다 |
| 분해 | 강화로 쌓인 경험치는 맨홀 아이템으로 전부 돌아오고, 코인은 80%가 돌아온다. 기본 경험치는 맨홀 아이템으로, 또는 장비 등급에 맞는 당근 화폐로 돌아온다: 카트리지는 12개, 드라이브 모듈은 8개 |

## 드라이브 모듈 유형

드라이브 모듈의 모양은 12가지이다. 각 모양에 파랑, 보라, 금색 등급이 있다.

| 드라이브 모듈 유형 | 칸 수 | 모양 |
| --- | --- | --- |
| Ⅱ형 드라이브 | 2 | 가로, 세로 |
| Ⅲ형 드라이브 | 3 | 가로, 세로, L자 4종 |
| Ⅳ형 드라이브 | 4 | 가로, 세로, Z자 2종 |

## 카트리지 세트

6개 세트는 한 속성의 피해를 올리고, 6개 세트는 어느 캐릭터에게나 쓸 수 있다.

| 카트리지 | 드라이브 모듈 2개 | 드라이브 모듈 4개 | 세트의 드라이브 모듈 모양 |
| --- | --- | --- | --- |
| 잃어버린 빛 | 빛속성 이능력 피해+10% | 착용자가 「울티메이트」 시전 후 주는 피해가 공격 대상 방어력의 25%를 무시한다. (20초간 지속, 해당 효과 중첩 불가) | Ⅱ형 가로, Ⅲ형 L자 ×2, Ⅳ형 세로 |
| 디아볼로스 | 암속성 이능력 피해+10% | 적의 암속성 이능력 저항을 12% 무시한다. 착용자가 「노바」 또는 「스코치」 반응 발동 참여 시 암속성 저항 무시 비율이 24%로 변경된다. (20초간 지속) | Ⅱ형 세로, Ⅲ형 L자 ×2, Ⅳ형 가로 |
| 숲속 반딧불의 마음 | 령속성 이능력 피해+10% | 파티원이 근처의 적에게 령속성 이능력 피해를 줄 때마다 착용자의 치명 피해가 8% 증가한다(최대 7중첩, 1중첩당 10초간 지속, 중복 발동 시 지속 시간 갱신). 필드 밖에서도 해당 효과가 유지된다. | Ⅱ형 가로, Ⅲ형 세로, Ⅲ형 L자, Ⅳ형 Z자 |
| 진홍: 쌍둥이 나비 | 주속성 이능력 피해+10% | 근처의 적이 주속성 피해를 받을 때마다 착용자의 공격력이 6% 증가한다(최대 6중첩, 1중첩당 10초간 지속, 중복 발동 시 지속 시간 갱신). 필드 밖에서도 해당 효과가 유지된다. | Ⅱ형 세로, Ⅲ형 가로, Ⅲ형 L자, Ⅳ형 Z자 |
| 악마의 피: 저주 | 혼속성 이능력 피해+10% | 주는 피해가 18% 증가한다. 「노바」 또는 「스테인」의 영향을 받은 유닛 공격 시 피해 증가 효과가 36%로 변경된다. | Ⅱ형 세로, Ⅲ형 세로, Ⅲ형 L자, Ⅳ형 Z자 |
| 스트리트 복서 | 상속성 이능력 피해+10% | 치명 확률+14%. 아군 파티원이 「레모라」 또는 「스테인」을 발동 후, 치명 확률이 추가로 14% 상승한다. (20초간 지속) | Ⅱ형 가로, Ⅲ형 가로, Ⅲ형 L자, Ⅳ형 Z자 |
| 왕국 수호자 | 방어력+15% | 착용자의 방어막 효과+20% | Ⅲ형 가로, Ⅲ형 세로, Ⅲ형 L자 ×2 |
| 그림자 신조 | 공격력+10% | 착용자가 「바이레일 스킬」 시전 시 공격력이 25% 증가한다. (20초간 지속) | Ⅱ형 가로, Ⅱ형 세로, Ⅳ형 가로, Ⅳ형 Z자 |
| 티아의 심야 선술집 | HP+10% | 착용자의 치료 효율+20% | Ⅲ형 가로, Ⅲ형 세로, Ⅲ형 L자 ×2 |
| 작은 대모험 | HP+10% | 착용자의 HP가 감소할 때마다 HP 상한이 4% 상승한다. (최대 10중첩, 1중첩당 10초간 지속, 「울티메이트」 시전 시 바로 10중첩 획득) | Ⅱ형 가로, Ⅱ형 세로, Ⅳ형 가로, Ⅳ형 Z자 |
| 음속 블루 고슴도치 | 에너지 충전 효율+12% | 착용자가 「울티메이트」 시전 시, 전체 파티원의 공격력이 15% 증가한다. (20초간 지속, 해당 효과 중첩 불가) | Ⅲ형 L자 ×4 |
| 고요한 산장 | 정신 피해+10% | 착용자가 일반 공격 시 주는 정신 피해가 12% 증가한다(최대 3중첩, 1중첩당 6초간 지속). | Ⅱ형 가로, Ⅱ형 세로, Ⅳ형 세로, Ⅳ형 Z자 |
