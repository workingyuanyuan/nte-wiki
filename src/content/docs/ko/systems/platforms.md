## 서버와 계정

| 항목 | 규칙 |
| --- | --- |
| 서버 | Asia, America, Europe, SEA |
| 서버 간 데이터 | 연동되지 않으며, 각 서버는 독립적이다 |
| 플랫폼 간 데이터 | 같은 서버에서 같은 계정으로 로그인하면 연동된다 |
| UID | 플랫폼 간 공통이며 무작위로 부여된다 |
| iOS와 Mac 로그인 | Facebook, Google, Sign in with Apple 또는 이메일 |
| Windows PC, Steam, Epic, 갤럭시 스토어 로그인 | Facebook, Google 또는 이메일 |
| PlayStation 로그인 | PSN 또는 이메일 |
| 제3자 로그인 | 서로 다른 제공자로 만든 계정은 별개이며 데이터를 공유하지 않는다 |
| 고객 지원 | 게임 내 [설정] - [고객센터] |

## 업데이트 방법

| 플랫폼 | 절차 |
| --- | --- |
| PC | 게임을 종료하고 런처를 다시 실행한 뒤 [업데이트]를 클릭한다 |
| Android | 게임을 실행하고 업데이트 안내에 따른다 |
| iOS와 Mac | App Store에서 다운로드하거나 업데이트한다 |
| PlayStation | 시스템 화면에서 이환을 선택하고 OPTIONS 버튼을 누른 뒤 업데이트 확인을 선택한다 |
| Steam | 게임을 종료하고 Steam 클라이언트를 다시 실행한 뒤, 라이브러리에서 이환을 찾아 업데이트를 클릭한다 |

버전 업데이트는 수요일 06:00부터 11:00 (UTC+8)까지 진행되며, 점검 중에는 로그인할 수 없다.
