## 스킬

우미츠키는 「아리아의 카덴차」로 「카덴차」 상태에 들어가고, 「스타카토」로 해파리를 타고 다니며 주기적으로 해파리 탄환을 쏜다. 「크레셴도」로 공격력 중첩을 쌓고, 「카논 합창」으로 적을 모으며, 「노바」가 끝난 뒤 추가 혼속성 피해를 준다.

| 슬롯 | 스킬 | 효과 |
| --- | --- | --- |
| 일반 공격 | 아카펠라, 레가토, 스타카토, 스피카토, 극한 반격: 싱코페이션 | 「레가토」는 최대 4단 혼속성 공격을 한다. 「스타카토」는 이동 중 회피를 길게 눌러 해파리를 타고, 체력이 떨어질 때까지 주기적으로 해파리 탄환을 쏘며, 이 상태의 극한 반격은 탄환 4발을 쏜다. 「스피카토」는 공중에서 낙하 공격을 하고, 「극한 반격: 싱코페이션」은 극한 회피 후 반격해 붕괴 수치를 깎는다. |
| 바이레일 스킬 | 아리아의 카덴차 | 광역 혼속성 피해를 1회 주고 「카덴차」 상태에 돌입한다. |
| 울티메이트 | 카논 합창 | 근처의 해파리를 불러 모아 광역 혼속성 피해를 6회 주고, 목표를 약간 끌어모은다. |
| 서포트 스킬 | 불협화음 | 해파리에게 공격을 지시해, 명중하면 광역 혼속성 피해를 1회 준다. |
| 패시브 1 | 하모닉스 | 「노바」 강화: 목표의 「노바」 상태가 끝나면 목표에게 혼속성 피해를 3회 준다. |
| 패시브 2 | 크레셴도 | 해파리 탄환이 목표에 명중하면 우미츠키의 공격력이 증가하며, 최대 10중첩까지 쌓인다. |

## 각성

중복 캐릭터를 하나 얻을 때마다 원하는 각성 하나를 해제하며, 각성 3개와 6개에서 공명이 해제된다.

| 각성 | 효과 |
| --- | --- |
| 미래서곡 | 「카덴차」 상태에서 우미츠키의 치명 확률이 15% 증가한다. |
| 특별한 선율 | 극한 회피 성공 또는 「서포트 스킬: 불협화음」 시전 시, 우미츠키가 5초 동안 「카덴차」 상태에 돌입한다. 카덴차 상태에서 해당 효과가 발동된 경우, 해당 상태의 지속 시간이 5초 연장되며, 「카덴차」 상태는 최대 12초까지 지속된다. |
| 삼중주의 쉼표 | 「카덴차」 상태에서 우미츠키가 「울티메이트: 카논 합창」으로 주는 피해가 20% 증가한다. |
| 여백의 미 | 「일반 공격: 스타카토」 시전 시, 우미츠키의 방어력이 20% 증가한다. |
| 평범한 선율 | 「울티메이트: 카논 합창」의 치명 확률이 15% 증가한다. |
| 과거의 푸가 | 「크레셴도」 효과는 최대 20회 중첩된다. 「바이레일 스킬: 아리아의 카덴차」 시전 후, 즉시 「크레셴도」 효과를 10중첩 획득한다. |
| 공명 3: 만물의 화음 | 「일반 공격: 아카펠라」, 「바이레일 스킬: 아리아의 카덴차」, 「울티메이트: 카논 합창」의 스킬 레벨이 1레벨 상승한다. |
| 공명 6: 우리의 하모니 | 「카덴차」 상태에 돌입하거나 「카덴차」 상태의 지속 시간이 연장될 경우, 전체 파티원의 혼속성 이능력 피해가 8% 증가한다. (15초간 지속, 중복 획득 시 지속 시간 갱신) |
