## 스킬

스키아는 「구속 격투술」과 「잠영 추격」으로 목표 하나에 「그림자 송곳니」를 최대 3개까지 붙인다. 바이레일 스킬은 「미행」을 발동해 「그림자 송곳니」가 사라지지 않게 하고, 「은신 잠영」에 들어가 접촉할 때 추가 공격을 일으키며, 「울부짖는 개떼」는 강화와 제어를 더한다.

| 슬롯 | 스킬 | 효과 |
| --- | --- | --- |
| 일반 공격 | 구속 격투술, 영역 장악, 그림자 송곳니, 극한 반격: 회심의 일획 | 「구속 격투술」은 최대 5단 상속성 공격을 하며 「그림자 송곳니」를 분열시킨다. 「그림자 송곳니」는 목표를 추적해 목표당 최대 3개까지 부착되고, 상속성 피해를 1회 준 뒤 사라진다. 낙하 공격 「영역 장악」과 극한 회피 후의 반격 「극한 반격: 회심의 일획」이 있다. |
| 바이레일 스킬 | 잠영 추격, 미행, 은신 잠영 | 「미행」 상태가 되어 광역 상속성 피해를 6회 주고, 목표마다 「그림자 송곳니」 3개를 분열시킨 뒤 「은신 잠영」에 들어간다. 「미행」 중에는 「그림자 송곳니」가 명중해도 사라지지 않는다. 「은신 잠영」은 들키지 않고 이동하게 하며, 접촉 시 「그림자 송곳니」의 추가 공격을 일으키고, 해제될 때 광역 피해를 준다. |
| 울티메이트 | 울부짖는 개떼 | 그림자를 바깥으로 퍼뜨려 광역 상속성 피해를 1회 주고, 다시 모아 광역 피해를 3회 준다. 발동 후 「그림자 송곳니」의 피해(「은신 잠영」의 접촉 피해 포함)가 증가하며, 공격할 때마다 제어 효과를 부여한다. |
| 서포트 스킬 | 수배령 | 경찰견을 지휘하듯 그림자로 목표를 물어뜯어 광역 상속성 피해를 1회 준다. |
| 패시브 1 | 현장 진압 | 「레모라」 강화로, 「그림자 송곳니」가 「레모라」 상태의 목표를 록온하면 「레모라」를 1회 추가로 부여한다. |
| 패시브 2 | 검거 완료 | 「울부짖는 개떼」 발동 후 「그림자 송곳니」의 피해(「은신 잠영」 모드의 접촉 피해 포함)가 증가한다. |

## 각성

중복 캐릭터를 하나 얻을 때마다 원하는 각성 하나를 해제하며, 각성 3개와 6개에서 공명이 해제된다.

| 각성 | 효과 |
| --- | --- |
| 변절자 처리 규정 | 「그림자 송곳니」의 자동 공격 피해 배율이 60% 상승한다. |
| 체계적인 계획표 | 스키아가 「바이레일 스킬: 잠영 추격」 발동 시 자신의 치명 확률이 10% 상승하고, 경직 저항력이 50% 상승한다. 15초 지속. |
| 이상 처리 초안 | 스키아가 「그림자 송곳니」로 록온한 목표에게 주는 피해가 4% 증가한다. 필드에 「그림자 송곳니」로 록온한 목표가 1명만 남아있을 경우, 스키아가 그 목표에게 주는 피해가 4% 추가 증가한다. |
| 일상 규범 지정 | 「미행」 상태의 지속 시간이 12초로 연장된다. 부착 1초당 목표가 받는 부착 피해가 2%씩, 최대 40%까지 증가한다. |
| 사회 적응 중책 | 「그림자 송곳니」로 목표 1명을 록온할 때마다 질량이 50 증가하고, 이동속도가 20% 감소한다. |
| 무의미한 겉모습 | 「은신 잠영」 모드에서 「그림자 송곳니」로 록온한 적 목표와 접촉하면 「그림자 송곳니」의 주는 추가 피해 배율이 20% 상승한다. |
| 공명 3: 직장 생존 규칙 | 「일반 공격: 구속 격투술」, 「바이레일 스킬: 잠영 추격」, 「울티메이트: 울부짖는 개떼」 스킬이 1레벨 오른다. |
| 공명 6: 표준 업무 지침 | 「그림자 송곳니」 1개당 각자 선택한 목표의 상속성 이능력 저항을 2%씩, 최대 6%까지 감소시킨다. |
