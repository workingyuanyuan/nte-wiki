이 선택상자로 사키리, 백장, 하토르, 파디아, 다포딜, 구원 중 원하는 캐릭터 한 명을 얻는다.

## 스킬

백장은 일반 공격, 회피 연계, 「아낌없는 가르침」의 파생 기술로 현재 HP를 소모해 언령 문자 「축」, 「금」, 「죄」를 생성하고, 영역 「가을 심판」 안에서 이를 발동해 추가 피해, 회복, 낮은 HP 적 처형 효과를 낸다.

| 슬롯 | 스킬 | 효과 |
| --- | --- | --- |
| 일반 공격 | 언행일치, 꾸밈 없는 말, 거짓 없는 말, 질풍의 일격, 극한 반격: 허실지계, 그림자 밟기 | 「언행일치」는 최대 5단 주속성 공격을 하며, 「그림자 밟기」로 3회 명중마다 언령 문자 「축」을 최대 3개까지 현재 HP를 소모해 생성한다. 「꾸밈 없는 말」과 「거짓 없는 말」은 터지는 저주 명령 3발을 발사한다. 「질풍의 일격」은 낙하 공격이며, 「극한 반격: 허실지계」는 「축」을 생성한다. |
| 바이레일 스킬 | 아낌없는 가르침, 공평한 마음, 억눌린 생각, 정죄의 일격 | 「공평한 마음」은 지맥의 문자로 목표 위치를 공격한다. 회피 후 바이레일 스킬을 누르면 「억눌린 생각」이 발동해 단일 대상 주속성 피해를 주고 언령 문자 「금」을 생성한다. 「꾸밈 없는 말」이나 「거짓 없는 말」 후에 시전하면 「정죄의 일격」이 발동해 광역 피해를 주고 언령 문자 「죄」를 생성한다. |
| 울티메이트 | 가을 심판 | 영역을 펼치고 언령 상태에 돌입해 주속성 지속 피해를 주며, HP가 일정 비율 아래인 목표를 처형한다. 일시적으로 치명적 피해에 면역되며, 면역이 발동하면 영역이 끝나고 기록한 피해가 나뉘어 들어온다. 「금」은 단일 대상 추가 피해를, 「죄」는 광역 피해를, 「축」은 회복과 피해를 발동한다. |
| 서포트 스킬 | 농땡이 끝 | 잠시 차지한 뒤 저주 명령을 써내려 광역 주속성 피해를 1회 주고, 명중하면 목표에게 언령 문자 「금」을 1개 생성한다. |
| 패시브 1 | 적당한 악취미 | 「스코치」 강화: 「스코치」 상태인 목표에게 언령 문자가 생성되면 같은 효과의 「스코치」를 한 번 더 부여한다. |
| 패시브 2 | 적절한 타이밍 | 백장의 공격력을 높이고 E.T.D 4팀 파티원과 협동 효과를 발동한다. 스키아의 잠행 중 교체해 들어오면 공격하고 「금」을 생성하며, 파디아의 HP가 낮아지면 공격하고 파디아를 치료하고, 라크리모사의 박쥐 상태 중 교체해 들어오면 슈퍼 점프를 발동한다. |

## 각성

중복 캐릭터를 하나 얻을 때마다 원하는 각성 하나를 해제하며, 각성 3개와 6개에서 공명이 해제된다.

| 각성 | 효과 |
| --- | --- |
| 오~ 대장! | 「가을 심판」 지속 기간 동안, 「금」 발동 시 백장의 다음 스킬 피해가 30% 증가한다(중첩 가능). 「죄」 발동 시 백장 스킬 쿨타임을 4초 단축한다(중첩 가능). (현재 스킬 쿨타임 중이 아니라면, 다음 사용 시 적용) |
| 강령의 깃발 | 산맥처럼 겹겹이 쌓여있다. 언령 문자를 1개 생성할 때마다 백장의 공격력이 6% 증가한다.(최대 4중첩, 1중첩당 지속 시간 10초) |
| 저주의 발언 | 언령 문자 생성 상한이 4개로 상승한다. |
| 어쩌면 축복 | 「가을 심판」 지속 기간 동안, 임의 언령 문자 1개가 발동되면, 백장은 최대 HP의 5%를 추가로 회복한다. |
| 달빛에게 | 아직 끝나지 않았어. 「가을 심판」의 지속 시간이 16초로 증가한다. |
| 백색수렴 | 「가을 심판」 지속 시간 동안, 백장의 치명 확률이 30% 상승한다. |
| 공명 3: 질서의 회복 | 「언행일치」, 「아낌없는 가르침」, 「가을 심판」의 스킬 레벨이 1레벨 오른다. |
| 공명 6: 머무는 곳 | 가끔은 대장답게 보호한다. 「가을 심판」 지속 시간 동안 영역 내 모든 파티원이 공격력 보너스를 20% 획득하고 모두 「즉결처형」 효과를 발동할 수 있다. |
