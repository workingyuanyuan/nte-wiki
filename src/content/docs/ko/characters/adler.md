## 스킬

아들러는 일반 공격으로 「업」을 쌓고 바이레일 스킬 「처단의 가호」로 이를 소모해 광역 주속성 지속 피해를 주며 「깨달음의 가호」 방어막을 부여한다. 울티메이트는 여러 번에 걸쳐 주속성 피해를 주고, 패시브 「절제」는 「스코치」 상태인 적에게 디버프를 건다.

| 슬롯 | 스킬 | 효과 |
| --- | --- | --- |
| 일반 공격 | 악업 초월, 번뇌 해방, 우매, 극한 반격: 아제, 업 | 「악업 초월」로 최대 5단 연속 주속성 공격을, 「번뇌 해방」으로 단일 대상 조준 사격을, 「우매」로 낙하 공격을 한다. 극한 회피 후 「악업 초월」을 시전하면 「극한 반격: 아제」가 발동해 붕괴 수치를 깎는다. 「악업 초월」, 「우매」, 「번뇌 해방」이 명중하면 「업」을 최대 20중첩까지 얻는다. |
| 바이레일 스킬 | 처단의 가호 | 공여 환영을 소환해 광역 주속성 피해와 주속성 지속 피해를 주고, 필드 위 캐릭터에게 「깨달음의 가호」 방어막을 부여한다. 시전 시 모든 「업」 중첩을 소모하며, 소모한 중첩마다 스킬 피해가 증가한다. |
| 울티메이트 | 만물 정화 | 다섯 「공여」인 「색」, 「수」, 「상」, 「식」, 「행」을 소환해 모든 적에게 각각 주속성 피해를 5회 준다. 필드에 적이 하나만 남았으면 「공여」가 한 번 더 공격해 총 10회의 주속성 피해를 준다. |
| 서포트 스킬 | 맑은 거울 | 적을 조준해 압축탄 1발을 쏘고, 명중하면 광역 주속성 피해를 1회 준다. |
| 패시브 1 | 절제 | 「스코치」 강화: 목표에게 「스코치」를 부여할 때마다 공격력 감소, 속성 저항 감소, 붕괴 효율 상승 중 무작위 디버프 하나를 부여한다. 같은 디버프는 중첩되지 않는다. |
| 패시브 2 | 정심 | 아들러의 방어력을 높인다. |

## 각성

중복 캐릭터를 하나 얻을 때마다 원하는 각성 하나를 해제하며, 각성 3개와 6개에서 공명이 해제된다.

| 각성 | 효과 |
| --- | --- |
| 무색 | 「울티메이트: 만물 정화」 발동 시, 아들러가 자신에게 「업」을 20중첩 부여한다. |
| 무수 | 「업」 1중첩당 아들러의 피해 보너스가 3%로 상승한다. |
| 무상 | 「깨달음의 가호」 방어막 흡수량이 20% 증가한다. |
| 무행 | 「깨달음의 가호」가 깨질 때, 아들러 방어력의 50%를 기준으로 초과 피해를 흡수한다. |
| 무식 | 「울티메이트: 만물 정화」 발동 시, 아들러가 울트에너지를 20P 반환한다. |
| 제법 공상 | 「깨달음의 가호」 지속 시간이 12초로 연장된다. |
| 공명 3: 깨달음의 정업 | 「일반 공격: 악업 초월」, 「바이레일 스킬: 처단의 가호」, 「울티메이트: 만물 정화」 스킬이 1레벨 오른다. |
| 공명 6: 축복의 가호 | 「깨달음의 가호」로 보호받는 상태일 때, 파티 전체가 주는 주속성 이능력 피해가 10% 증가한다. |
