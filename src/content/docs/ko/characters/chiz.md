Game8은 치즈의 바이레일 스킬을 "Pink Paws Priority Principe"로, Prydwen은 "Pink Paws Priority Principle"로 표기한다. 1.1 버전에서 치즈에게 맵의 「핑크퍼스를 털어라」 소장품을 모두 하이라이트 표시하는 도시 스킬이 추가되었다.

## 획득 방법

Game8에 따르면 도시 타이쿤 레벨을 올려 얻으며, Prydwen은 치즈와 그 중복 캐릭터를 과금 없이 얻을 수 있다고 적는다.

## 스킬

치즈는 일반 공격으로 「황금 곡식」을 모으고 누적된 바이레일 스킬 시전으로 이를 쓴다. 울티메이트의 「황금 곡식 시장」과 「흑자」 상태를 이용해 「황금 곡식 대출」과 변동하는 「황금 곡식」 가격을 빛속성 피해로 바꾼다.

| 슬롯 | 스킬 | 효과 |
| --- | --- | --- |
| 일반 공격 | 실향 검술, 흉년의 곡식, 풍년의 옥, 극한 반격: 민스키 모멘트 | 「실향 검술」은 최대 5회 공격해 빛속성 피해를 주고 「황금 곡식」을 얻는다. 「흉년의 곡식」은 짧게 또는 길게 눌러 빛속성 피해를 주고 「황금 곡식」과 폰즈를 얻는다(처치 시 추가). 「풍년의 옥」은 공중에서 낙하해 「황금 곡식」을 얻고, 극한 회피 후 「극한 반격: 민스키 모멘트」로 붕괴 수치를 깎고 「황금 곡식」을 얻는다. |
| 바이레일 스킬 | 핑크퍼스 우선 원칙 | 바이레일 스킬 사용 횟수를 최대 3회까지 저장한다. 연속으로 누르면 「무포지션」, 「반절 매수」, 「풀 매수」를 차례로 시전한다. 길게 누르면 2회 또는 3회를 소모하며, 「반절 매수」 동안 「황금 곡식」을 계속 소모하고, 모든 「황금 곡식」과 「적자」 상태의 「황금 곡식 대출」을 써서 치명타가 발동하지 않는 추가 빛속성 피해를 준다. 「흑자」에서 강화된다. |
| 울티메이트 | 제로섬 게임 | 「흑당 버블」을 던져 광역 빛속성 피해를 주고, 「황금 곡식 대출」을 「황금 곡식」으로 바꾸며, 「흑자」와 「황금 곡식 시장」에 들어가 모든 「황금 곡식」을 투자한다. 첫 「곡식 정산」 피해는 반드시 치명타가 된다. 「핑크퍼스 우선 원칙」을 누르거나 길게 누르면 「황금 곡식 캔들 차트」에 따라 「곡식 정산」이 일어나며, 이후 「황금 곡식 대출」을 상환한다. |
| 서포트 스킬 | 임시 입장 | 「흑당 버블」이 치즈를 태우고 목표에 돌진해 빛속성 피해를 1회 준다. |
| 패시브 1 | 날아가는 새 증후군 | 「차지」 강화: 필드 위 캐릭터가 추가로 차지를 얻는다. |
| 패시브 2 | 수집벽 | 치즈가 필드에 있는 동안 에너지 충전 효율이 증가한다. |

## 각성

중복 캐릭터를 하나 얻을 때마다 원하는 각성 하나를 해제하며, 각성 3개와 6개에서 공명이 해제된다.

| 각성 | 효과 |
| --- | --- |
| 해님아 해님아, 대답해 줘 | 「황금 곡식」과 「황금 곡식 대출」 저장 상한이 10% 증가한다. |
| 소리 없는 불꽃놀이 | 치즈가 「흑자」 상태에서 1초마다 현재 「황금 곡식」의 10%에 해당하는 이자를 획득한다. |
| 영영 비가 오지 않는다면 | 「황금 곡식 캔들 차트」에서의 「황금 곡식」 가격 상승 확률이 50% 증가한다. |
| 주먹밥과 붕대와 폰즈에게 | 「황금 곡식」 획득 속도가 20% 증가한다. |
| 일기장의 빈 페이지 | 치즈가 전투에 입장하는 즉시 현재 「황금 곡식」 저장 상한의 100%에 해당하는 「황금 곡식」을 획득한다. |
| 33일 | 「황금 곡식」으로 주는 추가 빛속성 이능력 피해가 15% 증가한다. |
| 공명 3: 친구이자 가족 | 「적자」 상태에서 「황금 곡식」 획득 효율이 추가로 50% 증가한다. |
| 공명 6: 귀향 | 치즈가 목표에게 피해를 주면, 목표의 빛속성 이능력 피해 저항을 10% 감소시킨다. |
