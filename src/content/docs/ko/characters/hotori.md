## 스킬

호토리는 쿨타임이나 울트에너지 대신 「열린 시계」에 시간이 지나며 에너지를 모은다. 바이레일 스킬은 에너지 60을 써서 아군의 서포트 스킬이나 바이레일 스킬을 최대 3개 기록하고, 울티메이트는 시간 정지를 발동해 기록을 재생하며 타치 연속 공격을 펼친다.

| 슬롯 | 스킬 | 효과 |
| --- | --- | --- |
| 일반 공격 | 유동하는 달빛, 열린 시계, 잔물결, 초승달, 극한 반격: 찰나의 몸짓 | 「유동하는 달빛」은 최대 5회 빛속성 공격을 하고, 「잔물결」은 전투 중 길게 누르면 앞으로 돌진하며, 「초승달」은 공중에서 내리꽂는다. 「열린 시계」는 호토리가 출전하면 저절로 돌아가며 에너지를 최대 120까지 모은다. 「극한 반격: 찰나의 몸짓」은 극한 회피 후 반격해 붕괴 수치를 깎는다. |
| 바이레일 스킬 | 현실 리플레이 | 쿨타임이 없다. 「열린 시계」 에너지가 60보다 많을 때 60을 소모해 빛속성 이능력 피해를 7회 주고, 시곗바늘을 되감으며, 아군의 서포트 스킬이나 바이레일 스킬을 최대 3개(아군 1명당 1개) 기록한다. 전투에 들어가거나 나가면 기록이 지워지고, 다시 시전하면 이전 기록을 덮어쓴다. |
| 울티메이트 | 밀려드는 세상 | 쿨타임과 울트에너지 소모가 없다. 「열린 시계」 에너지가 가득 차면 시전해 빛속성 공격을 10회 하고, 타치를 들고 시간 정지에 들어가며, 그동안 캐릭터 전환이 불가능하고 시간 제어 면역을 얻는다. 기록된 공격을 한 번 재생하고, 타치 연속 공격 단수를 10까지 쌓아 종결 피해를 주며, 시곗바늘을 되감는다. |
| 서포트 스킬 | 점주의 권위 | 우산을 던져 광역 빛속성 이능력 피해를 1회 준다. |
| 패시브 1 | 유령난초 문장 | 「블라썸」 강화를 부여해, 시간 정지 중에도 「창조의 줄기」 공격이 멈추지 않게 한다. |
| 패시브 2 | 세상의 모든 진귀한 것 | 「밀려드는 세상」의 종결 피해 배율을 높인다. |

## 각성

중복 캐릭터를 하나 얻을 때마다 원하는 각성 하나를 해제하며, 각성 3개와 6개에서 공명이 해제된다.

| 각성 | 효과 |
| --- | --- |
| 활기찬 성장 | 「서포트 스킬」 또는 「바이레일 스킬」 1개를 기록할 때마다, 호토리가 시간 정지 상태에서 주는 피해가 12% 증가한다. |
| 아득한 기억 | 시간 정지 상태에서 호토리의 주는 피해가 20% 증가한다. |
| 순간의 시선 | 「바이레일 스킬: 현실 리플레이」를 사용해 기록을 완성하면 「바이레일 스킬: 현실 리플레이」를 사용해 소모된 에너지를 빠르게 회복한다. 60초마다 최대 1회 발동한다. 에너지 회복 과정에서 에너지를 소모하는 행동을 하면 에너지 회복이 중단된다. |
| 흩어진 컬렉션 | 시곗바늘이 반시계 방향으로 돌아가지 않는 동안, 파티 전체가 목표를 1명 처치할 때마다 「열린 시계」에 에너지를 10 추가로 축적한다.(최대 3회 적용. 「울티메이트: 밀려드는 세상」 발동 시 카운트 리셋) |
| 진상 파악 | 호토리가 출전하고 필드에 적이 1명만 남아있을 경우, 파티 전체가 해당 목표에게 주는 피해가 15% 증가한다. 호토리가 탈진하면 효과는 사라진다. |
| 눈 위에 흐르는 시간 | 시간 정지 상태에서 호토리가 피해를 주면 목표 방어의 30%를 무시한다. |
| 공명 3: 흩어진 영원 | 「일반 공격: 유동하는 달빛」, 「바이레일 스킬: 현실 리플레이」, 「울티메이트: 밀려드는 세상」 스킬이 1레벨 오른다. |
| 공명 6: 확신의 보물 | 호토리가 파티에 있고 생존 상태인 경우, 파티 전체 공격력이 30% 증가한다. |
