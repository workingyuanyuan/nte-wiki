## 스킬

카오스는 공격으로 「죄목」을 쌓고, 울티메이트의 「악명의 굴레」 상태에서는 이를 빠르게 쌓는다. 최대치의 「죄목」을 「재단」으로 소모해 강력한 청산 피해를 주며, 「추격 허가」를 부여하고 「레모라」를 강화한다.

| 슬롯 | 스킬 | 효과 |
| --- | --- | --- |
| 일반 공격 | 추적, 재단, 파국, 직감 / 본능 | 「추적」은 최대 5단 상속성 공격을 한다. 일반 공격을 길게 누르면 「재단」이 발동해, 「죄목」이 최대치면 이를 소모하고 2단계의 강력한 청산 피해를 주며, 최대치가 아니면 1단계만 발동한다. 「파국」은 공중에서 낙하해 높이에 비례하는 광역 상속성 피해를 주고, 극한 회피 후 「추적」을 쓰면 「직감 / 본능」이 발동해 붕괴 수치를 깎는다. |
| 바이레일 스킬 | 혐의점 포착 | 전방으로 사격하고 사냥개를 소환해 목표를 덮쳐 2회 물어뜯게 한다. 명중하면 최대 2명의 적에게 「추격 허가」를 부여하며, 「추격 허가」가 있는 목표에게 주는 피해가 증가한다. |
| 울티메이트 | 죄업 청산 | 사냥개를 소환해 주위의 적을 제압하고, 범위 내 모든 적에게 「추격 허가」를 부여하며 「악명의 굴레」 상태가 된다. 「악명의 굴레」 동안 「죄목」이 시간에 따라 빠르게 쌓여, 「재단」을 더 자주 시전해 강력한 청산 피해를 줄 수 있다. |
| 서포트 스킬 | 강습 | 낫을 베어 올려 상속성 피해를 1회 준다. |
| 패시브 1 | 늦지 않은 정의 | 「레모라」 강화: 「레모라」가 끝나면 목표에게 공격력에 비례하는 상속성 피해를 준다. 「레모라」 기본 지속 시간을 넘긴 시간만큼 총 피해가 증가하며, 「레모라」를 다시 부여하면 지속 시간이 리셋된다. |
| 패시브 2 | 집중 마크! | 「추격 허가」가 부여된 적을 공격할 때 얻는 피해 보너스를 높인다. |

## 각성

중복 캐릭터를 하나 얻을 때마다 원하는 각성 하나를 해제하며, 각성 3개와 6개에서 공명이 해제된다.

| 각성 | 효과 |
| --- | --- |
| 진실의 눈 | 카오스가 「추격 허가」가 부여된 적 공격 시, 40%의 「죄목」을 추가로 획득한다. |
| 죄명 / 악행 | 카오스가 「추격 허가」를 가진 적 공격 시, 목표 방어력의 20%를 무시한다. |
| 폭죽 | 「울티메이트: 죄업 청산」 발동 시, 치명 피해가 30% 증가한다. 20초 지속.(중복 발동 시 지속 시간 갱신) |
| 굽이치는 파도 | 카오스가 「추격 허가」가 부여된 목표 처치 시, 해당 「추격 허가」는 근처 미표식 상태의 목표에 이전되며 지속 시간이 갱신된다. |
| 공허 응시 | 필드에 「추격 허가」가 부여된 목표가 1명만 남으면, 카오스가 그 목표에 주는 피해가 20% 증가한다. |
| 거짓 원점 | 「울티메이트: 죄업 청산」 발동 즉시 「죄목」을 최대치까지 획득한다. |
| 공명 3: 정의 / 정확 | 「일반 공격: 추적」, 「바이레일 스킬: 혐의점 포착」, 「울티메이트: 죄업 청산」 스킬이 1레벨 오른다. |
| 공명 6: 빛 / 낮 | 「추격 허가」가 부여된 적의 상속성 이능력 피해 저항이 10% 감소한다. |
