## 스킬

하토르는 바이레일 스킬, 「극한 반격: 오차 제로」, 패시브 「효율 부스트」로 「스피드퀵」 중첩을 쌓는다. 울티메이트를 시전하면 「긴급 배송」 상태가 되어 쌓은 중첩만큼 공격력 보너스를 얻고, 「공중 지령」이 중첩을 소모해 빠른 연속 공격을 하는 「싸이클론 스트라이크」로 바뀐다.

| 슬롯 | 스킬 | 효과 |
| --- | --- | --- |
| 일반 공격 | 초스피드 배송, 파이널 배송, 하늘의 지배자, 극한 반격: 오차 제로 | 「초스피드 배송」은 최대 5회 상속성 공격을 하고, 「파이널 배송」은 공중에서 내리꽂으며, 일반 공격을 길게 누르면 「하늘의 지배자」로 적을 띄운 뒤 내리꽂는다. 「극한 반격: 오차 제로」는 극한 회피 후 반격해 광역 상속성 이능력 피해를 주고 붕괴 수치를 깎으며 「스피드퀵」을 준다. |
| 바이레일 스킬 | 공중 지령, 싸이클론 스트라이크 | 「공중 지령」은 전방의 적을 베어 「스피드퀵」을 2중첩 얻는다. 길게 눌러 차지하면 상속성 광역 범위가 넓어지고 「별점 5점의 추적」을 부여해, 그 적이 아군을 명중하면 3중첩을 얻는다. 「긴급 배송」 중에는 중첩을 소모해 오토바이로 빠른 연속 공격을 하는 「싸이클론 스트라이크」가 된다. |
| 울티메이트 | 라이더 익스프레스 | 가시덤불 오토바이를 소환해 적 주위를 돌다가 급강하해 광역 상속성 이능력 피해를 주고 「긴급 배송」 상태에 돌입한다. 이 상태에서는 「스피드퀵」을 얻지 않고, 「공중 지령」이 「싸이클론 스트라이크」로 바뀌며, 이동속도가 오르고 쌓아 둔 중첩만큼 공격력 보너스를 얻는다. 캐릭터를 전환하면 「긴급 배송」이 즉시 끝난다. |
| 서포트 스킬 | 조준 낙하 | 공중에서 기습해 목표를 걷어차 충격을 일으키며 광역 상속성 이능력 피해를 2회 준다. |
| 패시브 1 | 딜레이 경고 | 「레모라」 강화를 부여해, 목표의 「레모라」 지속 시간을 늘리고 「레모라」의 영향을 받은 목표를 공격할 때 치명 확률을 높인다. |
| 패시브 2 | 효율 부스트 | 목표를 처치하면 「스피드퀵」을 1중첩 얻는다. |

## 각성

중복 캐릭터를 하나 얻을 때마다 원하는 각성 하나를 해제하며, 각성 3개와 6개에서 공명이 해제된다.

| 각성 | 효과 |
| --- | --- |
| 엘리트 배송원 | 전투 입장 후 처음 「바이레일 스킬」을 길게 누르면 바로 「스피드퀵」을 6중첩을 획득한다. |
| 가시 지배 | 「호평 일색」과 「별점 5점의 추적」이 자연 종료 시, 하토르가 「스피드퀵」을 획득한다. |
| 외로운 날개 | 하토르가 보스를 제외한 목표에게 주는 피해가 15% 증가한다. |
| 엔진의 울림 | 「긴급 배송」 상태에서 하토르가 「바이레일 스킬: 싸이클론 스트라이크」를 성공적으로 시전할 때마다 다음 「바이레일 스킬: 싸이클론 스트라이크」의 치명 확률이 25% 상승한다. 해당 효과는 이번 「긴급 배송」 상태 종료 후 사라진다. |
| 레귤러 샌드위치 | 「스피드퀵」을 1중첩 획득할 때마다 하토르가 목표에게 주는 피해가 1% 증가한다. 효과는 중첩되며 최대 15%까지 증가하고, 전투 상태 이탈 시 사라진다. |
| 일상생활 공략 중 | 「긴급 배송」 상태에서 하토르의 치명 피해가 30% 증가한다. |
| 공명 3: 더블 캐파 | 「일반 공격: 초스피드 배송」, 「바이레일 스킬: 공중 지령」, 「울티메이트: 라이더 익스프레스」 스킬이 1레벨 오른다. |
| 공명 6: 쾌속 통행 | 「긴급 배송」 상태에서 하토르의 주는 피해가 목표 방어력의 10%를 무시한다. |
