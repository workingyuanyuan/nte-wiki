## 프로필

| 항목 | 내용 |
| --- | --- |
| 등급 | S급, 상시 |
| 속성 | 암 |
| 아크 타입 | 액체 (Liquid) |
| 참전 | 1.0 버전 |
| 성우 | 중국어: 陈彦亦; 영어: Natalie Van Sistine; 일본어: 大原さやか; 한국어: 이명호 |
| 아카이브 | [다포딜 아카이브](/ko/characters/daffodill/archive/) |

공식 프로필은 에이본 골동품 가게의 다포딜을 대화를 어떻게 시작해야 할지 늘 모르고, 사람보다 이상 현상을 관찰하는 쪽을 좋아하는 인물로 그린다. 그녀의 칼날은 자격이 있다고 인정한 사람만을 위해 쓰인다.

공식 공지와 프로필은 영어 이름을 Daffodill로 표기한다. Prydwen과 Game8은 Daffodil로 표기한다.

## 획득 방법

| 방법 | 내용 |
| --- | --- |
| 상시 보드 | Game8과 Prydwen에 따르면 상시 S급 캐릭터는 스카버러 마켓의 상시 보드에 있다 |
| 선택상자, 1.2 버전 | 2026-08-19 05:59 (UTC+8) 이전에 캐릭터를 생성한 모든 플레이어에게 우편으로 S급 상시 캐릭터 선택상자 지급 |
| 선택상자, 1.4 버전 | 도시 타이쿤 「푸카 멤버십 플랜」에서 S급 상시 캐릭터 선택상자 획득 |

이 선택상자로 사키리, 백장, 하토르, 파디아, 다포딜, 구원 중 원하는 캐릭터 한 명을 얻는다. 보드의 작동 방식은 [보드와 아크 연구 모집](/ko/systems/boards/)에 있다.

## 스킬

다포딜은 붕괴 피해와 빠른 교체에 특화되어 있다. 아군의 서포트 스킬로 「공명」 중첩을 쌓아 「메아리」로 바꾸고, 울티메이트로 「통찰」을 부여하며 「잔상 이동」 횟수를 해제하고, 「디스코드」 강화로 적의 붕괴 수치 상한을 낮춘다.

| 슬롯 | 스킬 | 효과 |
| --- | --- | --- |
| 일반 공격 | 잔잔한 수면, 갈라지는 빛, 수면에 비친 그림자, 엇갈린 칼날, 크로스 체크, 극한 반격: 일섬 | 「잔잔한 수면」은 최대 5단 암속성 공격을 하고, 「갈라지는 빛」은 붕괴 피해 기여를 높인다. 길게 누르면 「수면에 비친 그림자」의 회오리 돌진과 칼자국이 발동하며, 연속 공격 중 회피하면 「잔잔한 수면」을 끊지 않고 무적 상태의 「엇갈린 칼날」이 발동한다. 「크로스 체크」는 공중에서 낙하 공격을 하고, 극한 회피 후 「극한 반격: 일섬」으로 붕괴 수치를 깎는다. |
| 바이레일 스킬 | 공명, 메아리 | 「공명」은 목표에게 피해를 주며, 파티원이 서포트 스킬을 시전할 때마다 「공명」 중첩을 얻어 「공명」의 피해와 붕괴 수치가 최대 2중첩까지 증가한다. 최대 중첩에서 「공명」이 강화되어 「메아리」로 바뀌며, 자세를 바꿔 로프로 칼날을 휘둘러 암속성 피해를 준다. |
| 울티메이트 | 피날레 장식 | 광역 암속성 피해를 주고, 왼쪽 눈을 개방해 피해를 높이며, 근처 적에게 「통찰」을 부여한다. 또한 「잔상 이동」을 최대 2회 사용할 수 있게 하며, 시전 시 「잔상 이동」 횟수를 갱신한다. |
| 서포트 스킬 | 극한 교차 | 칼날을 베듯이 휘둘러 목표에게 암속성 피해를 1회 준다. |
| 패시브 1 | 발검 | 「디스코드」 강화: 「디스코드」 상태인 목표의 붕괴 수치 상한을 낮춘다. 초기 붕괴 수치 상한에 따른 한도까지 중첩되며, 전투 이탈 시 원래대로 회복된다. |
| 패시브 2 | 매미 허물 | 「잔상 이동」으로 주는 피해를 높인다. |

## 각성

중복 캐릭터를 하나 얻을 때마다 원하는 각성 하나를 해제하며, 각성 3개와 6개에서 공명이 해제된다.

| 각성 | 효과 |
| --- | --- |
| 눈 | 파티 전체 캐릭터가 서포트 스킬을 발동할 때마다 「바이레일 스킬: 공명」의 피해량 증가가 100%, 붕괴 수치가 250%로 변한다. |
| 기계 행진 | 「잔상 이동」을 통한 반격기가 적을 명중하지 못하더라도, 마지막 공격으로 목표에게 고위력 피해를 주고 붕괴 수치를 대폭 차감하며, 「울티메이트: 피날레 장식」 에너지를 최대치까지 충전한다. |
| 창조된 자들 | 목표에 부가된 「통찰」은 제거되지 않는다(목표 사망/전투 이탈 제외, 중복 부가 시 최대 2중첩). |
| 은닉 속에서 | 목표가 「통찰」 지속 시간 내에 붕괴하면, 「통찰」 1중첩당 다포딜이 추가로 주는 붕괴 피해가 15% 증가한다. |
| 완벽한 진실 | 목표가 「통찰」 지속 시간 내에 붕괴하면, 「통찰」 1중첩당 다포딜에게 붕괴 피해를 1회 추가로 입는다. |
| 고고한 꽃 | 다포딜이 주는 모든 피해가 목표 방어력의 15%를 무시한다. |
| 공명 3: 비밀 행동 | 「일반 공격: 잔잔한 수면」, 「바이레일 스킬: 공명」, 「울티메이트: 피날레 장식」 스킬이 1레벨 오른다. |
| 공명 6: 햇살과 돌아갈 곳 | 목표가 붕괴 상태가 되면 목표의 암속성 저항이 15% 감소한다. |
