## 스킬

구원은 공격과 창조의 꽃으로 「장미의 약속 탄환」을 만들고 적을 「위험한 장미의 약속」으로 묶으며, 탄환을 소모해 자동 조준 사격을 한다. 울티메이트는 「최종 결산」을 발동해 묶인 모든 목표에게 「계약 청산」을 동시에 실행하며, 창조의 줄기 수용량도 늘린다.

| 슬롯 | 스킬 | 효과 |
| --- | --- | --- |
| 일반 공격 | 비밀이 생겨날 때, 전장 조망, 정보 지향형, 기회 포착, 극한 반격: 전세 역전 | 최대 5회 령속성 공격으로 「장미의 약속 탄환」을 얻고 마지막 타격에 「위험한 장미의 약속」을 부여하며, 낙하 공격과 조준 사격도 있다. 일반 공격을 길게 누르면 「장미의 약속 탄환」을 소모해 묶인 목표를 우선으로 자동 사격한다. 극한 회피 후 「극한 반격: 전세 역전」은 목표를 묶고 붕괴 수치를 깎으며 탄환을 준다. |
| 바이레일 스킬 | 정보 사냥꾼 | 전장을 가로질러 돌진하며 목표를 컨트롤 범위 안으로 끌어당기고 령속성 이능력 피해를 여러 번 준다. 「장미의 약속 탄환」을 얻고 목표와 「위험한 장미의 약속」을 맺는다. |
| 울티메이트 | 최종 결산 | 빠르게 돌진하며 주위 목표를 사격하다가 큰 령속성 폭발로 끝맺는다. 「최종 결산」을 발동해 근처의 「위험한 장미의 약속」 목표를 모두 「계약 청산」 단계로 만들고, 마지막 타격에 모든 청산을 동시에 실행한다. |
| 서포트 스킬 | 시크릿 포착 | 곡선 탄환을 쏘아 령속성 이능력 피해를 1회 주고, 명중하면 「장미의 약속 탄환」을 얻는다. |
| 패시브 1 | 굴러온 기회 | 「블라썸」 강화로 창조의 줄기를 1개 더 생성하고, 필드의 창조의 줄기 상한을 6개로 올린다. |
| 패시브 2 | 풍문조차 나의 힘 | 창조의 꽃이 적을 명중하면 묶이지 않은 목표를 「위험한 장미의 약속」으로 묶고, 이미 묶인 목표에게는 추가 청산을 발동해 령속성 이능력 피해를 더 준다. |

## 각성

중복 캐릭터를 하나 얻을 때마다 원하는 각성 하나를 해제하며, 각성 3개와 6개에서 공명이 해제된다.

| 각성 | 효과 |
| --- | --- |
| 통찰과 침묵 | 전장에 있는 「위험한 장미의 약속」을 맺은 목표 1명당 구원의 공격력이 5% 증가한다(최대 15%까지). |
| 비수가 되어 돌아온 과거 | 「위험한 장미의 약속」의 피해 배율이 100% 증가한다. 「울티메이트: 최종 결산」을 시전해 「계약 청산」을 발동 시, 전체 파티원은 해당하는 장미의 약속으로 준 총 피해량의 5%만큼 HP를 회복한다. |
| 승세 굳히기 | 「울티메이트: 최종 결산」을 시전해 「계약 청산」을 발동 시, 청산 목표의 붕괴 수치를 추가로 4P 차감한다. |
| 한 방 한 방이 치명타 | 자발적으로 「계약 청산」 발동 시, 피해 배율이 50% 증가하며 범위 내 목표에게 적용된다. |
| 진실을 아는 자의 여유 | 구원이 「위험한 장미의 약속」을 맺은 목표에게 주는 피해가 8% 증가한다. |
| 모든 비밀은 내 손안에 | 「위험한 장미의 약속」을 맺은 목표가 스킬을 시전할 때마다 200% 배율의 피해를 받는다. (5초 간격으로 적용) |
| 공명 3: 더블 캐파 | 「일반 공격: 비밀이 생겨날 때」, 「바이레일 스킬: 정보 사냥꾼」, 「울티메이트: 최종 결산」 스킬이 1레벨 오른다. |
| 공명 6: 쾌속 통행 | 「위험한 장미의 약속」을 맺은 목표의 령속성 이능력 저항이 10% 감소한다. |
